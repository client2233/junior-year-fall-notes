# 13 副属和弦（Secondary Dominant）

> 系列：[[11-属进行]] · [[12-小调中的属和弦]] · [[13-副属和弦]] · [[14-251进行]] · [[15-和弦进行2·乐曲中的运用]] · [[16-经过减和弦]] · [[17-五度圈的使用]] · [[18-三全音代理]] · [[19-下属小和弦]] · [[20-套句与持续低音]]
>
> [[12-小调中的属和弦]] 里做了一件事：小调没有合格的属，于是把 `Em` 临时改成 `E7` 来用。这一篇把这个「临时改一个音、造一个属七出来」的动作系统化 —— 事实证明，**调内的每一个顺阶和弦都能被自己的属七和弦「推向」它**，这些借来的属七就叫**副属和弦**。

## 13.1 出发点：属七和弦的移动方向

先把 [[11-属进行]] 的结论复述一遍：

- **属七和弦**：在属音上建立、并且**包含三全音**的和弦。根音名后面原封不动地加一个 `7`（`G7`、`E7`、`C7`…）。
- 因为含三全音，属七和弦是**不稳定的、有紧张感的**。
- 因为这种不稳定性，属七和弦**倾向于朝上方纯四度（下方纯五度）移动** —— 这个走向叫**属进行**。

讲座补了一句关键的话：**属七和弦的移动方向有大和弦与小和弦两种**。

| 调 | 属七 | 移动到 |
|---|---|---|
| 大调 | `G7` | **大和弦** `C` |
| 小调 | `E7` | **小和弦** `Am` |

也就是说：**属七和弦「往上走纯四度」这件事和目标是和弦的大/小无关**。`G7 → C` 和 `E7 → Am` 在移动方向上是同一件事，只是目标的形态不同。

> **要点** 既然移动方向由属七自己决定、与目标无关，那么**任何和弦都可以在前面挂一个「它下方纯五度的属七」来加强进行感**。这就是副属和弦的全部原理。

## 13.2 从主和弦开始试

讲座给的第一个例子还是 `C`，但做法是：把一个进行**中途的 `C` 换成 `C7`**。

`C7` 是 C 的属七形式，按上面的规则，它要往上走纯四度 → **`F`**。

听感上：

- `C7` 的部分给人**「即将进行到下属」的征兆**，所以它的音响有一种**浮游感**；
- 直接听 `C7` 而不是从 `C` 中途变过去，也完全成立。

于是 `C7 → F` 就是一个「人造的属进行」。讲座把这种做法叫做：**强行制造属七和弦**，并称之为一种**扩展技巧**。

> **要点** 在 C 大调里，本来只有 `G7` 是「名正言顺」的属七。而 **`C7`、`D7`、`E7`、`A7`、`B7` 这些都是从别的调借过来的** —— 借的代价是**必须加临时记号**（`C7` 要 `B♭`，`D7` 要 `F♯`，`E7` 要 `G♯`，`A7` 要 `C♯`，`B7` 要 `D♯` 和 `F♯`）。

## 13.3 副属和弦一览表

讲座给了一张表，三列分别是：

> **原本的顺阶和弦（三和弦 / 七和弦）→ 副属和弦的形式 → 解决方向（目标和弦）**

读法是：把左边那个顺阶和弦**原样改成属七**，它就变成中间那一列；这个属七会**顺畅地接到右边那个和弦**。

在 C 大调里逐个走一遍（左右两列都同时给出三和弦与七和弦形态，因为两者都能用）：

| 原本的顺阶和弦 | 副属和弦的形式 | 解决方向 | 需要什么临时记号 |
|---|---|---|---|
| **`C` / `C△7`** | **`C7`** | `F` / `F△7` | B♭ |
| **`Dm` / `Dm7`** | **`D7`** | `G` / `G7` | F♯ |
| **`Em` / `Em7`** | **`E7`** | `Am` / `Am7` | G♯ |
| **`F` / `F△7`** | **`F7`** | ~~`B♭`~~ | ✗ 不成立，见 13.4 |
| **`G` / `G7`** | **`G7`** | `C` / `C△7` | 不需要（本来就是 `V7`） |
| **`Am` / `Am7`** | **`A7`** | `Dm` / `Dm7` | C♯ |
| **`Bm(♭5)` / `Bm7(♭5)`** | **`B7`** | `Em` / `Em7` | D♯、F♯ |

找法一句话：**从目标和弦往前数，副属和弦在它下方纯五度（或上方纯四度）**。讲座的说法是「在音阶表上往右数 3 个、或往左数 4 个」——

- 「往右数 3 个」= 上行 3 个**音级** = 上行纯四度；
- 「往左数 4 个」= 下行 4 个音级 = 下行纯五度；
- 这和 [[11-属进行]] 里的**强进行**是同一个移动。所以讲座说「**就和强进行一样**」。

> **要点** 副属和弦不是新和弦，是**同一个顺阶和弦的属七形态**。所以记忆量没有增加 —— 只需要记住「改哪个音」：把三音升高半音，七音（小七度）降下来。`Em → E7` 里只有 `G → G♯` 这一个音变了，就是这么回事。

### 13.3.1 上一讲的 `E7` 就是这个东西

讲座专门点出：**上次讲的 `E7` 也是副属和弦**，而且是**使用频率极高**的一个。

「虽然那时不知道名称，但已经知道原理了」—— 这正是 [[12-小调中的属和弦]] 的核心：**先有「想要一个像样的属」这个需求，`E7` 才出现**。副属和弦这个名称只是给同一个动作补了一块牌子。

## 13.4 唯一的例外：`F7`

按上面的规则，`F` 的副属形式是 `F7`，它应该往上走纯四度到 `B`。但 `F7` 的移动方向实际是：

- `F7` 往上纯四度 → **`B♭`**，不是 `B`。

也就是说 **`F7` 会移动到以 `B♭` 为根音的和弦去**，而 `B♭` **不是 C 大调的音**。一旦接上去，**就走出了 C 大调（转调）**。

所以结论很干脆：

> **`F7` 不能作为副属和弦使用。**

但讲座紧接着说：**「`F7` 也有别的用途，等学到的时候再记也好」**。这个伏笔在 [[18-三全音代理]] 里兑现 —— `F7` 在那里是 `B7` 的**三全音代理和弦**，非常有用。

> **补充** 判断某个属七能不能当副属和弦，只要看**它的解决目标是不是调内和弦**即可。`C7` 虽然也要加 `B♭`，但它解决到调内的 `F`，所以可用；`F7` 解决到调外的 `B♭`，所以不可用。判断依据是**目标**，不是临时记号的有无。

## 13.5 各类副属和弦的听感

讲座用一组例子逐个听，并给了听感描述：

| 副属和弦 | 位置/进行 | 听感 |
|---|---|---|
| **`C7`** | 直接放在进行里 → `F` | 成熟、大气；`C7` 段的行进感**非常完美**，因为预示了要向**下属**进行，所以带**浮游感** |
| **`D7`** | 放进卡农进行的后半 → `G7` → `C` | 因为 `D7` 能预示后面的 `G7`，所以**容易构成重属和弦**（`D7 → G7 → C`） |
| **`E7`** | 换一个别的进行 → `Am` | 非常**激爽**、成熟的感觉，**摇滚风格**里很常见，能**完美地接回** |
| **`A7`** | 单独准备的和弦 | 根据用法不同效果不同；在**演歌**里出现得多，也是**爵士标准曲**里的常客 |
| **`B7`** | → `E` / `E7` | 很有**感情**、别致的和弦进行；`B7` 用到**两个临时升号** |

关于 `B7`，讲座特别提了一句：**`B7` 接下去的大都是 `E` 或 `E7` 之类的**，即使同属「重属和弦」一类，**`Am Em F C` / `D7 G7` 感觉更积极上升**。

讲座还展示了一个**循环用法**：连续使用副属和弦，可以做出一直循环下去的、很有趣的和弦进行。

> **补充** 「重属和弦」（`V/V`）指的是**属和弦的属和弦**。在 C 大调里，属是 `G`，`G` 的属是 `D`，所以 **`D7` 是重属和弦**，`D7 → G7 → C` 就是「重属 → 属 → 主」。讲座把 `B7` 也归入这一类，是因为它同样是从调外借来的属七（`B7 = V7/Em`），功能上起到「再推一层」的作用。

## 13.6 用代码把表列一遍

```python
NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
C_MAJOR = {0, 2, 4, 5, 7, 9, 11}                 # C 大调音高类
DIATONIC = {0: "C", 2: "Dm", 4: "Em", 5: "F", 7: "G", 9: "Am", 11: "Bm(♭5)"}

# 每个顺阶和弦「变成属七」后的解决方向 = 上行纯四度 = +5 半音
CHORDS = [(0, "C"), (2, "Dm"), (4, "Em"), (5, "F"), (7, "G"), (9, "Am"), (11, "Bm(♭5)")]

print(f"{'顺阶和弦':<10}{'副属形式':<10}{'解决到':<8}{'可用?'}")
for pc, name in CHORDS:
    tgt = (pc + 5) % 12
    ok = tgt in C_MAJOR
    label = DIATONIC.get(tgt, "—")
    print(f"{name:<10}{name[0] + '7':<10}{NAMES[tgt]:<8}{'✓ ' + label if ok else '✗ 调外，不可用'}")
```

输出：

```
顺阶和弦     副属形式     解决到    可用?
C         C7        F       ✓ F
Dm        D7        G       ✓ G
Em        E7        A       ✓ Am
F         F7        A#      ✗ 调外，不可用
G         G7        C       ✓ C
Am        A7        D       ✓ Dm
Bm(♭5)    B7        E       ✓ Em
```

（`A#` 与 `B♭` 是同一个音，这里按音高类输出。）

再把每个副属和弦需要的临时记号列出来：

```python
NATURAL = {"C": 0, "D": 2, "E": 4, "F": 5, "G": 7, "A": 9, "B": 11}
# 属七 = 根音 + 大三度 + 纯五度 + 小七度
DEG = [(0, "根音"), (4, "三音"), (7, "五音"), (10, "七音")]

for root in ["C", "D", "E", "F", "G", "A", "B"]:
    pcs = [(NATURAL[root] + k) % 12 for k, _ in DEG]
    outside = [NAMES[p] for p in pcs if p not in C_MAJOR]
    print(f"{root}7 调外音: {outside if outside else '（无）'}")
```

```
C7 调外音: ['A#']          ← B♭
D7 调外音: ['F#']
E7 调外音: ['G#']
F7 调外音: ['A#']          ← B♭
G7 调外音: （无）
A7 调外音: ['C#']
B7 调外音: ['D#', 'F#']
```

> **注意** `A#` 在这里应写作 **`B♭`**（`C7` 的小七度）、`D#` 应写作 **`E♭`** 时不适用 —— 实际上 `B7` 的两个调外音是 **`D♯` 和 `F♯`**，讲座说的「两个临时升号」指的正是这个。程序输出的是音高类，谱面上要按音级关系写成升号。

## 本篇小结

1. **属七和弦的移动方向由它自己决定**（上行纯四度），与目标和弦是大是小无关 —— 所以任何和弦都能被自己的属七「推」过去。
2. **副属和弦** = 把某个顺阶和弦改成它的**属七形态**，用来加强通往该和弦（实际是通往它上方纯四度的和弦）的进行感。
3. 找法：**目标和弦下方纯五度（上方纯四度）**的属七，就是它的副属和弦 —— 与[[11-属进行]]的**强进行**是同一个移动。
4. C 大调里可用的副属和弦：`C7→F`、`D7→G`、`E7→Am`、`G7→C`、`A7→Dm`、`B7→Em`。
5. **唯一的例外是 `F7`**：它解决到调外的 `B♭`，会转调，所以**不能作副属和弦**。它的用途在 [[18-三全音代理]] 兑现。
6. 副属和弦**都是从别的调借来的**，代价是要加**临时记号**（除 `G7`）。
7. [[12-小调中的属和弦]] 里的 `E7` 就是副属和弦 —— **那时只有原理，现在才补上名称**。
