# 14 二五一进行（II–V–I）

> 这一篇先补一个**记号法**（级数名），再讲这套记号法下最出名的那个组合 —— **2-5-1**。它其实是[[11-属进行]]里「强进行」连做两次的产物，也是后面所有技巧（副属和弦、代理和弦、转调）的演示台。

## 14.1 级数名：为什么用数字记和弦

到目前为止和弦都写成 `C`、`Dm`、`G7` 这样的**和弦名**。讲座从这一篇起改用**级数名**（`I`、`II`、`V`…）。

原因是**和弦名会骗人**。讲座给了一个反例：

- 看到一串 `F` 打头的和声时，如果默认「这是 C 大调」，会很自然地读成「从**下属**开始的进行」；
- 但这个进行**根本不在 C 大调上** —— 它的起始音不同，这次是在 **F 大调**上。
- 结果是：**同样的和弦名，在不同调里的功能完全不同**。

讲座的结论：

> 为了避免这种混乱，如果要表示和弦的功能，就**用级数名** —— 先确定「是哪个调」，再按音级编号。这样一来，**只要知道调，就知道功能**。

因此这一系列讲座标出的级数名，**都是相对于某个明确的调**的。实用的纪律是：

> **以后再遇到和弦，先确认它在哪个调内。**

> **要点** 级数名还有一个副作用是免费的：**换调不用改记号**。`2-5-1` 在 C 大调是 `Dm-G7-C`，在 F 大调是 `Gm-C7-F` —— 写法一模一样。这也是爵士乐手只用数字交流的原因。

> **补充** 级数名与和弦名的分工是「**功能 vs 音响**」：级数名说这个和弦在干什么（T/SD/D），和弦名说它具体按哪几个键。[[13-副属和弦]] 里借来的属七（`D7`、`E7`…）不属于本调音级，写成级数名时通常记作 `V7/II`、`V7/VI` 这样的「**分数**」形式。

## 14.2 2-5-1 的构造

**2-5-1** 就是**沿着音级 2 → 5 → 1 走一遍**的进行。在 C 大调里：

| 级数 | 和弦 | 功能 |
|---|---|---|
| **II** | **Dm7** | 下属功能组（SD） |
| **V** | **G7** | 属功能（D） |
| **I** | **C** | 主功能（T） |

它为什么这么强，讲座给的观察很朴素：

- `D → G`：低音上行纯四度 → **强进行** ✓
- `G → C`：低音上行纯四度 → **强进行** ✓

> **也就是说，2-5-1 是「连续强进行两次、然后回到主和弦」的进行。** 这么理解就可以了。

所以它天然地用在**乐曲的结尾** —— 终止感最强的收束方式。

> **要点** 2-5-1 的强度来自**结构**，不来自某个和弦的特殊性。把 `2 → 5` 和 `5 → 1` 分开看，每一段都只是[[11-属进行]]定义的那一次四度移动；连起来就成了最强的收束。

### 14.2.1 「2」在什么位置

讲座点出 2-5-1 里一个容易忽略的事实：**2 就在 5 的下方纯四度**。

- `D` 上行纯四度 → `G`。所以 **`2` 是「四度下方」的和弦**。
- 结论：**任何 `X → V → I` 的进行，都可以在 `V` 前面插入「它四度下方的和弦」**。

这个「**把四度下方的和弦放到 V 级前面**」的说法，正是 [[13-副属和弦]] 那张表的另一种读法 —— 副属和弦也是靠「四度下方的和弦 → 目标」这个关系工作的。讲座说这两个概念是**捆绑在一起的关系性**。

> **补充** 2-5-1 可以看成**套了两层的副属结构**：
> - `G7 → C`：`G7` 是 `C` 的属七（本调的正牌属和弦）；
> - `Dm7 → G7`：`D7` 本该是 `G` 的**副属和弦**（`V7/V`），只是这里**降级成了本调的 `Dm7`**，所以推力弱一些、色彩更柔和。
>
> 也就是说 2-5-1 = **「副属和弦推属、属推主」的连推两次**，`Dm7` 的位置正是 `D7` 的位置。

## 14.3 「5」是模糊的：拿它当转调枢轴

讲座的这一段是 2-5-1 最有用的一处性质。

看 2-5-1 的三个位置各自「说不说得清」：

| 位置 | 和弦 | 性质确定吗 |
|---|---|---|
| **2** | `Dm7` | 确定（小七和弦） |
| **5** | `G7` | **不确定** |
| **1** | `C` 或 `Cm` | 由 5 之后决定 |

问题出在 5：**`G7` 既能解决到大调的 `C`，也能解决到小调的 `Cm`**（见 [[12-小调中的属和弦]]：小调的属本来就是借来的属七）。所以**听完 2-5，你还不知道目标是大调还是小调**。

讲座给的用法是**反过来利用这种模糊**：

1. 先用 `2 → 5` 把音乐推到某个和弦上；
2. 在落到 5 的时候，**暂时按小调处理**（例如落到 `Cm`）；
3. 从那里再决定**往大调还是小调走**都可以。

这样 `2-5` 就变成了一个**转调枢轴**：一个可以通向大调、也可以通向小调的岔路口。

讲座还提到反向的做法（先用大调、再翻成小调），并说熟练使用这类进行能做出**成了名曲的进行** ——「与其说是诉说，不如说是向心中诉说」的那种感觉。

> **要点** 1 的大小不是 2-5 决定的，是**最后落下去的那一下**决定的。所以 **2-5 只负责「推到某个音上」，不负责「推到哪种和弦上」** —— 这个自由度就是它可以用来转调的原因。

## 14.4 小调的 2-5-1

把小调（自然小调）的顺阶和弦排出来，2-5-1 变成另一副样子：

| 级数 | C 大调的 2-5-1 | C 小调的 2-5-1 |
|---|---|---|
| **II** | `Dm7` | **`Dm7(♭5)`** |
| **V** | `G7` | `G7` |
| **I** | `C` | **`Cm`** |

- **2 变成 `m7(♭5)`**：自然小调的第 2 级三和弦是减三和弦（`D F A♭`），加上小七度就成了 `Dm7(♭5)`。
- **1 变成小和弦** `Cm`。
- `5` 依然要**临时借用和声小调的属七** `G7`（这正是 [[12-小调中的属和弦]] 的内容）。

听感上，讲座说小调版的 2-5-1 **有些悲伤、音响沉稳，却有一种独特的忧郁感**；复习两版 2-5-1 的构造差别，就能明白差别是从哪里来的。

> **补充** 大调版与小调版只差两处：**2 的五音降半音**（`A → A♭`）和**1 的三音降半音**（`E → E♭`）。而这两处改动正是「要把目标定成大调还是小调」的开关 —— 和上一节的「5 是模糊的」是同一件事的两面。

## 14.5 用代码把两版列出来

```python
NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
PC = {"C": 0, "D": 2, "E": 4, "F": 5, "G": 7, "A": 9, "B": 11}

def chord(root, offsets):
    return [NAMES[(PC[root] + k) % 12] for k in offsets]

MAJ7 = [0, 4, 7, 11]        # 大三和弦 + 大七度
M7   = [0, 3, 7, 10]        # 小三和弦 + 小七度
M7B5 = [0, 3, 6, 10]        # 减三和弦 + 小七度
DOM7 = [0, 4, 7, 10]        # 大三和弦 + 小七度
TRIAD_MAJ = [0, 4, 7]
TRIAD_MIN = [0, 3, 7]

print("C 大调 2-5-1 :",
      chord("D", M7),  "->", chord("G", DOM7), "->", chord("C", TRIAD_MAJ))
print("C 小调 2-5-1 :",
      chord("D", M7B5), "->", chord("G", DOM7), "->", chord("C", TRIAD_MIN))

# 强进行判定：低音上行纯四度（+5 半音）
def strong(a, b):
    return (PC[b] - PC[a]) % 12 == 5

print("D->G 强进行:", strong("D", "G"), " G->C 强进行:", strong("G", "C"))
```

输出：

```
C 大调 2-5-1 : ['D', 'F', 'A', 'C'] -> ['G', 'B', 'D', 'F'] -> ['C', 'E', 'G']
C 小调 2-5-1 : ['D', 'F', 'G#', 'A#'] -> ['G', 'B', 'D', 'F'] -> ['C', 'D#', 'G']
D->G 强进行: True  G->C 强进行: True
```

（`G#`、`D#` 在谱面上应写作 **`A♭`**、**`E♭`**；`A#` 应是 **`C` 的上方小七度 `B♭`** —— 程序只算音高类，不管音级写法。）

再确认「2 在 5 的下方纯四度」：

```python
print("D 上行纯四度 ->", NAMES[(PC['D'] + 5) % 12])   # G
print("D 是 G 的纯四度下方:", (PC['G'] - PC['D']) % 12 == 5)   # True
```

## 本篇小结

1. **级数名**（`I`、`II`、`V`…）表示和弦**相对某个调的功能**；和弦名只表示按键。级数名换调不用改写法，是它被广泛使用的原因。
2. **看到和弦先确认调** —— 同样的和弦名在不同调里功能不同，这是级数名存在的理由。
3. **2-5-1 = 连续两次强进行后回到主和弦**（`D→G`、`G→C`），所以是最强的收束，常用于乐句/乐曲结尾。
4. **2 位于 5 的下方纯四度** —— 所以 2-5-1 也可以读成「**在 `V` 前面插入它四度下方的和弦**」，与 [[13-副属和弦]] 是同一套关系性。
5. 2-5-1 可看成**套两层的副属结构**：`D7`（`V7/V`）的位置被降级成本调的 `Dm7`。
6. **`5` 是模糊的**：`G7` 能到 `C` 也能到 `Cm`，所以 **2-5 不决定目标是大调还是小调** —— 这个自由度使它成为**转调枢轴**。
7. **小调版 2-5-1**：`Dm7(♭5) → G7 → Cm`，与 [[12-小调中的属和弦]] 直接衔接。
