## 11.1 强进行

讲座给的第一块基石是**强进行**。

幻灯片的谱例是 `G → C`。低音从 **ソ**（G）走到 **ド**（C）：

> 像这样的，**低音上行纯四度、或者下行纯五度**的部分，就叫做**强进行**。

- 纯四度 = 5 半音，纯五度 = 7 半音。
- 下行纯五度到达的是图中 C **低八度**的 C，所以**也算强进行**。

> **补充** 「上行纯四度」和「下行纯五度」在十二平均律里是**同一个移动**：`+5 ≡ −7 (mod 12)`。所以「低音上行纯四度」这一条判据就够了，后半句只是为了照顾谱面上的方向感。

判据只看**低音**，跟和弦本身无关：

| 进行 | 低音 | 半音数 | 是否强进行 |
|---|---|---|---|
| `G → C` | G → C | 5 | ✓ |
| `Am → Dm` | A → D | 5 | ✓ |
| `Em → Am` | E → A | 5 | ✓ |
| `Dm → G` | D → G | 5 | ✓ |

> **要点** 这次只讲了 `G → C` 这一类（**属 → 主**）。之后的讲座会涉及别的强进行，先记住「**低音上行纯四度**」这条判据就好。

## 11.2 为什么属和弦会让人紧张

讲座把「属和弦为什么紧张」拆成两层：

- **音乐有感觉上的理由**（听感层面）
- **也有物理上的理由**（音本身的振动性质）

## 11.3 泛音：为什么是「强」

幻灯片给的实验：

1. 用力弹一下钢琴**低音区**的 C；
2. 仔细听 —— 能隐约听到 C 以外的音，是 **G**（Sol）。

**在基音之上的音高的音，称为泛音（倍音）。**

- 平时钢琴声听得很多，却从没注意到还有别的音在响；实际上泛音一直在响，**只是基音的音量大**。
- 由此有一种说法：**弹 C 会让人联想到其上方的 G**（纯五度）；换句话说 G 是 C 的「上方纯五度」，反过来走 `G → C` 就是一次「回到根上」的移动，所以听起来强。

讲座对这个说法是**保留**的：「无法完全认同这个说法的人不少」「感觉稍微有些强行」。但讲座表示自己「挺中意这个说法」，因为「**音本身的性质是乐理的根基**」，有点浪漫。

> **要点** 这一节是**对「为什么是强进行」的一种解释**，不是强进行的定义。定义仍然只是一句话：低音上行纯四度。

## 11.4 C 大调中的稳定音与不稳定音

- C 大调音阶都是白键；**以 C 为根音建立的和弦最稳定**（图上标红）。
- **C、E、G 是 C 大调中最稳定的三个音**。无论前面是什么和弦进行，最后接回 C 都有一种安心感。
- 除 CEG 之外的音（图上标灰）都不稳定。其中真正关键的是与稳定音**半音相邻**的那两个：
  - **B 在 C 的下方半音**
  - **F 在 E 的上方半音**
- 与稳定音紧挨着的邻音会被吸引：**B 被稳定的 C 所吸引，F 被稳定的 E 所吸引**。
- 可以把 C E G 想象成**三块磁石**：相比之下，相隔全音的 D 受到的吸引力比 B、F 小得多。

## 11.5 三全音

把上面那两个不稳定的音**同时弹响**（B 和 F）——听上去有些可怕，是让人感到不安的音响。

仔细看 B 和 F 之间的音程：**相隔三个全音**，故得名**三全音**（Tritone / トライトーン）。

- 它也叫**减五度**：「减五度」与「三全音」指的是**同一个音程**，只是叫法不同，不要混淆。

C 大调的顺阶和弦里，**包含 B–F 这对三全音**的只有三个：

| 类型 | 和弦 | 构成音 | 三全音 |
|---|---|---|---|
| 三和弦 | **Bm(♭5)** | B D F | B–F |
| 七和弦 | **G7** | G B D F | B–F |
| 七和弦 | **Bm7(♭5)** | B D F A | B–F |

> **要点** 三和弦里只有 `Bm(♭5)` 含三全音；七和弦里只有 `G7` 与 `Bm7(♭5)`。**`G7` 是唯一一个既含三全音、又能做「属 → 主」强进行的和弦**——这就是它在和声里地位特殊的全部原因。

## 11.6 属七和弦与属进行

三个候选和弦里，最倾向于解决到 C 的是 **G7**。幻灯片给的三条理由是：

| # | 理由 |
|---|---|
| ① | 低音是 `G`，可以朝着 `C` 的根音 `C` 做**强进行** |
| ② | **`B`–`F` 的三全音**想要移动到 `C` 和弦所含的 **`C` 与 `E`** |
| ③ | **三全音**产生浑浊的音响，因此和弦整体听起来不稳定 |

两个定义随之给出：

- **属七和弦（Dominant 7th）**：形如 `G7` 这样，**在属音上建立、并且包含三全音**的和弦。属七和弦中，**三音与七音一定是三全音的关系**。
- **属进行（Dominant Motion）**：**属七和弦移动到上方纯四度（或下方纯五度）和弦**的进行。

> **术语说明** 日语里这个进行也叫「**解決**」，但「解决」一词在中文乐理中并不单指属到主的进行；为避免歧义，讲座**暂译为「属进行」**。本篇沿用这个译法。

> **要点** 「**强进行**」说的是**低音的四/五度移动**；「**属进行**」说的是**属七和弦朝主方向的移动**。属进行必然包含一次强进行，但强进行的范围大得多 —— 只要低音上行纯四度就算，与和弦是不是属七无关。

### 11.6.1 转位会让强进行失效

强进行的判据落在**低音**上，所以属和弦一**转位**，低音条件就不成立了：

| 写法 | 低音 | 半音数 | 强进行 |
|---|---|---|---|
| `G → C`（原位） | G → C | 5 | ✓ |
| `G/B → C`（转位） | B → C | 1 | ✗ |

但上面理由 ②（B–F 三全音向 C–E 移动）和 ③（音响不稳定）**与低音无关，依然成立**。所以 `G7` 的转位**仍然强烈倾向解决到 C**，只是少了低音那一下推力。

> **补充** 这条是我从「判据只看低音」推出的，讲座没有展开。它解释了一件常见的事：`G7/B → C` 之所以照样像属进行，靠的是三全音的音高吸引力，而不是低音的四度跳动。

### 11.6.2 用代码把两件事判一遍

```python
from itertools import combinations

C_MAJOR = [0, 2, 4, 5, 7, 9, 11]              # C 大调音阶的音高类
DEGREE  = ["I", "II", "III", "IV", "V", "VI", "VII"]
TRIAD   = ["C", "Dm", "Em", "F", "G", "Am", "Bm(♭5)"]
SEVENTH = ["C△7", "Dm7", "Em7", "F△7", "G7", "Am7", "Bm7(♭5)"]

def chord(i, offsets):
    """从第 i 级起按音级偏移堆叠：0=根音、2=三度、4=五度、6=七度。"""
    return sorted({C_MAJOR[(i + k) % 7] for k in offsets})

def tritones(pcs):
    """音集里相差 6 个半音的音对就是三全音。"""
    return [(a, b) for a, b in combinations(pcs, 2) if (b - a) % 12 == 6]

for label, offsets, names in (("三和弦", (0, 2, 4), TRIAD),
                              ("七和弦", (0, 2, 4, 6), SEVENTH)):
    for i in range(7):
        pcs = chord(i, offsets)
        if tritones(pcs):
            print(f"{label} {DEGREE[i]:<4} {names[i]:<9} 音集={pcs} 三全音={tritones(pcs)}")
```

跑出来的结果与讲座完全一致：

```
三和弦 VII  Bm(♭5)    音集=[2, 5, 11]     三全音=[(5, 11)]
七和弦 V    G7        音集=[2, 5, 7, 11]  三全音=[(5, 11)]
七和弦 VII  Bm7(♭5)   音集=[2, 5, 9, 11]  三全音=[(5, 11)]
```

`(5, 11)` 就是 F 与 B。

```python
PC = {"C": 0, "D": 2, "E": 4, "F": 5, "G": 7, "A": 9, "B": 11}

def is_strong(bass_from, bass_to):
    """低音上行纯四度（+5 半音）＝ 下行纯五度（−7 半音），模 12 相等。"""
    return (bass_to - bass_from) % 12 == 5

print(is_strong(PC["G"], PC["C"]))        # True   原位 G → C
print(is_strong(PC["B"], PC["C"]))        # False  转位 G/B → C
print(is_strong(PC["A"], PC["D"]))        # True   Am → Dm
```

> **补充** 只要低音是上行纯四度就算强进行 —— 连 `Am → Dm`（不是属到主）也算。**「强进行」是低音层面的概念，「属进行」是和弦功能层面的概念**，两者不要混为一谈。后半段讲座会用「强进行」去解释副属和弦（[[13-副属和弦]]）。

## 本篇小结

1. **强进行** = 低音**上行纯四度**（等价于下行纯五度）的移动。判据只看低音。
2. 泛音是「为什么 G→C 听起来强」的一种解释：弹 C 能听到 G，所以 G 天然指向 C。**这是解释，不是定义。**
3. C 大调里 **C E G** 最稳定；与它们半音相邻的 **B、F** 最不稳定，分别被 C、E 吸引。
4. **B–F = 三全音**（= 减五度）。C 大调顺阶和弦中含三全音的只有 `Bm(♭5)`、`G7`、`Bm7(♭5)`。
5. **属七和弦** = 在属音上建立、含三全音的和弦；**属进行** = 属七和弦移动到上方纯四度（下方纯五度）和弦。
6. `G7 → C` 的三条理由：低音强进行、三全音向 C–E 移动、三全音本身音响不稳。
7. **转位会破坏低音那条理由，但不破坏另外两条** —— `G7/B → C` 依旧强烈倾向解决。
