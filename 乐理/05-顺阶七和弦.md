# 05 顺阶七和弦

> [[04-顺阶三和弦]] 讲的是三和弦（3 和音）。这一篇在其中再堆一个三度，得到**七和弦**（4 和音）。**构造要领完全不变**，多出来的是一个记号系统，这套记号会一直用到最后。

## 5.1 顺阶七和弦的构造

**三和弦是在音阶各音上三度堆两个音；七和弦就是在同样位置三度堆三个音。**

以 C 和弦为例：C 上三度堆两个音得 `C E G`；再往上加一个三度，得 `B`，于是 `C E G B`。

所有和弦做同样处理，就得到七个顺阶七和弦。这些和弦同样称为**顺阶和弦 / 调内和弦**。

| 起始音 | 构成音（意式） | 构成音（字母） | 记号 |
|---|---|---|---|
| `do` | do mi sol si | C E G B | **Cmaj7** |
| `re` | re fa la do | D F A C | **Dm7** |
| `mi` | mi sol si re | E G B D | **Em7** |
| `fa` | fa la do mi | F A C E | **Fmaj7** |
| `sol` | sol si re fa | G B D F | **G7** |
| `la` | la do mi sol | A C E G | **Am7** |
| `si` | si re fa la | B D F A | **Bm7(b5)** |

变成 4 和音之后，**音响变得复杂而丰满** —— 这是七和弦值得专门学一遍的理由。

## 5.2 七音：`7` 与 `maj7` 的区别

对比三和弦与七和弦的名称表，会发现不一样的地方只有两处：

- 一种是在和弦名后**直接加 `7`**（如 `Dm7`、`G7`、`Am7`）；
- 一种是在 `7` 前面**再加一个 `maj`**（如 `Cmaj7`、`Fmaj7`）。

区别在于**根音到七音的音程**，七音同样有大 / 小之分：

| 和弦 | 根音 → 七音 | 七音的性质 | 记号 |
|---|---|---|---|
| `Cmaj7`（C E G B） | **11 半音** | 大七度 | `maj7` |
| `Dm7`（D F A C） | **10 半音** | 小七度 | `7` |

> **要点** **根音到七音是 10 半音 → 加 `7`；11 半音 → 加 `maj7`。**

### 5.2.1 一个常见误解

**「大和弦就配 maj7，小和弦就配 7」是错的。** 三音与七音各自独立存在：

- 有大和弦 + 小七度的情况 —— `G7`（G B D F）就是例子，它是大三和弦配小七度。
- 也有小和弦 + 大七度的情况，虽然少见但确实存在（`mMaj7`）。

用「三音的性质」和「七音的性质」两个维度组合，共 **2 × 2 = 4 种**：

| | 小七度（根音→七音 10 半音） | 大七度（根音→七音 11 半音） |
|---|---|---|
| **大三度**（根音→三音 4 半音） | **属七和弦** `7`<br>例：`G7` = G B D F | **大七和弦** `maj7`<br>例：`Cmaj7` = C E G B |
| **小三度**（根音→三音 3 半音） | **小七和弦** `m7`<br>例：`Dm7` = D F A C | **小大七和弦** `mMaj7`<br>例：`CmMaj7` = C Eb G B |

> **要点** `mMaj7` 因为在顺阶和弦中不存在，听起来会有些陌生。把上面这张 2×2 表记住，**看到任何和弦记号都能立刻定位它的三音和七音**。

## 5.3 数半音的技巧

从根音往上数 10 或 11 个半音有点麻烦。一个更快的办法：

**把根音上移一个八度，再向下数到七音** —— 相隔一个全音就是 10 半音，相隔一个半音就是 11 半音。

> **补充** 七和弦的 pitch class 集合与三和弦一样是「根音 + 音程向量」：
>
> ```python
> SEVENTH = {
>     "maj7":  [0, 4, 7, 11],   # 大三和弦 + 大七度
>     "7":     [0, 4, 7, 10],   # 属七和弦：大三和弦 + 小七度
>     "m7":    [0, 3, 7, 10],   # 小三和弦 + 小七度
>     "m7b5":  [0, 3, 6, 10],   # 半减七和弦：减三和弦 + 小七度（Bm7(b5) 属此类）
>     "mMaj7": [0, 3, 7, 11],   # 小三和弦 + 大七度（顺阶和弦中不出现）
>     "dim7":  [0, 3, 6, 9],    # 减七和弦（顺阶和弦中不出现）
> }
>
> def name_seventh(third: int, seventh: int) -> str:
>     """third ∈ {3, 4}, seventh ∈ {10, 11} → 和弦记号后缀。"""
>     return {(4, 10): "7", (4, 11): "maj7",
>             (3, 10): "m7", (3, 11): "mMaj7"}[(third, seventh)]
> ```
>
> `Bm7(b5)` 的半减性质：`3 + 3 + 4`（小三度 + 小三度 + 大三度），根音到五音 6 半音、根音到七音 10 半音 —— 收集合 `[0, 3, 6, 10]`，正好对上。
>
> 大调顺阶七和弦的品质序列同样是固定的：`maj7 m7 m7 maj7 7 m7 m7(b5)`，罗马数字写作 `Imaj7 ii7 iii7 IVmaj7 V7 vi7 viiø7`。

## 本篇小结

1. **七和弦** = 三和弦上再堆一个三度（4 和音）；构造要领与三和弦完全一致。
2. C 大调顺阶七和弦：`Cmaj7 Dm7 Em7 Fmaj7 G7 Am7 Bm7(b5)`。
3. **`7` vs `maj7` 只看根音到七音**：10 半音（小七度）加 `7`，11 半音（大七度）加 `maj7`。
4. **三音与七音是独立的两维**，组合出 `7 / maj7 / m7 / mMaj7` 四种；「大和弦配 maj7」是常见误解，`G7` 即反例。
5. 数七音时可以「根音上移八度再向下数」来加速。
