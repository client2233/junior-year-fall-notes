# 20 套句与持续低音（Line Cliché / Pedal Point）

> 系列：[[11-属进行]] · [[12-小调中的属和弦]] · [[13-副属和弦]] · [[14-251进行]] · [[15-和弦进行2·乐曲中的运用]] · [[16-经过减和弦]] · [[17-五度圈的使用]] · [[18-三全音代理]] · [[19-下属小和弦]] · [[20-套句与持续低音]]
>
> 应用篇的**最后一篇**。前面十九篇几乎都在讲「和弦往哪里走」；这一篇讲的是**怎么让和弦「原地慢慢变」** —— 两个技巧：**套句**（一个声部级进移动）与**持续低音**（低音不动）。它们都不增加和弦，只改变**织体**。

## 20.1 套句是什么

> **套句** = **常套句**，也就是**定式**的意思 —— 「好像在哪里听过的、很熟悉的」和弦进行。

讲座给的第一个例子有一个醒目的特征：

- **根音被固定在 `C`**，而**和弦名每一小节都在变**（`C → Caug → C6 → C7`）。
- 换句话说：**和弦的根音不变，别的部分在变。**

把这一串和弦放到键盘上看，就能看出规律：

> **在动的那一个音在做半音或全音的级进。**

于是得到定义：

> **和弦的一部分音逐渐移动，这样的进行就叫套句。**

**效果**：和弦一个一个慢慢演变，可以制造**不浮夸、而优美的音响**。

> **术语** 日语叫**クリシェ**（cliché），英文一般叫 **line cliché**。中文教材有时译作「**线条进行**」或直接叫「**内声部半音进行**」。核心都是「**保持一部分、移动另一部分**」。

### 20.1.1 一个例子：`C → Caug → C6 → C7`

根音全程钉在 `C`，而**有另一个音在往上走**：

| 和弦 | 构成音 | 在动的那一个音 |
|---|---|---|
| **`C`** | C E **G** | **G** |
| **`Caug`** | C E **G♯** | **G♯** |
| **`C6`** | C E G **A** | **A** |
| **`C7`** | C E G **B♭** | **B♭** |

在动的那一个音：`G → G♯ → A → B♭`，**逐级上行**（全是半音）。根音一动不动 —— 这就是「根音固定的套句」。

> **注** `Caug`（增三和弦）就是 [[17-五度圈的使用]] 里「正三角形」那个图形所指的和弦；在这里它只是 `G` 升半音的一站。

> **要点** 套句的判据不是「和弦名相似」，而是**有一个声部在做级进**。所以看谱时应该去找**哪一条线在动**，而不是去背和弦名的排列。

## 20.2 常见的几种套句

讲座说得很宽心：**套句的种类并没有那么多。** 现在讲到的常用几个，**把形式背下来也是可以的**。

### 20.2.1 `sus4` / `sus2` 往复型（听感爽朗）

| 和弦 | 构成音（以 C 为例） | 从大三和弦怎么来 |
|---|---|---|
| **`C`** | C E G | 基准 |
| **`Csus4`** | C **F** G | **把三音 `E` 升半音** |
| **`Csus2`** | C **D** G | **把三音 `E` 下降全音** |

- `sus4` 解决时**回到原来的大三和弦**（三音复位）；幻灯片给的写法就是 **`Csus4 → C`**。
- 同理 **`Csus2 → C`** 也是三音复位（`D` 上行全音回到 `E`）。
- 让 **`Csus4 → C → Csus2 → C`** **反复**，就能听到「**来来去去**」的效果。
- 因为只是那一个音在 `F–E–D` 之间往返，**可以无限循环使用**，很方便。

### 20.2.2 以 `△7` 类和弦开始的套句

讲座给的听感描述是：**阴森**、**像是有格调的东西**、**吉他曲里会出现**，也用在**摇滚或热血**的音乐里。

- 和弦名有点难懂，但**关键仍在最上方的音**。
- 讲座指出：**用到很多 `△7` / `Maj7` 这类和弦，是套句的一大特征。**

> **补充** `△7`（大七和弦）天生适合套句，因为它**在最上方多出一个音**，正好给「级进的那条线」提供一个可动的声部。[[05-顺阶七和弦]] 里 `C△7 = C E G B` 的那个 `B`，在这里就是会往下走到 `B♭`、`A` 的那条线。

## 20.3 低音线套句

还有一种套句**根音并没有被固定**：

- 仔细看的话，**低音部在做半音向下的级进**。
- **低音做全音或半音级进的进行，叫做低音线套句。**

讲座自己也承认这里名字用得宽松：

> **严格来讲，这不符合套句的定义**（套句的定义是「和弦内的音逐渐移动」），但**因为相似，就这么叫了。**

一个例子（低音半音下行）：

| 和弦 | `C` | `G/B` | `B♭` | `F/A` | `Fm/A♭` | `C/G` |
|---|---|---|---|---|---|---|
| **低音** | C | B | B♭ | A | A♭ | G |

低音 `C → B → B♭ → A → A♭ → G`，**每一步都是半音**。

注意其中 `F/A → Fm/A♭` 顺手用到了 [[19-下属小和弦]] 的 `Fm` —— **下行低音线是下属小和弦最自然的落点之一**。

其他要点：

- 与根音固定的套句相比，**低音在移动，和弦的走向就听得更明白**。
- 也有使**低音上行**的低音线套句。
- 这些和弦**符合 [[16-经过减和弦]] 的做法** —— **重复多次经过减和弦的进行，和低音线套句也算同类**。
- **低音线套句比根音固定的套句变化要多得多**，但同样有很常用的几个模板；**自己做些新的进行也并非难事**。

### 20.3.1 一种好用的特例：所有和弦共含某个音

讲座提到一类特别的低音线套句：**所有和弦都含有某一个特定的音**（例子中是 `G`）。

- 这样一来，**即使旋律一直停在那一个音上也没有关系**，音响仍然很漂亮。
- 所以它**方便配合长音的旋律**，值得积极使用。

> **补充** 这类做法的原理和持续低音相通：**有一个音全程不动**，音乐就获得了「锚点」，旋律因此可以自由地拖长。区别只是那个锚点在**低音**（持续低音）还是在**内声部**（这种套句）。

## 20.4 持续低音

**做法**：拿一条很简单的进行，**把低音部固定在某个音上**（例子中是 `G`）。

**听感**：

> **明明只是改了低音，整体的感觉却截然不同。**

**作用**：**使听感保持同一，而使音响更加丰满厚实。**

**定义**：

> **持续低音 = 低音保持不变、只移动上面的音。**

- **低音固定这一点和套句一样**，所以两者能得到**相近的效果**。
- 在钢琴上弹的话，就是**左手一直按同一个音**。
- 讲座提醒：**平时使用的进行**也一样 —— **只要固定低音，就能得到非常不一样的音响**，值得多试。

### 20.4.1 三种类型

| 类型 | 低音固定在哪 | 备注 |
|---|---|---|
| **持续低主音** | **主音** | 可以用在**最后几段副歌**上（讲座的例子） |
| **持续低属音** | **属音** `G` | 讲座例子中用的就是这一种 |
| **持续低下属音** | **下属音** `F` | 「这个说法倒不常用」 |

- 持续低音**往往是这三者中的一个**。
- 讲座举的例子中，低音被固定在**主音**，说「可以用在**最后三段副歌**」的样子。

> **补充** 为什么持续低属音特别常见？因为低音停在属音上时，上方无论怎么走，**低音对主音的牵引力一直在** —— 音乐始终处于「悬着、等着落地」的状态。这正是副歌后段、或者段落收束前最需要的效果。

## 20.5 套句 vs 持续低音

讲座用一张**流程图**复习两者的区别，判据只有一条：**低音动不动**。

| 技巧 | 低音 | 氛围变化 |
|---|---|---|
| **持续低音** | **完全不动** | **浑然一体** |
| **低音线套句** | **一点点地变** | **一点点地变化** |

推论：

> **低音不变的话，氛围也能保持统一。**

所以讲座给的实用判据是：

> **无论如何都想要「变化尽量小」的时候，就试试固定低音。**

> **要点** 两个技巧的关系可以一句话记住：**套句让「一部分动」，持续低音让「低音不动」**。它们其实是同一条光谱的两端 —— 动的声部越少、位置越低，音乐就越「静」。

## 20.6 应用：吉他上的持续低音

讲座最后转到**乐器实操**，用吉他从头讲起。

**吉他的基本构造**：

- 6 根弦；从演奏者的视角从[内]到[外]依次编号，**6 弦的音最低**。
- 指板上**每一格半音就有一根金属条**，叫**品格（音品 / fret）**。
- 左手按住某个位置、右手拨弦，就能演奏旋律或和弦。

**做持续低音的例子**：

1. 先弹一个和弦（讲座的例子中 1、2 弦不弹，只用低音几根弦）。
2. 仔细看，**其中三根弦正好组成一个完整的大三和弦**。
3. **保持这个按法**，把手**整体往右（往高把位）移**到下一个位置。
4. 按法没变，所以上方那部分**仍然是大三和弦**；但**最低那根弦的音被固定住了**。
5. 结果：**低音不动、只有上方的音在变** → **这就是持续低音**。

讲座的结论：

- **利用吉他的特性，很容易就能做出持续低音。**
- **吉他相比键盘乐器，和弦音排列的自由度比较低**；但「**把低音固定、上下弹奏同类和弦**」正是它的**强项**。
- **每种乐器都有各自擅长的和弦进行。**

由此引出一条创作用建议：

> **试着用平常不用的乐器作曲** —— 可能会有**出乎意料的结果**，值得尝试各种乐器。

## 20.7 用代码验证

```python
NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
PC = {n: i for i, n in enumerate(NAMES)} | {"Ab": 8, "Bb": 10, "Eb": 3, "Db": 1}

def nm(ps):
    return [NAMES[p] for p in sorted(set(ps))]

def stack(root, offsets):
    """按累计半音偏移堆叠（返回有序的音高类列表）。"""
    return [(PC[root] + k) % 12 for k in offsets]

print("=== sus4 / sus2 与三音的关系（以 C 为例）===")
print("C     =", nm(stack("C", (0, 4, 7))))
print("Csus4 =", nm(stack("C", (0, 5, 7))), "  <- 三音 E 升半音 -> F")
print("Csus2 =", nm(stack("C", (0, 2, 7))), "  <- 三音 E 下降全音 -> D")

print()
print("=== 根音固定的套句：以 C 为固定根音 ===")
for label, offs in [("C", (0, 4, 7)), ("Caug", (0, 4, 8)),
                    ("C6", (0, 4, 7, 9)), ("C7", (0, 4, 7, 10))]:
    ps = stack("C", offs)
    print(f"{label:<5}= {str(nm(ps)):<26} 在动的那个音 = {NAMES[ps[-1]]}")

print()
print("=== 低音线套句：低音半音下行 ===")
seq = [("C", "C"), ("G/B", "B"), ("Bb", "Bb"), ("F/A", "A"), ("Fm/Ab", "Ab"), ("C/G", "G")]
print("和弦:", " -> ".join(n for n, _ in seq))
print("低音:", " -> ".join(b for _, b in seq))
print("相邻半音差:", [(PC[seq[i+1][1]] - PC[seq[i][1]]) % 12 - 12 for i in range(len(seq) - 1)])
```

输出：

```
=== sus4 / sus2 与三音的关系（以 C 为例）===
C     = ['C', 'E', 'G']
Csus4 = ['C', 'F', 'G']   <- 三音 E 升半音 -> F
Csus2 = ['C', 'D', 'G']   <- 三音 E 下降全音 -> D

=== 根音固定的套句：以 C 为固定根音 ===
C    = ['C', 'E', 'G']            在动的那个音 = G
Caug = ['C', 'E', 'G#']           在动的那个音 = G#
C6   = ['C', 'E', 'G', 'A']       在动的那个音 = A
C7   = ['C', 'E', 'G', 'A#']      在动的那个音 = A#

=== 低音线套句：低音半音下行 ===
和弦: C -> G/B -> Bb -> F/A -> Fm/Ab -> C/G
低音: C -> B -> Bb -> A -> Ab -> G
相邻半音差: [-1, -1, -1, -1, -1]
```

在动的那个音：`G → G♯ → A → B♭`，**逐级上行**，根音 `C` 全程不动。

> 输出里的 `A#` 在谱面上应写作 **`B♭`**（`C7` 的小七度）；程序只算音高类，不管音级写法。

## 本篇小结

1. **套句（cliché / 线条进行）** = **和弦的一部分音逐渐移动**的进行；典型形态是**根音固定、另一个声部级进**。
2. 效果是**不浮夸而优美**；判据是「**有一条线在动**」，不是和弦名相似。
3. 常见形态：**`sus4`/`sus2` 往复**（三音升半音/降全音，可无限循环）、**以 `△7` 类开始的套句**（用到很多大七和弦，是套句的特征）。
4. **低音线套句** = **低音做全音/半音级进**；严格说不符合套句定义，但因为相似而如此命名。**变化比根音固定的套句多得多**，与 [[16-经过减和弦]] 同类。
5. **持续低音** = **低音不动、只移动上面的音**。作用是**保持听感同一、使音响更丰满厚实**。
6. 三类型：**持续低主音 / 持续低属音 / 持续低下属音**（后者说法少见）。例子中低主音可用于**最后几段副歌**。
7. **区分两者的唯一判据是低音动不动**：低音不动 → 氛围**浑然一体**；低音微动 → 氛围**一点点变化**。想要变化最小，就**固定低音**。
8. **吉他**上「保持按法、整体移动」天然做出持续低音 —— **固定低音是吉他的强项**；**用平常不用的乐器写曲会有意外收获**。
9. **应用篇到此结束。** 讲座预告下一系列是**发展篇**，主要内容是**复合和弦**等内容，之后讲座的理解会很重要，建议先复习。
