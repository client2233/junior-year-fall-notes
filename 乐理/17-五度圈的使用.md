## 17.1 怎么画五度圈

讲座是**边讲边画**的，步骤照抄：

1. 在纸**正中间画一个比较大的十字**（画得太小，后面会挤成一团）。
2. 把纸**逆时针旋转 30° 左右**，在刚才的十字上**再画一个偏 30° 的十字**。
3. **重复上一步**，直到得到一个像时钟一样、有 **12 个顶点**的图。

然后在 12 个位置顺时针写上音名：

| 位置 | 12 点 | 1 点 | 2 点 | 3 点 | 4 点 | 5 点 | 6 点 | 7 点 | 8 点 | 9 点 | 10 点 | 11 点 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 音名 | **C** | G | D | A | E | B | G♭/F♯ | D♭ | A♭ | E♭ | B♭ | **F** |

- 从 `F`（11 点）继续顺时针走到 `G`（1 点）**也是纯五度**，所以**恰好回到原点形成闭环**。
- 规则一句话：**顺时针转 1 个单位 = 上行纯五度（7 半音）**。这就是「五度圈」这个名字的来源。

> **注意** 讲座特意提醒：这张图**只要错一个位置，就无法形成闭环**。所以写完后要自己验一遍「最后一格到第一格是不是也是纯五度」。

> **补充** 「顺时针 = 上行纯五度」这条规则可以写成公式：**第 k 格 = 从 C 上行纯五度 k 次 = 7k mod 12 半音**。用它就能反过来检查每个位置的音名对不对。

## 17.2 用途一：找调号

**问题**：想知道某个大调的音阶要加几个升/降号。

**做法**：

1. 在图中**找出这个调的位置**。
2. **顺时针**移动，数到它要几步 → **步数就是 ♯ 的数量**；
3. 要找 ♭ 的时候反过来 —— **逆时针**移动 → **步数就是 ♭ 的数量**。

例子：

| 调 | 位置 | 移动 | 调号 |
|---|---|---|---|
| **D 大调** | 2 点 | 顺时针 2 步 | **2 个 ♯** |
| **E 大调** | 4 点 | 顺时针 4 步 | **4 个 ♯** |
| **B 大调** | 5 点 | 顺时针 5 步 | **5 个 ♯** |
| **A♭ 大调** | 8 点 | 逆时针 4 步 | **4 个 ♭** |

讲座提醒可以用「**全 全 半 全 全 全 半**」的间隔自己去推一遍，验证结果是对的。

**加升降号的顺序**：

- **`♯` 的顺序**：与「从 `F` 开始顺时针移动」的顺序**一致** ——

  　　　　`F♯ → C♯ → G♯ → D♯ → A♯ → E♯ → B♯`

- **`♭` 的顺序**：与之**相反**（从 `B♭` 开始逆时针）——

  　　　　`B♭ → E♭ → A♭ → D♭ → G♭ → C♭ → F♭`

所以「知道几个升降号」之后就**按顺序加**，不必背调号表。

> **要点** 这条的实质是：**音名的移动步数 = 调号的数量**。原因是每个 ♯ 都恰好把音阶的某个音抬高半音，而这一切在五度圈上就是「往前走一格」。

## 17.3 用途二：找进行方向与副属和弦

五度圈的两个方向对应两种移动：

| 方向 | 音乐含义 |
|---|---|
| **顺时针** | 上行纯五度 |
| **逆时针** | **下行纯五度 = 上行纯四度** |

而「下行纯五度 / 上行纯四度」正是 [[11-属进行]] 里**强进行**的方向。于是——

> **逆时针就是强进行（属进行）的方向。**

这直接给出了找 [[13-副属和弦]] 的办法：**从目标和弦往回逆时针走一格，就是它的副属和弦**。

| 想知道 | 在圈上操作 | 结果 |
|---|---|---|
| `D7` 移动到哪 | 从 `D` 逆时针 1 格 | → `G` |
| `E7` 移动到哪 | 从 `E` 逆时针 1 格 | → `A` |
| `C7` 移动到哪 | 从 `C` 逆时针 1 格 | → `F` |

讲座说：知道了强进行的方向，**副属和弦**就一目了然 —— 这就是五度圈在**和弦方面**最主要的用法。

> **补充** 顺带把 [[14-251进行]] 也接上了：`2-5-1` 在圈上是**逆时针连走两格**（`D ← G ← C` 反过来读就是 `D → G → C`）。所以「2-5-1 是连续两次强进行」在图上是**连走两格**，一眼可见。

## 17.4 用途三：用图形记和弦构成音

在五度圈上，**同一种和弦型总是构成同一个图形**（只是整体旋转）。所以只要记住图形，就能立刻找出构成音。

| 和弦型 | 图形 | 为什么 |
|---|---|---|
| **增三和弦** | **正三角形**（相隔 **120°**） | 顺时针 4 格 = +4 半音 = **大三度**，三个音各隔 120° |
| **减七和弦** | **正方形**（相隔 **90°**） | 逆时针 3 格 = +3 半音 = **小三度**，四个音各隔 90° |
| **三全音** | **直径**（相隔 **180°**） | 6 格 = +6 半音 = **减五度** |
| **大三和弦 / 小三和弦** | 也有固定图形，但**不对称**（不那么「好看」） | 三个音在圈上间距不相等 |

讲座对这个现象的评论很有意思：

> **越是不稳定的和弦，越是能排成漂亮的形状。**

原因不难想：增三和弦与减七和弦是**完全对称**的（把音重新排列还是同一个和弦型），所以它们在圈上必然是等分图形；而大/小三和弦不对称，图形就不规整。

- 「**同样的形状即是同种和弦**」，所以**只要记得图形，就能很快找出构成音**。
- 讲座还专门给了一张**常用和弦的图形表**，说「习惯弹琴的人这样记会更方便」。

> **补充** 减七和弦的「正方形」性质有一个直接后果：**`dim7` 的四个音各自作根音，得到的还是同一个 `dim7`**（四个音轮换，和弦不变）。这正是 [[16-经过减和弦]] 中「`dim7` 四个音全按小三度堆叠」的图形版本。三全音是「直径」这一点，则是 [[18-三全音代理]] 的全部基础。

## 17.5 用途四：找转调目标

五度圈还能用来**判断往哪里转调**：相邻（或圈上接近）的调共享很多音，转起来顺；圈上相距远的调对比强烈。讲座把这一条列在「其他用途」里，没有展开。

## 17.6 五度圈与四度圈

讲座提到有人把五度圈做成周边（T 恤之类），并顺着说了一句很有用的话：

- **对着镜子看（左右颠倒）就得到了四度圈。**
- 那时就不再是「纯五度循环」，而是**纯四度循环**。
- **四度圈是五度圈的镜像。**
- 爵士乐等乐种**非常重视 `2-5-1` 这类强进行**，所以也有人认为**四度圈看起来更方便** —— 因为在四度圈上，强进行是**顺时针**的，读进行方向和读谱方向一致。

> **要点** 严格来说讲座最后补了一句：「虽说和五度圈比起来，四度圈没那么常见」。所以**主体仍然用五度圈**，四度圈只是同一张图的左右镜像。

## 17.7 用代码把整张图与四种用途验一遍

```python
NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
PC = {n: i for i, n in enumerate(NAMES)}

# 第 k 格（从 12 点 C 起顺时针）= 上行纯五度 k 次 = 7k mod 12 半音
def at(k):
    return NAMES[(7 * k) % 12]

print("五度圈:", [at(k) for k in range(12)], "→ 回到", at(12))

# 用途一：调号数量
print("D 大调在 2 点 →", 2, "个 ♯； A♭ 大调在 8 点 →", 12 - 8, "个 ♭")

# 用途二：逆时针 = 强进行方向 = +5 半音
def ccw(name):
    return NAMES[(PC[name] + 5) % 12]      # 逆时针 1 格
print("D7 →", ccw("D"), "  E7 →", ccw("E"), "  C7 →", ccw("C"))

# 用途三：图形
print("顺时针 4 格 =", (4 * 7) % 12, "半音 = 大三度  → 增三和弦: 正三角形")
print("逆时针 3 格 =", (12 - 21) % 12, "半音 = 小三度 → 减七和弦: 正方形")
print("6 格 =", (6 * 7) % 12, "半音 = 三全音  → 直径")
```

输出：

```
五度圈: ['C', 'G', 'D', 'A', 'E', 'B', 'F#', 'C#', 'G#', 'D#', 'A#', 'F'] → 回到 C
D 大调在 2 点 → 2 个 ♯； A♭ 大调在 8 点 → 4 个 ♭
D7 → G   E7 → A   C7 → F
顺时针 4 格 = 4 半音 = 大三度  → 增三和弦: 正三角形
逆时针 3 格 = 3 半音 = 小三度 → 减七和弦: 正方形
6 格 = 6 半音 = 三全音  → 直径
```

再看「直径」这一条有多直接 —— 它就是 [[18-三全音代理]] 的公式：

```python
for dom in ["G", "D", "F", "A", "B"]:
    print(f"{dom}7 的正对面（差 6 半音）= {NAMES[(PC[dom] + 6) % 12]}7")
```

```
G7 的正对面 = C#7   ← 也就是 D♭7
D7 的正对面 = G#7   ← A♭7
F7 的正对面 = B7
A7 的正对面 = D#7   ← E♭7
B7 的正对面 = F7
```

## 本篇小结

1. **五度圈**：12 个顶点排成时钟状，**顺时针 1 格 = 上行纯五度（7 半音）**，从 `F` 回到 `C` 恰好闭环。
2. 音名（12 点起顺时针）：**C G D A E B G♭/F♯ D♭ A♭ E♭ B♭ F**。
3. **用途一（调号）**：顺时针步数 = **`♯` 的数量**，逆时针步数 = **`♭` 的数量**；`♯` 按 `F♯ C♯ G♯ D♯ A♯ E♯ B♯` 顺序加，`♭` 按 `B♭ E♭ A♭ D♭ G♭ C♭ F♭` 顺序加。
4. **用途二（进行方向）**：**逆时针 = 强进行（属进行）方向** → 逆时针一格就能找到**副属和弦**。
5. **用途三（图形）**：增三和弦 = **正三角形**（120°）、减七和弦 = **正方形**（90°）、三全音 = **直径**（180°）。**同形状即同和弦型**，记住图形就能找出构成音；**越不稳定的和弦图形越规整**。
6. **用途四**：辅助判断转调方向。
7. **四度圈 = 五度圈的左右镜像**；爵士乐等重视 `2-5-1` 的乐种里，四度圈读起来更顺，但仍以五度圈为主。
