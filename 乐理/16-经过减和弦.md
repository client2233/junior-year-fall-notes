# 16 经过减和弦（Passing Diminished Chord）

> 系列：[[11-属进行]] · [[12-小调中的属和弦]] · [[13-副属和弦]] · [[14-251进行]] · [[15-和弦进行2·乐曲中的运用]] · [[16-经过减和弦]] · [[17-五度圈的使用]] · [[18-三全音代理]] · [[19-下属小和弦]] · [[20-套句与持续低音]]
>
> 这一篇讲**减和弦**。听感上它「情绪不安定、却有停滞的感觉」，很特别。但真正的收获在最后一节：**减三和弦就是属七和弦省略根音的形式** —— 前面几篇的属进行、副属和弦，到这里全都串成一条线。

## 16.1 减和弦的构成音

三种三和弦的间隔对比：

| 三和弦 | 根音 → 3 音 | 3 音 → 5 音 | 根音 → 5 音 |
|---|---|---|---|
| **大三和弦** | 4 半音 | 3 半音 | 7 半音（纯五度） |
| **小三和弦** | 3 半音 | 4 半音 | 7 半音（纯五度） |
| **减三和弦 `dim`** | **3 半音** | **3 半音** | **6 半音（减五度）** |

也就是说，**减三和弦 = 两个小三度叠起来**。因为根音到五音是 6 半音 = **减五度 = 三全音**，所以减三和弦自带[[11-属进行]]里那个「不稳定的音响」。

记号上有两种写法，指的都是同一个和弦：

| 写法 | 强调什么 |
|---|---|
| **`dim`** | 强调「这是**减和弦**」 |
| **`m(♭5)`** | 强调「这是**从某个和弦派生来**的（小三和弦 + 降五音）」 |

讲座说两者**用法没有明确区分**，但本系列**大多用 `dim`**。

> **要点** 减和弦**属于小和弦家族** —— 判据是根音到三音是**小三度**。这和 [[04-顺阶三和弦]]/[[08-和弦的功能]] 里「按三音大小分家族」的规则一致：含小三度的和弦都算小和弦家族。

## 16.2 减七和弦、半减七和弦与重降号

把减三和弦继续往上叠三度，得到三种七和弦：

| 和弦 | 堆叠 | 例子（`F♯` 为根） | 最上方的音 |
|---|---|---|---|
| **`dim`**（减三和弦） | 3 + 3 | F♯ A C | —（只有三个音） |
| **`dim7`**（减七和弦） | 3 + 3 + **3** | F♯ A C **E♭** | 减七度 |
| **`m7(♭5)`**（半减七和弦） | 3 + 3 + **4** | F♯ A C **E** | 小七度 |

- **`dim7`** 的四个音**全部以小三度堆叠** —— 是唯一一种「间距完全均匀」的四音和弦。
- **`m7(♭5)`** 与 `dim7` **只差最上方那个音**（`E♭` vs `E`）。

### 16.2.1 为什么要用重降号

讲座给了一个具体例子：某个减和弦的构成音里出现了 **`B♭♭`**（重降号）。

- **重降号 = 降两个半音**，所以 `B♭♭` 实际就是 `A`。
- 明明可以直接写成 `A`，为什么不写？

原因有两层，**都是为了乐谱更好懂**：

1. **保持谱面上的「三度」形状。** 如果把 `B♭♭` 写成 `A`，那在五线谱上 `G♭` 到 `A` **看起来像二度**，只有这一处和其他位置不一致。用重降号则**所有相邻音看起来都是三度**。
2. **方便演奏。** 谱面上音位置均匀，**手指的排列就跟着均匀**，演奏者一眼就能看出「这是个对称的减和弦」。

讲座说这方面的书写法则要细讲得花很长时间，留到以后。

## 16.3 经过减和弦的用法

先把名字说清楚：**「经过」（passing）说的就是「夹在两个和弦之间经过一下」。**

**使用条件（唯一一条）**：

> 只能用在**根音相距全音**（顺次进行 / **级进**）的两个和弦之间。

- **顺次进行（级进）** = 移动到相邻和弦的进行（例如 `C → D`）。
- **根音跳音移动的进行无法使用经过减和弦。**

**插入方法**：

> 用**以起始和弦上方半音为根音的 `dim`**。

对照表（以 C 大调为例）：

| 原本的进行 | 根音关系 | 插入 | 插入后的根音走向 |
|---|---|---|---|
| `F → G` | 全音 | **`F♯dim`** | F → **F♯** → G（全为半音） |
| `G → Am` | 全音 | **`G♯dim`** | G → **G♯** → A（全为半音） |
| `C → D` | 全音 | **`C♯dim`** | C → **`C♯`** → D（全为半音） |
| `F → B♭` | 纯四度 | ✗ | 不是全音，不能插入 |

所以一句话概括：

> **经过减和弦原本就是「让全音移动的和弦变成顺滑的半音级进」的做法。**

> **补充** 为什么只能用于全音？因为全音之间**正好空出半音的位置** —— 那个半音上的音就是插入点。根音相距半音时中间无位可插；相距三度以上则**中间有多于一个位置**，插入就不再是「经过」而变成「增加过渡」。所以这不是限制，是几何后果。

## 16.4 关键：减和弦就是省略根音的属七和弦

这是这一篇最重要的一段。

以 `F → G` 之间插入的 **`F♯dim`** 为例，看它的构成音：`F♯ A C`。从下往上都是 3 半音。而 **`F♯` 到 `C` 之间正好是 6 半音 —— 三全音。**

- 含三全音的**代表性和弦是属七和弦**（[[11-属进行]]）。
- 那就把 `D7` 拿出来对照：`D7 = D F♯ A C`。
- **`F♯dim = F♯ A C` 正好是 `D7` 去掉根音 `D`。**

而且**三全音完全一样**（都是 `F♯–C`），所以**移动方向也一样**。

于是得到结论：

> **`dim` 就是属七和弦省略根音的形式。**

推论立刻出来：**所有的经过减和弦都可以被对应的属七和弦置换**（反过来也成立）。讲座给了一组例子，并总结成一句：

> **构成音相近的和弦，性质也相近。**

注意 `D7` 在 C 大调里是 [[13-副属和弦]]里的副属和弦（`D7 → G`）—— 所以**经过减和弦和副属和弦是同一批东西的两种外观**。

> **要点** 这条把前面几篇全部接上了：`D7` 的三全音 `F♯–C` → 去掉根音得到 `F♯dim` → `F♯dim` 插在 `F` 与 `G` 之间使根音半音化。**同一个音响，三种用法（属和弦、副属和弦、经过减和弦）。**

## 16.5 变体：`dim7`、半减七、还是三和弦

把上面那个三和弦的 `dim` 升级成七和弦，会有不同效果：

| 形态 | 音响 | 适用性 |
|---|---|---|
| **`dim7`**（减七和弦） | **更加复杂、更加阴暗**；阴暗感、怪诞感更强，可以很强烈地解决到下一个和弦 | 但**音响复杂，可能不适合某些风格** |
| **`m7(♭5)`**（半减七和弦） | 与 `dim7` **只差最上方的音**，因此**与前后和弦的共同音更多**，**旋律更好处理**，音响更自然 | 想过「经过」得顺滑时优先考虑 |
| **三和弦 `dim`** | 音响本身已经够复杂 | **无法判断时直接用三和弦** —— 在以七和弦为主体的进行里也不会有违和感 |

讲座的实际建议：

- **用半减七（`m7(♭5)`）往往能得到更自然的音响**（因为共同音多，旋律好写）。
- **但不是「必须」用哪种形态** —— 无论哪种形态差别都不大，**可以自由选择**。

> **补充** 「共同音多 → 旋律好处理」的原因是：前后和弦的音如果能延续到 `dim` 里，旋律线可以走**共同音**而不必全部跳动。`m7(♭5)` 比 `dim7` 多出的那个**小七度**，通常正好是前后和弦的构成音，所以衔接更顺。

## 16.6 用代码验证

```python
from itertools import combinations

NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
PC = {n: i for i, n in enumerate(NAMES)}

def stack(root, offsets):
    """以 root 为根音，按累计半音偏移堆叠。"""
    return sorted((PC[root] + k) % 12 for k in offsets)

def tritone(pcs):
    pcs = sorted(set(pcs))
    return [(NAMES[a], NAMES[b]) for a, b in combinations(pcs, 2) if (b - a) % 12 == 6]

def names(pcs):
    return [NAMES[p] for p in pcs]

# ---- 三种和弦的间隔 ----
print("大三和弦:", names(stack("C", (0, 4, 7))), "间隔 4+3")
print("小三和弦:", names(stack("C", (0, 3, 7))), "间隔 3+4")
print("减三和弦:", names(stack("C", (0, 3, 6))), "间隔 3+3 -> 根到五音是减五度")
print()

# ---- 关键：dim = 属七和弦去掉根音 ----
for root in ["D", "G", "C", "A"]:
    dom7     = stack(root, (0, 4, 7, 10))       # 属七
    rootless = stack(root, (4, 7, 10))          # 去掉根音
    third    = NAMES[(PC[root] + 4) % 12]       # 大三度音
    dim      = stack(third, (0, 3, 6))          # 以三音为根的减三和弦
    print(f"{root}7      = {names(dom7)}  三全音 {tritone(dom7)}")
    print(f"  去根音  = {names(rootless)}")
    print(f"  {third}dim     = {names(dim)}  三全音 {tritone(dim)}")
    print(f"  → 完全相同: {rootless == dim and tritone(dom7) == tritone(dim)}")
```

输出：

```
大三和弦: ['C', 'E', 'G'] 间隔 4+3
小三和弦: ['C', 'D#', 'G'] 间隔 3+4
减三和弦: ['C', 'D#', 'F#'] 间隔 3+3 -> 根到五音是减五度

D7      = ['C', 'D', 'F#', 'A']  三全音 [('C', 'F#')]
  去根音  = ['C', 'F#', 'A']
  F#dim     = ['C', 'F#', 'A']  三全音 [('C', 'F#')]
  → 完全相同: True
G7      = ['D', 'F', 'G', 'B']  三全音 [('F', 'B')]
  去根音  = ['D', 'F', 'B']
  Bdim     = ['D', 'F', 'B']  三全音 [('F', 'B')]
  → 完全相同: True
...
```

最后验证插入规则：

```python
for a, b in [("F", "G"), ("G", "A"), ("C", "D"), ("D", "E")]:
    ins = NAMES[(PC[a] + 1) % 12]
    print(f"{a} -> {b}: 插入 {ins}dim  =>  {a} {ins} {b} 全是半音")
```

```
F -> G: 插入 F#dim  =>  F F# G 全是半音
G -> A: 插入 G#dim  =>  G G# A 全是半音
C -> D: 插入 C#dim  =>  C C# D 全是半音
D -> E: 插入 D#dim  =>  D D# E 全是半音
```

## 本篇小结

1. **减三和弦 `dim` = 两个小三度叠起来**（3 + 3），根音到五音是**减五度 = 三全音**，所以音响不稳定。
2. 记号有 `dim` 与 `m(♭5)` 两种，指同一个和弦；`dim` 强调「减」，`m(♭5)` 强调「派生」。减和弦**属于小和弦家族**。
3. **`dim7`** 是四个音全按小三度堆叠（3+3+3）；**`m7(♭5)`** 与它只差最上方那个音（小七度 vs 减七度）。
4. **重降号**（`B♭♭ = A`）是为了**保持谱面上「处处都是三度」的形状**，便于阅读与演奏。
5. **经过减和弦**：夹在**根音相距全音**的两个和弦之间，用**起始和弦上方半音的 `dim`**，使根音由全音移动变成**半音级进**。根音跳进的进行**不能用**。
6. **`dim` = 属七和弦省略根音的形式**（`F♯dim` = `D7` 去掉 `D`），三全音与移动方向都相同 —— 所以经过减和弦与[[13-副属和弦]]是同一批东西。
7. 形态可自由选择：想过得顺滑用 **`m7(♭5)`**（共同音多、旋律好写），想更强/更阴暗用 **`dim7`**，**拿不定就用三和弦**。
