# 08 和弦的功能

> 系列：[[01-音名与音程]] · [[02-排列间隔与大调音阶]] · [[03-自然小调音阶·平行调与同主调]] · [[04-顺阶三和弦]] · [[05-顺阶七和弦]] · [[06-和弦进行]] · [[07-和弦转位]] · [[09-代理和弦与功能的扩展]] · [[10-速查·和弦记号与功能表]]
>
> [[06-和弦进行]] 把和弦的排列当作例子罗列了一遍，**刻意跳过了「为什么这些顺序听起来自然」**。这一篇补上这一层：顺阶和弦带有**功能**（function），功能决定了和弦之间「天生倾向于怎么接」。

## 8.1 从「起立—敬礼」说起

看一个最简单的进行：

```
C  –  G7  –  C
```

这是大家小学时就听过、像上课提示音一样的进行。它对应一套动作：

| 和弦 | 动作 | 状态 |
|---|---|---|
| `C` | 起立 | 稳定 |
| `G7` | 敬礼 | 紧张（身体绷着） |
| `C` | 回到起立 | 稳定 |

也就是说，**这套动作与和弦的功能完全对应**。音乐中经常出现这种「紧张与稳定」的关系 —— 很少有曲子中断在听上去还有后续的和弦上，大部分曲子会终止在 `C` 这样的稳定和弦上。

## 8.2 三种功能

| 功能 | 中文名 | 英文 | 状态 | C 大调中 |
|---|---|---|---|---|
| **T** | 主和弦 | Tonic | 稳定 | `C` / `Cmaj7` |
| **D** | 属和弦 | Dominant | 紧张 | `G` / `G7` |
| **SD** | 下属和弦 | Subdominant | 半稳定半紧张 | `F` / `Fmaj7` |

**主和弦 / 属和弦 / 下属和弦**这种叫法，在乐理上称作**和弦的功能**（function）。

### 8.2.1 主和弦 T（稳定的）

- 听感稳定，是所有进行最终要落回的地方。
- `C` 是主和弦，`Cmaj7` 同样是主和弦 —— **功能与三和弦 / 七和弦无关**。

### 8.2.2 属和弦 D（紧张的）

- 听感紧张，总想要回到主和弦。
- 一听到 `G7` 就想要回到 `C`，所以 `G7` 像是「支配者」 —— Dominant 本身就有「支配」的意思。

### 8.2.3 下属和弦 SD（中间状态）

- **半稳定、半紧张。** 往好的说是万能，往差的说是灰色地带。
- 它有一定的稳定感，同时也具有**比属和弦稍差的「回到主和弦」的能力**。
- 对比听：`SD → T` 的回复感比 `D → T` 要弱一些。

**下属和弦回到主和弦的走向**（`F → C`）也叫**变格终止**。因为赞美诗的结尾唱「阿门」时用的正是这个进行，所以俗称**阿门终止**。好好利用的话，`SD → T` 会是非常华丽的效果。

> **要点** 属和弦与下属和弦的构成音完全不同，所以两者**不能随心所欲互换**。但一定要记住：**从 `F` 也能回到 `C`。**

## 8.3 功能的移动规则

把三种功能看成三种姿势：

| 功能 | 姿势 | 可以走向 |
|---|---|---|
| **T**（稳定） | 直立站着 | → D 或 → SD（稳定状态可以变换到任意姿势） |
| **D**（紧张） | 敬礼 | → T（紧张状态想要回到稳定） |
| **SD**（半稳定半紧张） | 走路 | → T 或 → D（既能回稳定，也能到紧张） |

下属和弦也因此被称为**具有动力的和弦** —— 既不是站着也不是敬礼，而是走路；一直站着有时也会想走走。

## 8.4 终止（Cadence）

**这种和弦进行的最小单位称作终止**（cadence）。运用终止的概念可以进一步分析和弦进行。

回到稳定主和弦的几种基本走法：

| 走向 | 名称 / 说明 |
|---|---|
| **D → T** | 完全终止 —— 最典型的「敬礼之后起立」 |
| **SD → T** | 变格终止（阿门终止） |
| **SD → D → T** | 讲座列为第三类终止 |
| **T → SD → D → T** | 与上一条只差最前面的一个 `T` |

### 8.4.1 例外：D → SD

**属 → 下属（`D → SD`）在古典音乐理论中是不允许的**，但在**流行与爵士理论中例外地可行**，讲座列为第四类终止。

用人物的动作来比：这就像**敬礼之后不直起腰，直接开始走路** —— 能感觉到这有些反常。也就是说，**敬礼之后必须要回到直立**。

> **要点** 这类规则是**古典乐的礼仪**。最近的音乐有很多打破了这些礼仪 —— 既然现在的音乐怎么折腾都可以，那学这些走向还有意义吗？
>
> 有。**古典音乐理论是对「人认为美妙的音响」的归纳。** 守住它，能做出非常爽快的音乐；但反过来 ——
>
> - **太拘泥于规则**，写出来的东西没什么新意；
> - **太标新立异**，也会不好听。
>
> 这条平衡感比规则本身更重要。

> **补充** 「功能」的概念在分析上等价于把 [[06-和弦进行]] 的数字编号分成三个组：`T = {1, 3, 6}`、`SD = {2, 4}`、`D = {5, 7}`（依据见 [[09-代理和弦与功能的扩展]]）。于是各种「进行」只要把数字换成功能号，结构立刻显形：
>
> - 1625 = `T(1) – T(6) – SD(2) – D(5)` → 落到 `D` 上，所以强烈要求回到 `T`
> - 卡农 1-5-6-3-4-1-2-5 = `T – D – T – T – SD – T – SD – D`，整体是「稳定 ↔ 紧张」的反复摆荡
> - 251（`Dm – G – C`）= `SD – D – T`，最标准的终止型
>
> 这套「功能 → 数字 → 和弦」的三层映射，是把乐理变成可计算对象的关键一步。

---

## 本篇小结

1. 顺阶和弦带有**功能**：**主 T（稳定）**、**属 D（紧张）**、**下属 SD（半稳定半紧张）**。C 大调对应 `C`、`G`、`F`。
2. 移动规则：`T → D / SD`，`D → T`，`SD → T / D`。
3. **变格终止（阿门终止）**= `SD → T`；`D → T` 是完全终止。
4. **终止**（cadence）是和弦进行的最小单位。
5. `D → SD` 在古典理论中禁止，在流行 / 爵士中可行 —— **规则是对「好听」的归纳，不是不可违反的律法。**
