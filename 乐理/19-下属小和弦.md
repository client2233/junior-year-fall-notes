# 19 下属小和弦（Subdominant Minor Chord）

> 系列：[[11-属进行]] · [[12-小调中的属和弦]] · [[13-副属和弦]] · [[14-251进行]] · [[15-和弦进行2·乐曲中的运用]] · [[16-经过减和弦]] · [[17-五度圈的使用]] · [[18-三全音代理]] · [[19-下属小和弦]] · [[20-套句与持续低音]]
>
> 应用篇里**绝大多数的技巧都围着「属」转**（副属和弦、三全音代理和弦……）。这一篇反其道，讲**下属**。核心问题是：**同样要落到主和弦上，为什么「下属 → 主」听起来比「属 → 主」弱？** 答案拆成两条 —— 一条关于低音，一条关于半音邻音。两条各有各的补法。

## 19.1 复习：下属 → 主 为什么较弱

在 C 大调里下属是 **`F`**。讲座在基础篇（[[06-和弦进行]] / [[08-和弦的功能]]）已经讲过 `F` 可以解决到主和弦 `C`。

- 听感上可以明显听出：**「下属 → 主」比「属 → 主」要弱。**
- 原因有好几个，讲座挑出**两个主要的原因**，分别在下面两节处理。

## 19.2 原因一：低音不构成强进行

第一个原因落在**根音的进行**上。用 [[11-属进行]] 的判据检查：

| 进行 | 低音走向 | 半音数 | 是强进行吗 |
|---|---|---|---|
| **`G → C`**（属 → 主） | 上行纯四度 | +5 | ✓ |
| **`F → C`**（下属 → 主） | **下行纯四度** | **−5** | **✗** |

> 讲座的说法：「**能强进行到 `C` 的，是 `G` 或 `G7` 的特权。**」

### 19.2.1 补法：把低音移到 `G`

弱点清楚了，补法就很简单 —— **只要把低音从 `F` 移到 `G`**：

- 低音变成 `G → C`，**成为强进行** ✓
- 上方继续弹 `F` 和弦，于是**保留下属和弦的音响** ✓

这个和弦就是**属系分数和弦**（图上看有点像**转位和弦**，讲座也这么说）。

**定义**：

> **属系分数和弦 = 低音构成强进行的下属和弦。**（共有 4 类。）

性质：**原本是下属和弦**，但因为**低音可构成强进行**，所以**可以当作属功能使用**。

**用法**：直接放到 `2-5-1` 里 —— **原本放 `G7` 这种属功能和弦的位置，可以改成它**（详见 [[14-251进行]]）。

**代价**：

- 因为**构成音不同**，需要注意**与旋律的配合**。
- **进行感最强的仍然是 `G7`。**

**最典型的写法是 `F/G`**（读作「`F` on `G`」）：上方保持 `F` 和弦，低音换成 `G`。讲座用的就是这个例子 —— 幻灯片把 `F → C` 标为「**不是强进行**」，把 `F/G → C` 标为「**强进行**」，并注明这条强进行正是由**属系分数和弦（`F/G`）**形成的。

它在 [[15-和弦进行2·乐曲中的运用]] 里已经以「替代 `G7`、没有三全音、音响更柔和」的形式先出现过一次。

## 19.3 原因二：与主和弦只有一个半音邻音

第二个原因落在**构成音**上。先回顾一条基础篇里的结论：

> **与主和弦半音相邻的音越多，和声越不稳定。**

把 `F` 与 `C` 的构成音并排列出：

| `F`（F A C） | 最近的 `C` 和弦音（C E G） | 距离 |
|---|---|---|
| **F** | **E** | **半音** ✓ |
| A | G | 全音 ✗ |
| C | C | 共同音 |

结果：**只有 `F` 一个音是不稳定的，其余都稳定** —— 所以 `F → C` 的**紧张度不够**，进行感自然弱。

### 19.3.1 补法：把下属和弦的三音降低半音

让第二个音也变成半音邻音 —— **把 `A` 改成 `A♭`**：

| `Fm`（F A♭ C） | 最近的 `C` 和弦音 | 距离 |
|---|---|---|
| **F** | **E** | **半音** ✓ |
| **A♭** | **G** | **半音** ✓ |
| C | C | 共同音 |

- `A♭` 距离 `C` 和弦里的 `G` **只有半音** → 所以 **`Fm` 比 `F` 更有向 `C` 进行的动力**。
- 注意 **`A♭` 比 `A` 距离 `G` 更近**，所以更容易解决到 `C`。

这种和弦就叫**下属小和弦** —— 名字很好记：**把下属和弦的三音降低半音**。

**听感**（讲座的描述）：

- 有一种**谜之温和**的感觉，甚至可以说是**神圣**的感觉。
- 「虽然是小和弦，**音响却很温和**，挺有趣的」。

## 19.4 强度排序

讲座把学过的和弦整理到一张表上，**越靠右，向主和弦的进行就越强**：

| ← 弱 | | | 强 → |
|---|---|---|---|
| **下属和弦** `F` | **属系分数和弦** `F/G` | **属和弦** `G7` | |

- **属系分数和弦**虽然被当作属功能使用，但它**原本是下属和弦**，因此**没有导音、也没有三全音**（这两个正是 [[11-属进行]] 里属和弦紧张的来源）。
- 所以它到主和弦的**进行强度介于「下属」与「属」之间**。

讲座还并排比较了**四种终止形**（下属直接到主、经属系分数和弦到主、经属到主、下属小和弦到主等），并强调：**这张表只是一个大概，具体强度会随曲调与和弦走向变化。**

> **要点** 这张表把「功能」从二值变成了**连续量**：下属、属系分数和弦、属，都在做「落到主上」这一件事，只是**推力大小不同**。选哪个取决于你要多强的终止感。

## 19.5 下属小和弦的其他形态

`Fm` 只是**最基础的那一个**。讲座给了一张表列出下属小和弦的**两个构成条件**，然后去找符合的和弦。

> **补充** 表是图示，这里按讲座随后给出的构造反推，两个条件应当是：
> 1. **含有 `A♭`** —— 它是主和弦五音 `G` 的上方半音，提供向主的牵引力；
> 2. **与 `Fm` 有共同音** —— 这样才能保留下属的音响。

按这两条找出来的和弦**非常多**：

| 和弦 | 构成音 | 与 `Fm` 的共同音 | 由什么构造 |
|---|---|---|---|
| **`Fm`** | F A♭ C | —（基准） | 把 `F` 的三音降半音 |
| **`Fm7`** | F A♭ C E♭ | F A♭ C | 直接加小七度 |
| **`Fm6`** | F A♭ C D | F A♭ C | 加大六度 |
| **`Fm7(♭5)`** | F A♭ C♭ E♭ | F A♭ | 再加降五音 |
| **`A♭6`** | A♭ C E♭ F | A♭ C | **`A♭` 和弦上方叠加一个大六度音** |
| **`D♭△7`** | D♭ F A♭ C | F A♭ | **把根音降到 `D♭` 形成 `D♭` 和弦，上方叠加大七度** |

讲座对这堆和弦的态度很实在：

> **「不要被复杂的和弦名迷惑」—— 要做的只是把下属和弦的 `A` 改成 `A♭`。**
>
> **「把这些全记住也太难了，开始用起来就好。」**

其中 **`m7(♭5)`** 是**基础篇以来首次出现**的一个形态（此前只在 [[16-经过减和弦]] 里作为减和弦家族的一员出现过）。讲座说：**作为下属小和弦使用的情况是存在的**。

**用法与听感**：

- 除了接回主和弦，还能用在**很多别的场合**（例如**转调**）。
- **在曲子着重强调的地方**用下属小和弦，效果最好。
- 但要注意：**同属下属小和弦，也有很多音响不同的和弦 —— 它没有完全统一的用法，要好好区分开来使用。**

> **补充** 这段「形态很多、用法不统一」正是下属小和弦难用的原因：它不像 `G7` 那样有唯一的标准形式。**先把 `Fm` 用熟**，其他形态在具体乐句里逐个认识，比背表有效。

## 19.6 用代码验证两条结论

```python
NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
PC = {n: i for i, n in enumerate(NAMES)} | {"Ab": 8, "Bb": 10, "Eb": 3, "Db": 1, "Cb": 11}

def notes(*ns):
    return sorted(PC[n] % 12 for n in ns)

def strong(a, b):
    """强进行：低音上行纯四度（+5 半音）。"""
    return (PC[b] - PC[a]) % 12 == 5

print("=== 结论一：低音 ===")
print("F  -> C 低音:", (PC['C'] - PC['F']) % 12 - 12, "半音  强进行?", strong('F', 'C'))
print("F/G-> C 低音:", (PC['C'] - PC['G']) % 12 - 12, "半音  强进行?", strong('G', 'C'))

print()
print("=== 结论二：半音邻音 ===")
C_CHORD = notes("C", "E", "G")

def neighbours(chord_notes):
    out = []
    for c in chord_notes:
        for t in C_CHORD:
            d = (t - c + 6) % 12 - 6
            if abs(d) == 1:
                out.append((NAMES[c], NAMES[t]))
    return out

for label, ch in [("F  (F A C)", notes("F", "A", "C")),
                  ("Fm (F Ab C)", notes("F", "Ab", "C"))]:
    n = neighbours(ch)
    print(f"{label:<14} 与 C 和弦的半音邻音: {n}   共 {len(n)} 个")
```

输出：

```
=== 结论一：低音 ===
F  -> C 低音: -5 半音  强进行? False
F/G-> C 低音: -7 半音  强进行? True

=== 结论二：半音邻音 ===
F  (F A C)     与 C 和弦的半音邻音: [('F', 'E')]          共 1 个
Fm (F Ab C)    与 C 和弦的半音邻音: [('F', 'E'), ('G#', 'G')]  共 2 个
```

两条都坐实了：**`F → C` 既不是强进行（低音 −5），又只有 1 个半音邻音**；`Fm` 把半音邻音补到 **2 个**，`F/G` 把低音换成 **−7（下行纯五度 = 强进行）**。

> 输出里的 `G#` 在谱面上应写作 **`A♭`** —— 程序只算音高类，不管音级写法。

## 本篇小结

1. **下属 → 主**比**属 → 主**弱，两个主要原因：**低音不是强进行**（`F → C` 是下行纯四度 −5）、**与主和弦只有 1 个半音邻音**。
2. **补法一 → 属系分数和弦**：把低音移到 `G`（写成 `F/G`），低音成为强进行，上方保留 `F` 的音响。**原为下属、因低音而能当属功能用**，共 4 类（见 [[15-和弦进行2·乐曲中的运用]] 的预告）。
3. **补法二 → 下属小和弦**：把下属和弦的**三音降低半音**（`F → Fm`），使 `A♭` 与主和弦的 `G` 构成第二个半音邻音，向主进行更有动力。
4. **强度排序**：`下属` ＜ `属系分数和弦` ＜ `属`。属系分数和弦没有导音与三全音，所以强度居中；此表只是大概。
5. **下属小和弦形态很多**（`Fm`、`Fm7`、`Fm6`、`Fm7(♭5)`、`A♭6`、`D♭△7`…），构成条件是**含 `A♭`** 且**与 `Fm` 有共同音**；**不必全记**，先把 `Fm` 用熟。
6. **用法**：接回主和弦、转调、在**着重强调处**使用；但同类和弦音响差异大，**没有统一用法，要区分使用**。
