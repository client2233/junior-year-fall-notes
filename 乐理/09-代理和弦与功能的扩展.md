# 09 代理和弦与功能的扩展

> 系列：[[01-音名与音程]] · [[02-排列间隔与大调音阶]] · [[03-自然小调音阶·平行调与同主调]] · [[04-顺阶三和弦]] · [[05-顺阶七和弦]] · [[06-和弦进行]] · [[07-和弦转位]] · [[08-和弦的功能]] · [[10-速查·和弦记号与功能表]]
>
> [[08-和弦的功能]] 只给 `C`、`G`、`F` 三个和弦定了功能。这一篇把剩下四个和弦也归好类 —— 归类的依据、以及这套分类的**局限**，是这一篇真正的内容。

## 9.1 主要 3 和弦

[[08-和弦的功能]] 只说明了 7 个顺阶和弦中的 `C`、`G`、`F` 三个：

| 和弦 | 功能 |
|---|---|
| `C` | 稳定的**主**和弦 |
| `G` | 紧张的**属**和弦 |
| `F` | 中间性质的**下属**和弦 |

这三个和弦称作**主要 3 和弦 / 正和弦**。它们是最基本的三个。

剩余四个和弦是：**`Dm`、`Em`、`Am`、`Bm(b5)`**。

> **要点** 这四个和弦**都可以归入主 / 属 / 下属三种功能之一**。功能**只有 3 种** —— 只有 3 种的话记起来就方便多了。也就是说，**小和弦同样有「稳定」和「紧张」之分**。

## 9.2 归类依据：共同音

把每个小和弦拿去和「主要 3 和弦」比对，**看它们共享几个构成音**：

| 小和弦 | 构成音 | 比对对象 | 共同音 | 共同音数 | 归属 |
|---|---|---|---|---|---|
| `Am` | A C E | `C` = C E G | **C、E** | 2 | **主功能 T** |
| `Em` | E G B | `C` = C E G | **E、G** | 2 | **主功能 T** |
| `Dm` | D F A | `F` = F A C | **F、A** | 2 | **下属功能 SD** |
| `Bm(b5)` | B D F | `G` = G B D | **B、D** | 2 | **属功能 D** |

**相邻的两个和弦有两个共同音** —— 这就是判据。用线把共同音连起来，关系一目了然。

> **要点** **共同音多就是一类。** 由此得到完整的功能分组：

| 功能 | 和弦 |
|---|---|
| **主 T** | `C`、`Am`、`Em` |
| **下属 SD** | `F`、`Dm` |
| **属 D** | `G`、`Bm(b5)` |

七和弦同理：`Cmaj7`、`Am7`、`Em7` 归主，`Fmaj7`、`Dm7` 归下属，`G7`、`Bm7(b5)` 归属。

## 9.3 代理和弦（副和弦）

**可以替代主要 3 和弦、在和弦走向大致不变的情况下替换使用的和弦，叫代理和弦**（讲座中亦称「副和弦」）。

**推荐用法**：

1. **先用主要 3 和弦写**（`C – G – C` 这类），骨架清晰；
2. **再把其中一部分和弦换成代理和弦**，得到更好的音响。

这样写出来的曲子**和弦变化变多、色彩更丰富，小和弦的哀愁也很配**。练熟之后，也可以直接带着代理和弦写。

例：把上面的「起立—敬礼」进行 `C – G7 – C` 里的主和弦换成 `Am` 等，就能在和弦走向大致不变的前提下改变色彩。

## 9.4 这套分类的局限

用代理和弦并不总是成功的。**同样是主功能，有些地方换成代理和弦听起来很好，有些地方就不行。**

原因有两条：

### 9.4.1 主功能内部也有强弱

即使都是主功能，稳定性也有差别。把原来最后落回的 `C` 换成 `Em`，就没有「真正的主和弦」感了 —— 因为 `Em` 的稳定感弱于 `C`。

### 9.4.2 分类方法本身有边界情况

用「共同音」分类时会遇到模棱两可的和弦，典型的就是 **`Em`**：

- `Em`（E G B）与主和弦 `C` 有两个共同音（E、G）→ 归主功能；
- 但 `Em` 与属和弦 `G`（G B D）也有两个共同音（G、B）→ **`Em` 同样有属和弦的味道**。

讲座把 `Em` 归入主功能的理由是：

1. **优先考虑 `E`（mi）** —— 它是决定主和弦亮度的关键音；
2. 若把 `Em` 归到属功能，**主功能和弦就比属功能的少了**，分组失衡。

> **要点** 由以上两条得出的结论：**同一功能的和弦未必能完美替代；反过来，不同功能的和弦有时反而更符合当前的需要。**
>
> 所谓「同功能」在实际使用中只能当参考 —— **只要听上去没问题就行了**。

### 9.4.3 还要注意旋律

使用代理和弦会**改变和弦的构成音**，因此可能出现**与旋律不兼容**的问题。

最终还是得**实际用用看**才能判断。

> **补充** 这套「按共同音分组」的做法，与和弦替代的经典判据（三度替换 / 三全音替换 / 共同音替换）是同一件事的初等版本：
>
> - `C ↔ Am` 共享 C、E（三度替换）；
> - `C ↔ Em` 共享 E、G（三度替换）；
> - `F ↔ Dm` 共享 F、A（三度替换）；
> - `G ↔ Bm(b5)` 共享 B、D（三度替换）。
>
> 也就是说，本讲座的分组**本质上就是「相差一个三度的和弦可以互相替代」**。这条规律可以直接用集合运算验证：
>
> ```python
> TRIAD = {"major": [0, 4, 7], "minor": [0, 3, 7], "diminished": [0, 3, 6]}
> PC = {"C": 0, "D": 2, "E": 4, "F": 5, "G": 7, "A": 9, "B": 11}
>
> def pcs(root: str, quality: str) -> set[int]:
>     return {(PC[root] + i) % 12 for i in TRIAD[quality]}
>
> def shared(a: set[int], b: set[int]) -> int:
>     return len(a & b)
>
> pcs("C", "major") & pcs("A", "minor")   # {0, 4} → 共同音 2 个
> ```
>
> 把七个顺阶和弦两两求共同音数，得到的等价类正好就是 9.2 节那张分组表 —— 换句话说，**功能分组在程序里就是一次集合相似度的聚类**。
>
> 另外，`Em` 归属的模棱两可并非讲座的疏漏，而是这类基于共同音的聚类方法固有的问题：**`Em` 与 `C`、`G` 各共享两个音，是一个真正的边界点。** 遇到这种和弦时，判断依据只能是上下文，这也正是 9.4 节结论「实际听」的原因。

---

## 本篇小结

1. **主要 3 和弦（正和弦）**= `C`（主）、`G`（属）、`F`（下属）。
2. 其余 `Dm`、`Em`、`Am`、`Bm(b5)` **全部可以归入主 / 属 / 下属三种功能**，判据是**共同音多的归为一类**。
3. 完整分组：**主 T = {C, Am, Em}**，**下属 SD = {F, Dm}**，**属 D = {G, Bm(b5)}**。
4. **代理和弦**：在走向大致不变的前提下替换主要 3 和弦的和弦。推荐先写主要 3 和弦、再局部替换。
5. **局限**：主功能内部有强弱；分类本身存在边界情况（`Em` 既像主也像属）；替换会改变构成音，可能与旋律冲突 —— **最终以听感为准。**
