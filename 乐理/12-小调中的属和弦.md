# 12 小调中的属和弦

> 系列：[[11-属进行]] · [[12-小调中的属和弦]] · [[13-副属和弦]] · [[14-251进行]] · [[15-和弦进行2·乐曲中的运用]] · [[16-经过减和弦]] · [[17-五度圈的使用]] · [[18-三全音代理]] · [[19-下属小和弦]] · [[20-套句与持续低音]]
>
> 上一篇把「属 → 主」在**大调**里讲透了。这一篇把它搬到小调 —— 结果发现小调里**根本没有属和弦**，得临时造一个。这个「临时造」的动作，后面会膨胀成 [[13-副属和弦]] 整篇的内容。

## 12.1 小调音阶的和弦功能

### 12.1.1 从大调平移过来

- C 大调音阶 = 从 C 开始按 `全 全 半 全 全 全 半` 排列。
- 从 G 开始按**同样的间隔**排上去，得到的也全是白键 → 那就是 G 大调。
- **排列间隔相同，组成的音阶就都是大调音阶**（见 [[02-排列间隔与大调音阶]]）。
- 把 C 大调的顺序**从第六个音 A 开始**往上排 → **A 自然小调**（见 [[03-自然小调音阶·平行调与同主调]]）。
- A 自然小调与 C 大调互为**平行调**。

因此 A 自然小调的顺阶和弦，和 C 大调**完全是同一批**，只是顺序换了：

| 级数 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| **C 大调** 顺阶 | C | Dm | Em | F | G | Am | Bm(♭5) |
| **A 自然小调** 顺阶 | Am | Bm(♭5) | C | Dm | Em | F | G |

### 12.1.2 和弦相同，功能不同

虽然和弦集合一模一样，但**功能（T / SD / D）跟着主音走**：

| 和弦 | 功能 |
|---|---|
| **Am** | **T**（主） |
| **Dm** | **SD**（下属） |
| **Em** | **D**（属） |

这三个是 A 自然小调的**主要三和弦（正三和弦）**。其余四个（Bm(♭5)、C、F、G）的功能，用与 C 大调**完全相同的方法**判定 —— 看它与主要三和弦的共同音（见 [[09-代理和弦与功能的扩展]]）。讲座提到：**也有些乐理书会把 `F` 归到下属**。

功能的判定方法本身与大小调无关，拓展到七和弦时也不改变。

> **要点** 判断小调功能时不要重新背表：**先定主和弦，再取它上下五度的两个和弦**（Am → Dm、Em），剩下四个按共同音归类。这与大调的流程完全一致，只是出发点从 C 挪到了 Am。

> **补充** 顺阶和弦表随主音整体平移，而功能划分跟着「谁是主」走。所以同一个 F 和弦，在 C 大调里是 IV（SD），在 A 自然小调里要靠共同音重新归类 —— 这正是 `F` 在不同教材里归类不一致的原因。

### 12.1.3 两个调的界限是模糊的

A 自然小调与 C 大调共用同一批和弦，所以：

- 在 **C 大调**的曲子里使用 A 自然小调的功能，**并无大碍**；反过来也一样。
- **偶尔用小调的功能，能给曲子增加起伏**，让它更丰富。

讲座把这个过程比作「上司换了一个，职场的氛围就变了」—— 和弦没动，功能的意义变了。

## 12.2 小调的属和弦出了问题

### 12.2.1 问题：Em 不是合格的属

回头看 A 自然小调的主要三和弦里的属 —— 它是 **Em**，一个**小三和弦**。

按 [[11-属进行]] 的定义，属和弦要「有紧张感、倾向于移动到主和弦」。而 Em 缺两样东西：

| 缺什么 | 具体 |
|---|---|
| **导音** | Em 里的 G 在 A 上方**全音**处，不是半音；没有「半音下方被主音吸引」的牵引力 |
| **三全音** | `Em7 = E G B D` 里**找不到任何一对相差 6 半音的音** |

讲座特别强调：**三全音带来的混浊音响，对属和弦的紧张度影响很大**。

### 12.2.2 解法：把 G 升高半音

一个改动同时解决两个问题 —— **把 G 改成 G♯**：

| 得到什么 | 说明 |
|---|---|
| **导音** | G♯ 正好落在主音 A 的**下方半音**，具备导音功能 |
| **三全音** | `E7 = E G♯ B D` 中，**G♯–D 相差 6 半音**，三全音出现了 |

于是 `Em → E`、`Em7 → E7`。听感对比：

- **Em**：感觉过于稳定，紧张感似乎不太够。
- **E**：显得有些幽暗，**很想回到 Am**。

讲座用了一组谱例 `Am | G | F | E`，把 `E` 框红强调。

> **要点** 小调里的「属」不是音阶自带的那一个（v = Em），而是**临时借用的大三和弦 V（E / E7）**。「小调中的属和弦」这个标题指的就是这个借来的和弦。

## 12.3 三种小调音阶

为了让 G♯「名正言顺」地进入音阶，产生了另外两种小调音阶：

| 名称 | 相对自然小调改了什么 | A 上的音 |
|---|---|---|
| **自然小调**（ナチュラル） | 基准 | A B C D E F G |
| **和声小调**（ハーモニック） | **第 7 音升高半音** | A B C D E F **G♯** |
| **旋律小调**（メロディック） | **第 6、7 音都升高半音** | A B C D E F♯ **G♯** |

三者的取舍：

| 音阶 | 优点 | 代价 |
|---|---|---|
| 自然小调 | 听上去「很正」 | 属和弦里**没有导音**，也没有三全音 |
| 和声小调 | **具备导音**，属和弦成立 | F 与 G♯ 之间出现**增二度**，唱奏较难 |
| 旋律小调 | 没有增音程，**唱奏简单** | 听感**有时过于明朗**，不太像小调 |

> **术语** 日语叫「和声的短音阶」，中文通常叫**和声小音阶**；旋律小调同理。这里指的是**上行**时升高第 6 音的形式。

实际怎么用 —— 讲座给的答案很干脆：

> 基本上常用**自然小调**；**写到属和弦的部分的时候，临时变为和声小调或旋律小调。**

也就是说音阶可以在**一首曲子的中途临时更换**，因为两者都只是为解决「属和弦缺导音 / 缺三全音」这个问题而存在的。

> **补充** 音阶与和弦是同一件事的两种读法：把 G 升半音，既改了音阶（自然 → 和声），也改了和弦（Em → E）。**先有「想要一个像样的属」这个需求，音阶才被改** —— 顺序不要记反。

### 12.3.1 用代码验证一遍

```python
from itertools import combinations

NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
NAT_MINOR = [2, 1, 2, 2, 1, 2, 2]        # 自然小调：全 半 全 全 半 全 全

def scale(root, steps):
    out, acc = [], root
    for s in steps:
        out.append(acc % 12)
        acc += s
    return out

def tritone(pcs):
    """相差 6 半音的音对。"""
    return [(a, b) for a, b in combinations(sorted(pcs), 2) if (b - a) % 12 == 6]

nat = scale(9, NAT_MINOR)                       # 9 = A
har = nat[:-1] + [(nat[-1] + 1) % 12]            # 第 7 音 +1
mel = har[:-2] + [(har[-2] + 1) % 12, har[-1]]   # 第 6、7 音 +1

for label, sc in (("自然小调", nat), ("和声小调", har), ("旋律小调", mel)):
    print(f"{label}: {' '.join(NAMES[p] for p in sc)}")

print("Em7 三全音:", tritone((4, 7, 11, 2)))     # []       没有
print("E7  三全音:", tritone((4, 8, 11, 2)))     # [(2, 8)]  D–G#
```

输出：

```
自然小调: A B C D E F G
和声小调: A B C D E F G#
旋律小调: A B C D E F# G#
Em7 三全音: []
E7  三全音: [(2, 8)]
```

再把 A 自然小调的七个顺阶三和弦列一遍，确认与 C 大调是同一批：

```python
TRIAD = ["Am", "Bm(♭5)", "C", "Dm", "Em", "F", "G"]
for i in range(7):
    pcs = sorted({nat[(i + k) % 7] for k in (0, 2, 4)})
    print(f"{i + 1} {TRIAD[i]:<9} {' '.join(NAMES[p] for p in pcs)}")
```

```
1 Am        A C E
2 Bm(♭5)    B D F
3 C         C E G
4 Dm        D F A
5 Em        E G B
6 F         F A C
7 G         G B D
```

## 本篇小结

1. 小调音阶由大调音阶**从第六个音开始排**得到；两者的顺阶和弦是**同一批**，只是顺序和功能划分不同。
2. A 自然小调的**主要三和弦**：`Am = T`、`Dm = SD`、`Em = D`。其余和弦按共同音归类。
3. 小调与平行大调的**功能界限模糊**，可以混用，用来增加起伏。
4. 自然小调的属 `Em` **既没有导音、也没有三全音**，作为属和弦不合格。
5. 把 **G 升半音**同时解决两个问题 → `Em → E`、`Em7 → E7`，小调的属就此成立。
6. 为此产生**和声小调**（第 7 音升，代价是增二度）与**旋律小调**（第 6、7 音升，代价是过分明朗）。
7. 实用做法：**常规用自然小调，写到属和弦处临时切换**。
