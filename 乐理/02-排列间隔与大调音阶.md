# 02 排列间隔与大调音阶

> 系列：[[01-音名与音程]] · [[03-自然小调音阶·平行调与同主调]] · [[04-顺阶三和弦]] · [[05-顺阶七和弦]] · [[06-和弦进行]] · [[07-和弦转位]] · [[08-和弦的功能]] · [[09-代理和弦与功能的扩展]] · [[10-速查·和弦记号与功能表]]
>
> [[01-音名与音程]] 只讲了 `Do-Re`、`Mi-Fa` 两组音的全音半音关系。这一篇把它推广到完整七个音，得到**排列间隔**；再用同一间隔从别的音出发，就得到**音阶**。

## 2.1 排列间隔（Interval）

把 `do-re-mi-fa-sol-la-si` 相邻两音之间的距离逐个判断一遍：

| 相邻音组 | 键盘上的关系 | 全音 / 半音 |
|---|---|---|
| `do–re`（C–D） | 中间夹一个琴键 | 全音 |
| `re–mi`（D–E） | 中间夹一个琴键 | 全音 |
| `mi–fa`（E–F） | 紧挨着 | 半音 |
| `fa–sol`（F–G） | 中间夹一个琴键 | 全音 |
| `sol–la`（G–A） | 中间夹一个琴键 | 全音 |
| `la–si`（A–B） | 中间夹一个琴键 | 全音 |
| `si–do`（B–C） | 紧挨着 | 半音 |

从最低的 `do` 往上读，得到的串是：

```
全 全 半 全 全 全 半
```

这个「相邻音之间是全音还是半音」的排列，就叫**排列间隔**。

> **要点** `do-re-mi-fa-sol-la-si` 的排列间隔是 **全全半全全全半**。被问到就答这个，这是整门讲座唯一需要背死的字符串 —— 大调音阶、顺阶和弦全都由它长出来。

## 2.2 音阶（Scale）

用「全全半全全全半」这组间隔，**从 do 以外的音开始往上排**，会得到什么？

### 2.2.1 从 `fa`（F）开始

| 步骤 | 间隔 | 结果 |
|---|---|---|
| `fa`(F) | 全音 | `sol`(G) |
| `sol`(G) | 全音 | `la`(A) |
| `la`(A) | 半音 | `降si`(Bb) ← 出现黑键 |
| `降si`(Bb) | 全音 | `do`(C) |
| `do`(C) | 全音 | `re`(D) |
| `re`(D) | 全音 | `mi`(E) |
| `mi`(E) | 半音 | `fa`(F) ← 回到起点 |

得到 `fa-sol-la-降si-do-re-mi-fa`，即 **F G A Bb C D E F**。含一个黑键。

### 2.2.2 从 `sol`（G）开始

同样的算法得到 **G A B C D E F# G**，也是一个黑键，只是位置从前面的 Bb 挪到了 F#。

### 2.2.3 从黑键开始

从 `降re`（Db）开始，得到 **Db Eb F Gb Ab Bb C Db**，这次有五个黑键。

> **要点** **起始音不同，音阶里包含的黑键就不同** —— 这是全部「调号」问题的根源。但听感上它们都近似 `do-re-mi-fa-sol-la-si`，因为**相邻音的间隔完全一样**，只是整体高低平移了。

### 2.2.4 变调

上面这个现象就是**变调**（transpose，唱的时候叫「升调 / 降调」）：**不改变曲子的听感，只改变整体音高**。K 歌时按「+2 / −1」按钮做的事情，就是给每个音加上同一个半音数。

## 2.3 大调音阶（Major Scale）

**用固定间隔排出来的一组音，就叫音阶**（Scale）。其中用「全全半全全全半」排出来的那一种，叫**大调音阶**。

从 C 开始的大调音阶（`do-re-mi-fa-sol-la-si-do`）称为 **C 大调音阶**。

日式说法里：`C` 读作 `ハ`，**大调在日语中称作「长调」**，所以 C 大调也叫 `ハ长调`。常听古典乐会注意到曲名里频繁出现「○○大调」，那是在明示曲目所用的音阶。

键盘上从 `C` 到 `B` 连同黑键一共 **12 个键**，因此一共可以排出 **12 个大调**。

> **要点** **不需要把 12 个调全背下来。** 只要记住 `全全半全全全半`，任何一个大调都能当场推出来。

> **补充** 「12 个大调」是按**实际音高集合**数的：`Db` 大调与 `C#` 大调的音完全一样，只是写法不同（等音调）。如果按乐谱写法数，常见调号有 15 个（含 `C#`/`Cb` 等极端写法）。做数据处理时按 12 个 pitch class 计数才是对的。
>
> 这组间隔向量写成代码只有一行：
>
> ```python
> MAJOR_STEPS = [2, 2, 1, 2, 2, 2, 1]          # 全全半全全全半
>
> def major_scale(root_pc: int) -> list[int]:
>     """给定主音 pitch class，返回大调音阶的 12 进制音级。"""
>     out, acc = [], root_pc
>     for s in MAJOR_STEPS:
>         out.append(acc % 12)
>         acc += s
>     return out
>
> major_scale(0)   # C 大调 → [0, 2, 4, 5, 7, 9, 11]
> major_scale(5)   # F 大调 → [5, 7, 9, 10, 0, 2, 4]，注意 10 = Bb
> ```
>
> 换个 `root_pc` 就换一个调 —— 这就是「12 个大调」在程序里的样子。

---

## 本篇小结

1. **排列间隔**：`do-re-mi-fa-sol-la-si` 相邻音的全音半音串为 **全全半全全全半**。
2. **音阶**：用固定间隔从任意音开始排出来的一组音。从 `fa` 起得 F 大调、从 `sol` 起得 G 大调、从 `降re` 起得 Db 大调 —— 起始音不同，黑键的数量与位置就不同。
3. 起始音不同但间隔相同 → 听感近似、只有高低差别，这就是**变调**。
4. **大调音阶** = 全全半全全全半；从 C 开始的叫 C 大调音阶。12 个键对应 12 个大调，但只需记住那串间隔。
