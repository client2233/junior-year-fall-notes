# 18 三全音代理（Tritone Substitution）

> 系列：[[11-属进行]] · [[12-小调中的属和弦]] · [[13-副属和弦]] · [[14-251进行]] · [[15-和弦进行2·乐曲中的运用]] · [[16-经过减和弦]] · [[17-五度圈的使用]] · [[18-三全音代理]] · [[19-下属小和弦]] · [[20-套句与持续低音]]
>
> 这一篇是 [[17-五度圈的使用]] 的第一个兑现点：**把属七和弦换成它在五度圈上正对面的那个属七**。听感会换一副面孔，但功能不变 —— 原因是这两个和弦**共用同一对三全音**。

## 18.1 什么是三全音代理和弦

讲座先播了一个和弦进行，让听者自己「找出比较特别的和弦」，然后**把后半段单独拿出来**分析。

做法是拿一个属七和弦和它的**三全音代理和弦**并排比较：

| 比较项 | `G7`（原属和弦） | `D♭7`（三全音代理和弦） |
|---|---|---|
| 倾向移动到 `C` 的程度 | 差不多 | 差不多 |
| 构成音的写法 | 简单 | **要用很多降号**（`D♭ F A♭ C♭`） |

**定义**：

> 对任意一个属七和弦，**在五度圈上正相对（相差 6 个半音、也就是半圈）的那个音上的属七和弦**，就是它的**三全音代理和弦**。

举例：

| 属七和弦 | 三全音代理和弦 |
|---|---|
| `G7` | **`D♭7`** |
| `D7` | **`A♭7`** |
| `F7` | **`B7`** |
| `A7` | **`E♭7`** |
| `B7` | **`F7`** |

- 讲座强调：**没有必要一个个去背对应的三全音代理和弦** —— 用五度圈对一眼就行。
- 这个关系是**对称的**：`G7` 的三全音代理和弦是 `D♭7`，`D♭7` 的三全音代理和弦也是 `G7`。**两者互为三全音代理和弦。**

> **术语** 日语把这个和弦叫**裏コード**（うらコード，字面是「背面和弦」），英文一般叫 **tritone substitution（三全音代理）**。中文教材里「三全音代理」「三全音替代」都指同一件事。

## 18.2 为什么成立：共用同一对三全音

把两个和弦的构成音摊开看：

| 和弦 | 构成音 | 三全音 | 共同音 |
|---|---|---|---|
| `G7` | G **B** D **F** | **B – F** | — |
| `D♭7` | D♭ **F** A♭ **C♭**(=B) | **F – B** | **F、B** |

- 两个和弦的**三全音是同一对音**（`B` 与 `F`）。
- 既然三全音相同，而属七和弦的移动方向由三全音决定（[[11-属进行]]），那么**它们就倾向移动到同一个和弦**。两个都指向 `C`。
- 讲座的原话：**「因为是同一组三全音，所以倾向才移动到同一个和弦。」**

> **要点** 三全音代理不做任何「分析」，它只是**换掉外壳、保留内核**。`G7` 与 `D♭7` 的差别在于除了 `F`、`B` 之外的那两个音；而恰恰是那两个音**决定了色彩**（见 18.4）。

### 18.2.1 幻灯片上还有一条特征：`D♭7` 的音全部贴着 `C`

讲座那张比较表里，`D♭7` 一栏还多了一条特征：

> **`D♭7` 的所有构成音都与 `C` 和弦半音相接。**

逐个检查 `D♭ F A♭ B` 与 `C E G` 的距离：

| `D♭7` 的音 | 距 `C` 和弦最近的音 | 距离 |
|---|---|---|
| **D♭** | C | 半音 |
| **F** | E | 半音 |
| **A♭** | G | 半音 |
| **B**(C♭) | C | 半音 |

四个音**全部**找到半音距离的落点，一个不剩。反过来看也成立：**`C` 和弦的四个半音邻音恰好就是 `D♭ F A♭ B`** —— 也就是 `D♭7`。

> **补充** 这条解释了为什么 `D♭7 → C` 听起来那么顺：**每一个音都只需要走一个半音**。而 `G7` 一侧对应的是「能做**强进行**」（低音上行纯四度），表里标的是「可能 / 不可能」的对比 —— 也就是说，`G7` 靠的是**低音的四度跳进**，`D♭7` 靠的是**全部声部的半音贴靠**。两条路都能到 `C`，这才是「听感不同但功能相同」的具体内容。

## 18.3 用五度圈理解：旋转 180°

讲座承认「稍微有点难懂，不过用五度圈来讲应该更好理解」。做法是：

1. 把 `G7` 的**所有构成音**在五度圈上连起来 → 得到一个**「属七和弦的形状」**。
2. 找出 `G7` 里的**三全音 `F`–`B`** 在圈上的位置 → 这两个音**正好在直径的两端**（相隔 180°）。
3. 问：圈上还有哪些和弦的图形包含**这条直径**？
   - **只有两种**：原本 `G7` 的形状，以及把 `G7` 的形状**旋转 180°** 得到的图形。
   - 后者就是 `D♭7`。

> 所以 **属七和弦的三全音代理和弦 = 把它的图形在五度圈上旋转 180°。**

拿 [[17-五度圈的使用]] 里「三全音 = 直径」这条一起看，这一节几乎是同义反复 —— **三全音既然是直径，那么包含它的和弦必然成对出现在直径两端**。

## 18.4 用法与听感

**做法**：先写一条用到属七和弦的进行，然后把其中某个属七**换成它的三全音代理和弦**。

讲座举了三个例子：

### 例 1：`A7 → E♭7`

- 从 `A` 的正对位得到 `E♭`，所以 `A7` 的三全音代理和弦是 `E♭7`。
- 听感：有一种**说不出的优雅**。
- 和原来的进行相比**相差挺大**，但**音响的氛围在一定程度上是相似的**。

### 例 2：`B7 → F7`

- `B7` 的三全音代理和弦是 `F7`。
- 听感：**像转调的感觉**、听起来**很烦躁**，说得难听点是**糟糕的音响**。
- 但讲座说：**`F7` 的根音是 `F`，还挺容易使用的。**

### 低音走向：负属进行

这是理解听感差异的关键：

| 写法 | 低音走向 | 半音数 |
|---|---|---|
| 原本的属进行 `G7 → C` | **上行纯四度** | +5 |
| 换成三全音代理和弦 `D♭7 → C` | **向下半音级进** | −1 |

讲座说：

> 有人把**三全音代理和弦的向下半音级进**叫做**负属进行**。

于是效果是：**把属进行原本的强推感，换成了一种「消极感」。**

> **补充** 「负属进行」这个名字的来历很清楚：正向的属进行是**上行纯四度**（往谱面右上方走），而三全音代理和弦是**下行半音**（往左下方走）。两者都能到主，但一个「推上去」，一个「滑下去」。这是同一个功能位置上的两种情绪。

### 用法建议

讲座对用量给了明确警告：

- **三全音代理和弦是个特殊的技巧**，请用在**想要强调的地方** / 乐曲的重要位置。
- **用太多的话就会失去新鲜感** —— 要注意**用法和用量**。

讲座还给了一张表，列出某个位置**所有可用的选择**，逐个播放比较，建议去挑**符合自己听感、容易搭配旋律**的那个。

## 18.5 `F7` 的翻身

这一节是前后章节的接点。

- 在 [[13-副属和弦]] 里，`F7` 是**唯一不能作副属和弦**的和弦（因为它解决到调外的 `B♭`）。
- 但在这一篇里：**`F7` 可以作为三全音代理和弦使用** —— 它是 `B7` 的三全音代理和弦。
- 讲座的语气是「**那时候没能用到的 `F7`，终于有用途了**」。

所以讲座在 [[13-副属和弦]] 里说「`F7` 也有别的用途，到时候再记也好」，指的就是这里。

> **要点** 判断一个属七「能不能用」时，要分清问的是**哪个角色**。`F7` 在 C 大调里**不能当副属和弦**（`V7/IV` 会把音乐带出调），但**完全可以当三全音代理和弦**（替代 `B7` 指向 `Em`）。**同一个和弦在不同功能位置上，可用性完全不同。**

## 18.6 用代码验证

```python
from itertools import combinations

NAMES = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
PC = {n: i for i, n in enumerate(NAMES)}

def pcs(*ns):
    return sorted(PC[n] % 12 for n in ns)

def tritone(ps):
    ps = sorted(set(ps))
    return [(NAMES[a], NAMES[b]) for a, b in combinations(ps, 2) if (b - a) % 12 == 6]

def dom7(root):
    """属七和弦：根音 + 大三度 + 纯五度 + 小七度。"""
    return pcs(root, NAMES[(PC[root] + 4) % 12],
                     NAMES[(PC[root] + 7) % 12],
                     NAMES[(PC[root] + 10) % 12])

def show(label, ps):
    print(f"{label:<5}= {[NAMES[p] for p in ps]!s:<26} 三全音 {tritone(ps)}")

# 四对互为三全音代理和弦的例子
for dom, sub in [("G", "Db"), ("D", "Ab"), ("F", "B"), ("A", "Eb")]:
    a, b = dom7(dom), dom7(sub)
    show(f"{dom}7", a)
    show(f"{sub}7", b)
    common = sorted(set(NAMES[p] for p in a) & set(NAMES[p] for p in b))
    print(f"      共同音 = {common}   三全音相同 = {tritone(a) == tritone(b)}")
```

输出：

```
G7   = ['D', 'F', 'G', 'B']       三全音 [('F', 'B')]
Db7  = ['C#', 'F', 'G#', 'B']     三全音 [('F', 'B')]
      共同音 = ['B', 'F']   三全音相同 = True
D7   = ['C', 'D', 'F#', 'A']      三全音 [('C', 'F#')]
Ab7  = ['C', 'D#', 'F#', 'G#']    三全音 [('C', 'F#')]
      共同音 = ['C', 'F#']   三全音相同 = True
F7   = ['C', 'D#', 'F', 'A']      三全音 [('D#', 'A')]
B7   = ['D#', 'F#', 'A', 'B']     三全音 [('D#', 'A')]
      共同音 = ['A', 'D#']   三全音相同 = True
A7   = ['C#', 'E', 'G', 'A']      三全音 [('C#', 'G')]
Eb7  = ['C#', 'D#', 'G', 'A#']    三全音 [('C#', 'G')]
      共同音 = ['C#', 'G']   三全音相同 = True
```

再验证「低音走向」与「五度圈 180°」：

```python
for dom in ["G", "D", "F", "A", "B"]:
    sub = NAMES[(PC[dom] + 6) % 12]
    print(f"{dom}7 的三全音代理和弦 = {sub}7   （五度圈上相差 180°）")

print()
print("G7 -> C   低音 G  -> C :", (PC['C'] - PC['G']) % 12, "半音（上行纯四度）")
print("Db7 -> C  低音 Db -> C :", (PC['C'] - PC['Db']) % 12 - 12, "半音（向下半音 = 负属进行）")
```

## 本篇小结

1. **三全音代理和弦** = **五度圈上正对面（相差 6 半音）那个音上的属七和弦**。`G7 ↔ D♭7`、`D7 ↔ A♭7`、`A7 ↔ E♭7`、`B7 ↔ F7`。
2. 成立的原因是**两个和弦共用同一对三全音**（`G7` 与 `D♭7` 共用 `B`、`F`），所以**移动方向相同**，都指向 `C`。
3. 用五度圈看就是**把和弦图形旋转 180°** —— 因为三全音在圈上是一条**直径**（[[17-五度圈的使用]]）。
4. 幻灯片另给了一条特征：**`D♭7` 的四个构成音全部与 `C` 和弦半音相接**（`D♭ F A♭ B` 正是 `C E G` 的四个半音邻音）。对照之下 `G7 → C` 的打法是**低音上行纯四度**，两条路都能到 `C`。
5. 听感随例子而异：`A7 → E♭7` **优雅**；`B7 → F7` **像转调、烦躁**。差别来自除三全音外的那两个音。
6. **低音走向从「上行纯四度」变成「向下半音级进」** —— 讲座把它叫**负属进行**，效果是**把强推感换成消极感**。
7. **`F7` 在这里翻身**：它在 [[13-副属和弦]] 里不能当副属和弦，但**可以当 `B7` 的三全音代理和弦**。
8. **用量要克制**：特别技巧用在**想强调的地方**；用多了会**失去新鲜感**。
