## 4.1 顺阶三和弦的构造

### 4.1.1 构造法：在每个音上「三度堆两个音」

**对音阶上的每一个音，以三度为间隔向上再堆两个音**，就得到一个三和弦。

以 C 大调音阶 `C D E F G A B`（去掉末尾重复的高八度 do）为例：

- 从 **C** 出发：与 C 隔开一个音的是 E，与 E 隔开一个音的是 G → 得 **C E G**
- 从 **D** 出发：与 D 隔开一个音的是 F，与 F 隔开一个音的是 A → 得 **D F A**
- 从 **E** 出发：E → G → B → 得 **E G B**
- 依此类推（本质就是「隔一个取一个，共取三个」）

七个起始音各得一个和弦，画在五线谱上像一串整齐的团子。

### 4.1.2 七个和弦与它们的名字

| 起始音 | 构成音（意式） | 构成音（字母） | 名称 | 记号 |
|---|---|---|---|---|
| `do` | do mi sol | C E G | C 大三和弦 | **C** |
| `re` | re fa la | D F A | D 小三和弦 | **Dm** |
| `mi` | mi sol si | E G B | E 小三和弦 | **Em** |
| `fa` | fa la do | F A C | F 大三和弦 | **F** |
| `sol` | sol si re | G B D | G 大三和弦 | **G** |
| `la` | la do mi | A C E | A 小三和弦 | **Am** |
| `si` | si re fa | B D F | B 减三和弦 | **Bm(b5)** |

这七个和弦总称为**顺阶和弦 / 调内和弦**（diatonic chord）—— 即在某个调的音阶内「顺次」堆出来的和弦。

> **要点** 换一个音阶（换调），这七个和弦的具体音和顺序都会变，**但品质的排列规律完全一样**（见补充）。所以不需要背七个调的和弦表，只需要记构造法。

## 4.2 和弦各音的名称

三和弦的三个音各有名字，**这几个名称必须记住**：

| 名称 | 英文 | 含义 |
|---|---|---|
| **根音** | Root | 生成这个和弦的最下方（基准）的那个音 |
| **三音** | 三度音 | 与根音呈三度关系的音 |
| **五音** | 五度音 | 与根音呈五度关系的音 |

（七和弦再多一个**七音**，见 [[05-顺阶七和弦]]。）

> **要点** 记住的不是「某个和弦叫什么」，而是「**和弦是在音阶各音上三度堆两个音**」这条构造法。名字是结果的副产品。

## 4.3 大和弦与小和弦的区别

和弦分类中**最重要的就是大 / 小**。C 大调的顺阶三和弦里，分为大和弦的是 **C、F、G** 三个，其余四个是小和弦（`Bm(b5)` 归在减和弦里）。

**记号上的粗判据**：和弦记号里带 `m` 的是小和弦，不带 `m` 的是大和弦。

但这个判据只是方便记忆，**本质区别在于音程**。以半音为单位数：

| 和弦 | 根音 → 三音 | 三音 → 五音 | 根音 → 五音 | 性质 |
|---|---|---|---|---|
| **C** | 4 半音（大三度） | 3 半音（小三度） | 7 半音 | 大和弦 |
| **Dm** | 3 半音（小三度） | 4 半音（大三度） | 7 半音 | 小和弦 |
| **Bm(b5)** | 3 半音（小三度） | 3 半音（小三度） | **6 半音** | 减和弦 |

- **大 / 小和弦的根音到五音都是 7 半音**（纯五度），上下两个三度的 4 / 3 半音关系正好相反。
- **Bm(b5)** 是顺阶和弦里的异类：三音到五音也只有 3 半音，五音比通常低半音，根音到五音只有 6 半音 —— 所以记号上要加 `b5`（降五音），叫**减三和弦**。

> **要点** 拿到一个和弦，数两个半音数就能判断大小：**4 + 3 = 大，3 + 4 = 小，3 + 3 = 减**。

> **补充** 把三和弦写成 pitch class 集合（模 12，根音记为 0）：
>
> ```python
> TRIAD = {
>     "major":      [0, 4, 7],   # 大三和弦：根音 + 大三度 + 纯五度
>     "minor":      [0, 3, 7],   # 小三和弦
>     "diminished": [0, 3, 6],   # 减三和弦（Bm(b5) 属这一类）
>     "augmented":  [0, 4, 8],   # 增三和弦（大调顺阶和弦里不出现）
> }
>
> def diatonic_triads(major_pc: int) -> list[tuple[int, list[int]]]:
>     """返回某大调上的七个顺阶三和弦。"""
>     steps = [2, 2, 1, 2, 2, 2, 1]
>     scale, acc = [], major_pc
>     for s in steps:
>         scale.append(acc % 12); acc += s
>     out = []
>     for i, r in enumerate(scale):
>         notes = [scale[(i + k) % 7] for k in (0, 2, 4)]   # 隔一个取一个
>         out.append((r, notes))
>     return out
> ```
>
> `diatonic_triads(0)` 得到的正是 C Dm Em F G Am Bm(b5)，与表完全对得上。
>
> 推而广之，**任何大调上七个顺阶三和弦的品质序列都是固定的**：`大 小 小 大 大 小 减`。用罗马数字写出来是 `I ii iii IV V vi vii°`（大写 = 大和弦，小写 = 小和弦，`°` = 减和弦）。这就是「为什么不用背七个调」的真正原因。

---

## 本篇小结

1. **构造法**：在音阶的每个音上以三度为间隔向上堆两个音，得到七个**顺阶和弦 / 调内和弦**。
2. 和弦各音称**根音**、**三音**、**五音**。
3. **大 / 小**看半音数：`4 + 3` 为大，`3 + 4` 为小；两者根音到五音都是 7 半音。
4. `Bm(b5)` 是 `3 + 3`、根音到五音 6 半音的**减三和弦**，顺阶和弦中唯一的例外。
5. 记号上带 `m` 为小和弦，不带为大和弦（粗判据）。
