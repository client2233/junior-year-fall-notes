# 03 自然小调音阶·平行调与同主调

> 系列：[[01-音名与音程]] · [[02-排列间隔与大调音阶]] · [[04-顺阶三和弦]] · [[05-顺阶七和弦]] · [[06-和弦进行]] · [[07-和弦转位]] · [[08-和弦的功能]] · [[09-代理和弦与功能的扩展]] · [[10-速查·和弦记号与功能表]]
>
> [[02-排列间隔与大调音阶]] 建立了大调音阶。这一篇讲与它相对的小调音阶，以及音阶之间的两种关系 —— **平行调**与**同主调**。这两种关系的区别是后面理解「转调」和「借用和弦」的前提。

## 3.1 自然小调音阶（Natural Minor Scale）

与大调音阶相对的是**自然小调音阶**。「自然」这个限定词的含义之后会讲到，现在只需记住：**与大调相对的就是自然小调**；平时说「小调」有时也代指它，但严格写全称更稳妥。

### 3.1.1 怎么得到：大调的第 3、6、7 音降半音

把 C 大调音阶 `C D E F G A B` 的**第 3、6、7 音**各降半音：

| 音级 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| C 大调音阶 | C | D | E | F | G | A | B |
| 降半音后 | C | D | **Eb** | F | G | **Ab** | **Bb** |

得到 **C 自然小调音阶 = C D Eb F G Ab Bb C**。三个音被降低 —— 五线谱上不容易看清，画成键盘图就一目了然。

听感上，与大调相比**明显更悲伤、更哀愁**。只动三个音，气氛就完全不同。

### 3.1.2 排列间隔

| 相邻音组 | 间隔 |
|---|---|
| C–D | 全音 |
| D–Eb | 半音 |
| Eb–F | 全音 |
| F–G | 全音 |
| G–Ab | 半音 |
| Ab–Bb | 全音 |
| Bb–C | 全音 |

即 **全 半 全 全 半 全 全**。

> **要点** 大调的 `全全半全全全半` 必须背死。**自然小调的间隔不用刻意背** —— 理由在 3.2 节。

### 3.1.3 小调化：把大调旋律变暗

既然「大调的第 3、6、7 音降半音 = 自然小调」，那么**把一段大调旋律里所有的第 3、6、7 音降半音，这段旋律就变成自然小调的了**。这就是把明朗曲子改得阴暗的做法。

要点：

- 简单旋律越容易变换 —— **先拿童谣试**。把某首童谣在 C 大调上的 E、A、B 全部降半音，立刻得到阴郁版本。
- 有些旋律这么改会不合适，但整体上这是个通用手段。

## 3.2 平行调与同主调

### 3.2.1 自然小调的间隔其实是「大调平移」

把自然小调的间隔串转一下圈：

```
自然小调：全 半 全 全 半 全 全
从第 3 项开始读： 全 全 半 全 全 全 半
```

**恰好就是大调的排列间隔。**

反过来：**从大调音阶的第 6 音开始排列，得到的间隔就是自然小调的间隔**。以 C 大调为例，从第 6 音 A 开始：

```
C 大调：C D E F G A B   →  从 A 开始读：A B C D E F G
间隔：全 半 全 全 半 全 全        ← 正是自然小调的间隔
```

从 A 开始的这个音阶就叫 **A 自然小调音阶**。

> **要点** 这就是「自然小调的间隔不用背」的原因：**它就是大调间隔换个起点读**。

### 3.2.2 平行调（relative key）

**C 大调与 A 自然小调使用的是完全相同的一组音**（C D E F G A B），只是主音不同。这样一对音阶互称**平行调**。

- C 大调的平行调是 A 自然小调；A 自然小调的平行调是 C 大调。
- 由 3.2.1 的推导可知：**大调的第 6 音就是它平行小调的主音**（「往前数两个音」是同一个意思）。
- 两者在理论上是不同的音阶，但**音高集合相同**，所以在平行调之间移动不会有明显违和 —— 现在的流行乐大多数情况下不做严格区分。
- 也正因为音完全相同，一首曲子「游走」到平行调的可能性非常高。

### 3.2.3 同主调（parallel key / 同主音调）

C 大调与 C 自然小调**主音相同、音阶不同**（后者是前者降 3、6、7 音的结果）。这种关系叫**同主调**。

- 由 C 大调移动到 C 自然小调，很多人会**明显感觉到进入了另一个世界**。
- 所以同主调是「想要彻底改变曲调」时的一个有力手段。
- 与平行调对比：平行调换音、不换感觉；同主调换感觉、主音不动。

### 3.2.4 转调

**曲子中途变换曲调叫转调**（modulation）。平行调与同主调是两种最常用的转调目标。

## 术语对照

同一组概念在日文与中文里的说法不同，读日文资料时容易混：

| 日文 | 中文 |
|---|---|
| 長調 | 大调 |
| 短調 | 小调 |
| 平行調 | 平行调（同音列关系） |
| 同主調 | 同主调（同主音关系） |
| 転調 | 转调 |

> **补充** 这一篇只讲了**自然**小调。实际使用中小调还有**和声小调**（第 7 音回升半音）与**旋律小调**（上行第 6、7 音回升、下行还原），它们是为了修掉自然小调在和声上的缺陷而出现的。讲座后续会讲到，届时可在 [[02-排列间隔与大调音阶]] 的间隔串上各改一位即可。
>
> 用代码表达两种关系：
>
> ```python
> MAJOR = [0, 2, 4, 5, 7, 9, 11]                  # 以主音为 0 的相对音级
> NAT_MINOR = [0, 2, 3, 5, 7, 8, 10]              # 大调第 3、6、7 音降半音
>
> def relative_minor_pc(tonic_pc: int) -> int:
>     """大调主音 → 平行小调主音（第 6 音，即 +9 半音）。"""
>     return (tonic_pc + 9) % 12
>
> relative_minor_pc(0)    # C 大调 → 9 = A
> ```
>
> 注意 `NAT_MINOR` 与 `MAJOR` 是**同一组音在不同主音下的表示**：A 自然小调与 C 大调音列相同，这就是[[04-顺阶三和弦]]里同一批和弦能在两个调之间反复横跳的原因。

## 本篇小结

1. **自然小调音阶** = 大调音阶的第 3、6、7 音降半音；排列间隔为**全半全全半全全**。
2. 把大调旋律中所有第 3、6、7 音降半音，整段旋律即**小调化**。
3. **平行调**：音高集合相同、主音不同（C 大调 ↔ A 自然小调）。大调的第 6 音开始排列即得平行小调，两者互移不明显违和。
4. **同主调**：主音相同、音阶不同（C 大调 ↔ C 自然小调），互换会明显改变曲调。
5. 曲子中途变换曲调叫**转调**。
