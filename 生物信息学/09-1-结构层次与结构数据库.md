前十二讲停在「序列」这一层：比对、谱、HMM 都是把一条序列映射成一个可打分的对象。这一讲换到「结构」这一层，先解决三件事：结构分成几层、这些结构存在哪里、用什么尺子量两个结构像不像。

## 26.1 四个基本层面

| 层面 | 描述的对象 | 稳定它的相互作用 | 是否可由序列直接读出 |
|---|---|---|---|
| 一级结构 | 氨基酸的线性序列与残基间的共价连接 | 肽键（共价） | 是，就是序列本身 |
| 二级结构 | 主链的**局部**构象 | 主链之间的氢键 | 部分，需预测 |
| 三级结构 | 整条链的三维坐标 | 疏水核心、氢键、盐桥、二硫键 | 否，需实验或预测 |
| 四级结构 | 多个亚基的组装方式 | 亚基间非共价作用 | 否 |

二级结构的**规则**部分只有两类：α-螺旋与 β-折叠；其余（环区 loop、转角 turn）统称非规则结构。

这里有一个常被讲错的点：**β-折叠的氢键可以连接序列上相距很远的残基**。所以二级结构不能一概归因于「序列上的短程相互作用」—— 一条 β 链的配对对象可能在一百个残基之外。这条限制直接决定了二级结构预测的上限：只看局部窗口的方法（[[09-2-蛋白质二级结构预测]] 里的 Chou–Fasman、GOR）天生看不到这类长程约束，要到 PSIPRED 之后引入进化信息、以及后来的双向 LSTM，才把这块补上。

## 26.2 结构档案：PDB

PDB（Protein Data Bank）是生物大分子三维结构的**唯一**核心档案。它不是一个网站，而是一个联盟：

- **wwPDB** 是管理机构，三家成员门户共享同一份核心档案：
  - RCSB PDB（美国，`rcsb.org`）
  - PDBe（欧洲，`ebi.ac.uk/pdbe`）
  - PDBj（日本，`pdbj.org`）
- **MSD** 是 PDBe 的旧称，不是独立的档案。早期课件把 PDB 与 MSD 并列成两个库，会误导。

一个条目包含：原子坐标、实验方法（X-ray / NMR / cryo-EM）、质量指标（分辨率、R-free、B 因子）、配体与小分子、以及文献引用。RCSB 门户现在还索引 AlphaFold 等**计算模型**，检索时务必分清实验结构与预测结构 —— 后者的坐标不是观测值，不能当基准真值用来评估方法。

规模直觉：PDB 累计条目已超过 20 万，但按序列一致性 30% 聚类去冗余后只剩几万。这就是「实验结构覆盖度」的真实口径 —— 条目数不等于不重复的结构数。

## 26.3 结构分类：SCOPe 与 CATH

结构分类库要回答的问题是：**已知结构一共只有多少种折叠方式**。两个库都按层级组织，但四层的含义**不完全对应**。

SCOPe（延续经典 SCOP 体系，`scop.berkeley.edu`）：

| 层 | 含义 |
|---|---|
| Class | 二级结构组成，如全 α、全 β、α/β、α+β |
| Fold | 二级结构单元的**拓扑排布**相同（顺序与连接方式一致） |
| Superfamily | 有远缘进化证据（低序列一致性但结构/功能相似） |
| Family | 序列一致性显著（通常 >30%），功能相同 |

CATH（`cathdb.info`）：

| 层 | 字母 | 含义 |
|---|---|---|
| Class | C | 二级结构组成 |
| Architecture | A | 二级结构单元的**空间布局**，不考虑连接顺序 |
| Topology | T | 在布局基础上**进一步考虑连接顺序** |
| Homologous superfamily | H | 有共同祖先证据 |

差别在第二、三层。SCOP 的 Fold 已经把连接顺序算进去了，CATH 把它拆成 Architecture（只看空间布局）和 Topology（才看连接顺序）两步。所以「SCOP 的 Fold ≈ CATH 的 Topology」，不是 Architecture。

CATH 的规模有官方口径：v4.4（基于 2024-10-01 的 PDB）列出 **1472 个 Topology**。早期课件说「折叠类型约 1000 种」，是旧版量级估计，别当固定事实 —— 这个数随分类体系与数据库版本变。

两个库都有的配套资源：

- **ASTRAL**（SCOPe）：提供结构域序列、坐标和按序列一致性去冗余的代表集，是做结构域数据集的标准来源。
- **FunFams**（CATH）：在 Homologous superfamily 之下再按功能细分，用于功能转移。

## 26.4 序列层面的家族：Pfam 与 InterPro

结构分类按**几何**归类，Pfam 按**序列**归类，两套体系在结构域这一级会撞上。

**Pfam** 的基本单位是结构域家族，模型是**profile HMM**（多序列比对建出来的，[[08-5-profile-HMM与HMMER]]）：

- 建模型：对家族的多序列比对跑 `hmmbuild`，得到位置特异的发射与转移概率。
- 注释：拿模型去扫序列，输出「这条蛋白含哪些结构域、在序列的哪一段」。
- **Clan**：把有共同进化来源的多个 Pfam 条目聚成一族，解决「同一结构域被拆成好几个条目」的冗余。
- 入口现在由 InterPro 承载，Pfam 条目页可直接看比对与 HMM。

**InterPro** 是整合层：把 Pfam、PROSITE、SMART、CDD 等成员库的特征模型汇到一起，统一组织成家族/结构域/重复/重要位点四类条目，并挂上 GO 注释（下一篇 [[10-2-GO与语义相似度]] 用的就是这层）与 UniProt、PDB 的链接。扫描工具是 **InterProScan**，一次跑完所有成员库再汇总。

用哪个：只想知道「有没有某个已知结构域」→ Pfam；想知道「这条蛋白在细胞里干什么」（要 GO 术语）→ InterPro。

## 26.5 结构比对：DALI

分类库是**人工层级归类**，DALI 是**结构比对与相似性检索服务**，两者不是一回事。

DALI 的核心是一个数学事实：**两个结构的 Cα–Cα 距离矩阵，在刚体运动（旋转 + 平移）下不变**。

设结构 $A$ 有 $n$ 个 Cα，定义矩阵

$$
D^{(A)}_{ij}=\lVert \mathbf{x}^{(A)}_i-\mathbf{x}^{(A)}_j\rVert
$$

把整个结构旋转 $R$、平移 $\mathbf{t}$ 后 $\mathbf{x}'_i=R\mathbf{x}_i+\mathbf{t}$，则

$$
\lVert \mathbf{x}'_i-\mathbf{x}'_j\rVert=\lVert R(\mathbf{x}_i-\mathbf{x}_j)\rVert=\lVert \mathbf{x}_i-\mathbf{x}_j\rVert
$$

所以 $D'=D$。**这就把「找一个最优叠合」这个六自由度优化问题消掉了**：比对退化成「在两个距离矩阵里找一致的子矩阵」，是纯粹的图/矩阵问题。DALI 做的就是把这个子矩阵搜索写成动态规划。

输出指标：

| 指标 | 含义 | 怎么读 |
|---|---|---|
| Z-score | 比对得分相对随机结构的显著性（多少倍标准差） | 一般 >2 才算有意义，>8 认为同折叠 |
| RMSD | 叠合后对应 Cα 的均方根偏差 | 必须与比对长度一起看 |
| 比对长度 / 覆盖度 | 参与比对的残基数 | 只比上 30 个残基的 RMSD 再小也没意义 |

**RMSD 单独看会骗人**：两个结构比上 20 个残基、RMSD 0.5 Å，与比上 200 个残基、RMSD 3 Å，后者往往是更有价值的同源发现。这就是后来 TM-score 出现的动机（按距离归一化并给近距离残基更高权重，取值 0–1，对长度不敏感）。

## 26.6 数据格式：PDB 与 mmCIF

PDB 格式是**固定列宽**的纯文本，不是分隔符文本。标准列位置（1-based，含端点）：

| 字段 | 列 | 示例（ATOM 行） |
|---|---|---|
| 记录名 | 1–6 | `ATOM  ` |
| 原子序号 | 7–11 | `    1` |
| 原子名 | 13–16 | ` N  ` |
| 残基名 | 18–20 | `PRO` |
| 链标识 | 22 | `A` |
| 残基序号 | 23–26 | `   1` |
| x | 31–38 | `  24.595` |
| y | 39–46 | `  65.444` |
| z | 47–54 | ` -36.298` |
| 占有率 occupancy | 55–60 | `  1.00` |
| 温度因子 B | 61–66 | ` 108.09` |
| 元素符号 | 77–78 | ` N` |

**实际动手时的坑**：网上抄来或工具转换过的 PDB 行经常错位。拿课件里那行验证：

```
ATOM      1  N   PRO A   1      24.595  65.444 -36.298  1.00 108.09           N
```

按上表切片，B 因子列（61–66）切出 `' 108.0'`（漏了末位 9），元素列（77–78）切出 `'  '`（空）。原因很简单：这行是别的格式转过来的，`108.09` 占了 7 个字符而不是 6，往右的字段全部偏移一格。

结论：**永远不要用 `line.split()` 解析 PDB**，也不要自己数格子。用 Biopython 的 `PDBParser`，或者直接用 **mmCIF**（`_atom_site` 循环，明确的键值对，没有列宽问题）。mmCIF 已经是 wwPDB 的推荐格式，PDB 格式只是历史兼容。

## 订正

**1. 第 6 页把「PDB」与「MSD」并列成两个结构档案，是错的。**

MSD（Macromolecular Structure Database）是 PDBe 的旧名，不是独立档案。三家门户（RCSB / PDBe / PDBj）共享同一份 wwPDB 核心档案，条目编号（4 位，如 `3ELH`）在三家通用。

**2. 第 15 页把 DALI 与 SCOP、CATH 并列归类为「结构分类」，混淆了两种东西。**

SCOP/CATH 是**人工（结合自动）建立的层级分类库**，一个结构域被指派到唯一的 Class/Fold/... 路径上；DALI 是**检索服务**，输入一个结构，输出一堆按相似度排序的命中，不产生分类路径。DALI 的输出（Z-score + RMSD + 比对长度）可以作为归类的证据，但它本身不做归类。

**3. 第 45 页「已知结构可归入约 1000 种折叠」是旧口径，不能当固定事实。**

CATH v4.4（2024-10-01 版 PDB）给出 1472 个 Topology。这个数字每版都在涨，写报告要带版本与日期。

**4. 二级结构「主要由主链氢键稳定」这句话对，但「二级结构只反映序列上的短程相互作用」这句错。**

β-折叠的配对链在序列上可以隔很远；跨链的 β-折叠（四级结构层面）更是完全没有序列邻近性。这条错误会造成一个连锁误解：以为二级结构预测只要看 ±8 个残基的窗口就够 —— 那正是 Chou–Fasman 和 GOR 的时代局限，不是二级结构本身的性质。
