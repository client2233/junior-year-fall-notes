这一篇接课件第 51 页那一行表格往下讲：**profile HMM 是 HMM 在生物信息学里最主要的存在形式**，也是前面三代东西（打分表 → 频率表 → 概率模型）的最后一代。课件本身只给了名字与 HMMER 的出处（Haussler, Krogh, Mian & Sjölander 1993，用珠蛋白家族做的第一个例子），下面标 **补充** 的部分是我按 HMMER 的公开文档补的。

## 25.1 从 profile 到 profile HMM：缺的是什么

回顾 [[07-6-sequence-profile与profile比对]] 的 profile：

$$
p(j,a)=\sum_{b=1}^{20}f_{jb}B(a,b)
$$

它是**一张 $L\times20$ 的打分表**，配上 ClustalW 那种「全局固定」的 gap 罚分。

三个缺口：

| 缺口 | 后果 |
|---|---|
| gap 罚分与位置无关 | 环区（loop）本该允许大量 indel，核心区不该；用同一个罚分两头都错 |
| 没有概率归一 | 分数不可解释，无法算「这条序列出现的概率」 |
| 没有「结束」的概念 | 只能做全局比对，做不了「序列里只有一段匹配」的局部搜索 |

**profile HMM 补的正是这三样**：把每个位置的发射做成概率分布、把 gap 的**开与延伸**做成随位置变化的**转移概率**、加上 BEGIN/END 状态让局部比对成为一条合法路径。

## 25.2 三态结构

**补充**。一个长度为 $L$ 的 profile HMM，核心是一条「主链」，每个位置 $k=1,\dots,L$ 有三种状态：

| 状态 | 名称 | 发射 | 含义 |
|---|---|---|---|
| $M_k$ | match | 有（20 维分布） | 序列的第 $k$ 个保守位点对上了 |
| $I_k$ | insert | 有（20 维分布） | 在位置 $k$ 之后插入了一个多余的残基 |
| $D_k$ | delete | **无**（静默状态） | 模型的位置 $k$ 在序列里缺失 |

$L$ 个位置 × 3 种状态 = $3L$ 个核心状态，再加两个特殊状态：

- $B$（begin）：进入模型的入口；
- $E$（end）：离开模型的出口。

HMMER 的 Plan7 还额外加了三个「侧翼」状态 $N$（N 端未匹配区）、$C$（C 端未匹配区）、$J$（两次匹配之间的连接区），用来支持**多结构域、局部**比对。

允许的转移（口径：从 $M_k$ 出发）：

| 转移 | 含义 |
|---|---|
| $M_k\to M_{k+1}$ | 对上第 $k+1$ 位 |
| $M_k\to I_k$ | 在第 $k$ 位后插入 |
| $M_k\to D_{k+1}$ | 跳过第 $k+1$ 位 |
| $I_k\to I_k$ | 连续插入 |
| $I_k\to M_{k+1}$ | 插入结束，继续匹配 |
| $D_k\to D_{k+1}$ | 连续缺失 |

$D$ 状态**不能发射**，也不能直接进 $I$（否则同一位置会既缺失又插入，语义冲突）。这条限制让路径与比对一一对应 —— 这是 profile HMM 能被当作「比对算法」用的根本原因。

```text
        ┌───┐   ┌───┐        ┌───┐
   B ──►│M1 │──►│M2 │─ ... ─►│ML │──► E
        └─┬─┘   └─┬─┘        └─┬─┘
          │  ↺    │  ↺         │
        ┌─▼─┐   ┌─▼─┐        ┌─▼─┐
        │I1 │   │I2 │        │IL │
        └───┘   └───┘        └───┘
          │       │            │
        ┌─▼─┐   ┌─▼─┐        ┌─▼─┐
        │D1 │──►│D2 │─ ... ─►│DL │
        └───┘   └───┘        └───┘
```

## 25.3 打分就是「沿路径求和」

一条序列 $x$ 与模型的**一个比对**，等价于模型上的一条**路径**。这条路径的对数几率（log-odds）分数：

$$
S=\sum_{\text{路径上的发射}}\log\frac{e_k(x_i)}{P(x_i)}+\sum_{\text{路径上的转移}}\log\frac{t_{uv}}{t^{\text{null}}_{uv}}
$$

| 项 | 含义 |
|---|---|
| $e_k(x_i)$ | 状态 $k$ 发射残基 $x_i$ 的概率（$M$ 或 $I$ 状态才有） |
| $P(x_i)$ | 背景频率（零模型） |
| $t_{uv}$ | 模型里 $u\to v$ 的转移概率 |
| $t^{\text{null}}_{uv}$ | 零模型里对应的转移概率（通常取固定的 gap 开/延伸） |

**前两项的比值就是 07-5 里 PSSM 的 $S(i,j)$，后一项是 profile 没有的东西**。所以：

> profile HMM 的分数 = PSSM 的发射分 + **位置特异的 gap 分**。

这就是它比 PSSM 灵敏的全部原因。[[07-5-PSI-BLAST·PSSM与位置特异性打分]] 19.9 那张表里「HMM 学的是这个位点允不允许 gap」说的就是这件事。

**三种算法在 profile HMM 上的含义**（与 [[08-2-概率计算·前向与后向算法]]、[[08-3-Viterbi解码·动态规划求最优路径]] 一一对应）：

| 算法 | 在这个模型上算什么 | HMMER 里的用途 |
|---|---|---|
| Viterbi | 最优路径 = **最优比对** | 建 profile、给比对（`hmmalign`） |
| 前向（sum-product） | 所有路径概率之和 = **序列的边缘似然** | 给 log-odds 总分、算 E 值 |
| 后向 | 与 $\alpha$ 配对 | Baum–Welch 的参数更新 |
| Baum–Welch | 从无标注序列学参数 | `hmmbuild` 的一种模式 |

注意一个**容易搞混的点**：HMMER 报的分数是**前向**分数（所有比对的概率和），不是 Viterbi 分数。前向分数 ≥ Viterbi 分数，且对「同一家族的不同比对方式」做了边缘化，所以更稳。要拿最优比对（比如给结构建模用），得另外跑 `hmmalign`。

## 25.4 建模型：hmmbuild

**补充**。从一条多序列比对出发：

```bash
hmmbuild globins.hmm globins.sto      # Stockholm 格式的比对 → profile HMM
hmmsearch globins.hmm proteins.fa    # 拿 profile 搜库
hmmscan  Pfam-A.hmm proteins.fa      # 反向：拿序列搜 profile 库
hmmalign globins.hmm seqs.fa         # 把序列比对到模型上（Viterbi）
```

`hmmbuild` 内部做的三件事，全部对应前面讲过的东西：

| 步骤 | 对应 |
|---|---|
| 序列赋权 | Henikoff 位置权重（[[07-6-sequence-profile与profile比对]] 20.5） |
| 从比对反推模型结构 | 某一列 gap 比例高 → 该位置倾向 $D$；插入多 → $I$ 的转移概率大 |
| 加先验（Dirichlet 混合） | 就是 07-5 的「伪计数」，防止小样本把概率压成 0 |

最后一条要强调：**Baum–Welch 的闭式解会把参数推到 0/1**（[[08-4-Baum-Welch学习与EM推导]] 24.7），所以真实工具都加先验。HMMER 用的是 Dirichlet 混合先验，等价于「每个参数先垫若干个虚拟观测」。没有这层，20 条序列建出的模型会有一半的发射概率是 0。

## 25.5 搜库：HMMER3 的四级过滤

**补充**。profile HMM 的前向算法是 $O(L\cdot L_{\text{seq}})$，拿它扫 UniProt（两亿条）是跑不动的。HMMER3 的做法是**逐级加严**：

| 级 | 算法 | 作用 |
|---|---|---|
| 1 | MSV（multiple segment Viterbi，无 gap） | 极快的粗筛，滤掉 99% 以上 |
| 2 | Viterbi 滤波 | 带 gap，进一步筛 |
| 3 | Forward 滤波 | 用真实分数再筛 |
| 4 | 全 Forward + 域后处理 | 只对通过的少数序列做完整计算，并切出结构域边界 |

**这条流水线值得记的原因**：它说明「精确算法 + 聪明的过滤」比「近似算法」更划算。前三级都不是最终答案，但它们的漏检率被控制在可接受范围（HMMER 的滤波阈值可调，`--F1/F2/F3`）。

E 值的来源：HMMER3 对 Forward 分数用**指数尾分布**拟合（而不是 BLAST 的 Gumbel），并对「组成偏倚」做 null2 校正。所以 **HMMER 的 E 值与 BLAST 的 E 值不可直接比较** —— 两者统计模型不同。

## 25.6 与 PSI-BLAST 的定位差别

| | PSI-BLAST（PSSM） | HMMER（profile HMM） |
|---|---|---|
| 模型 | 打分表 | 概率模型（含转移） |
| gap | 全局固定罚分 | 位置特异、可学 |
| 训练 | 迭代搜库 + 重建 PSSM | `hmmbuild` 一次性从比对建，或 BW |
| 灵敏度（远缘） | 中 | 高 |
| 速度 | 快 | 慢（但 HMMER3 已接近可用） |
| 输出 | 命中列表 + PSSM | 命中列表 + 域边界 + 比对 |

实践建议：**先用 HMMER 搜**（灵敏度高、给域边界），命中再用 BLAST 做交叉验证（速度快、生态好）。Pfam、InterPro 的家族模型全部是 HMM，不是 PSSM —— 这本身就是行业投票的结果。

## 25.7 生物信息学里的其他 HMM

| 工具 | 隐藏状态 | 用途 |
|---|---|---|
| HMMER / Pfam | 匹配 / 插入 / 缺失 | 蛋白家族与结构域 |
| GenScan、Augustus（HMM 部分） | 外显子、内含子、UTR、基因间区 | 基因预测 |
| TMHMM、Phobius | 跨膜螺旋 / 胞内 / 胞外 | 拓扑预测 |
| HMMER 的 `nhmmer` | 同 HMMER，核苷酸版 | 非编码 RNA 家族 |

共性：**状态就是「这一段是什么」**，而观测是碱基/残基。所以第 21.7 节那张表不是三个孤立的例子，是同一套建模思路的四次应用。

> **补充** 现代深度模型（CNN/Transformer 的序列标注）在这几类任务上大多已经超过 HMM，但它们仍然共用 HMM 的两个遗产：**（1）把序列切成「段」而不是逐点独立预测**；**（2）用动态规划保证输出路径合法**（CRF 层就是 HMM 的判别式版本）。学 HMM 不是为了用 HMM，是为了看懂这两个约束从哪来。

## 订正

**1. 第 51 页「蛋白质家族/结构域搜索 | profile HMM 的匹配/插入/缺失状态」这一行是全课件唯一提到 profile HMM 结构的地方，但没有任何展开。**

表里出现 $M/I/D$ 三个字母却没有定义，前面的 21–24 节又全是「罐子模型」那种抽象状态。读者到这里会出现断层：知道 HMM 有 $N$ 个状态，但不知道 profile HMM 的状态为什么是 $3L$ 个、$D$ 为什么不发射。

本篇 25.2 补上了这个缺口。若考试只按课件范围出题，这一段可以不背；但若下一讲直接讲 HMMER，这一节是必需的。

**2. 第 2 页引 Haussler et al. (1993) 时只给了「Protein modeling using hidden Markov models: Analysis of globins」，没说是**哪一步**的工作。**

那篇是**用 HMM 给珠蛋白家族建模**（建 profile HMM 并做家族内部分类），不是提出 HMMER 的论文。HMMER 软件本身的引用应是 Eddy 的系列文章（1995 起）。写报告时别把两者混成一条引用。

**3. 第 51 页把「HMMER」写成「HMMER：远缘同源检测与家族注释」，只给了结论没给边界。**

HMMER 强在**有家族模型可比**的场景（Pfam/InterPro 已建好模型）；若手里只有一个新蛋白、没有对应的家族 HMM，仍然要先用 BLAST/PSI-BLAST 找同源、建比对，再用 `hmmbuild` 建自己的模型。工具链是串起来的，不是二选一。
