> 本节两个高频考点：**① SW 与 NW 的两点差别**；**② 仿射罚分下的 Gotoh 三矩阵**。

## 4.1 Smith-Waterman 局部比对

> T. F. Smith & M. S. Waterman, *Identification of common molecular subsequences.* J Mol Biol (1981) **147**, 195–197.

- **Temple F. Smith** (1939–)，Boston University
- **Michael S. Waterman** (1942–)，University of Southern California (USC)

**目标**：生成**局部最优**比对 —— 只找两条序列中**最优的那些相似片段**，允许序列的前后两端"不比对"（即自由悬空）。

**生物学动机**：两个蛋白可能只在**某个结构域**上同源（如都含 BIR 结构域），全长比对会被无关区域淹没；或者一条短序列要在一个长序列里找匹配。

---

## 4.2 SW 与 NW 的两点差别（**必背原文级**）

### 差别 1：得分不允许为负（Non-negative scores）
$$F(i,j) = \max\begin{cases} F(i-1,\,j-1) + s(x_i, y_j) \\ F(i-1,\,j) + g \\ F(i,\,j-1) + g \\ \mathbf{0} & \text{← SW 多出来的第 4 项} \end{cases}$$

- 初始化时，按迭代公式，**第一行第一列全部为 0**：
$$F(i,0) = F(0,j) = 0$$
- 含义：**当一条比对的累积得分降到 0 时，就"重新开始"** —— 相当于丢弃前面这段不相似的前缀。

### 差别 2：回溯的起点与终点不同

> **回溯从矩阵中得分最高的单元格开始，一直做到遇到得分为 0 的单元格为止。**
> 即：从表格中找到**得分最大的那一项**开始回溯，直到**得分为 0** 的那一项结束。

| | NW（全局） | SW（局部） |
|---|---|---|
| 初始化 | $F(i,0)=ig$，$F(0,j)=jg$ | **全 0** |
| 递推中是否含 0 | 否 | **是（不允许负分）** |
| 回溯起点 | 固定 $F(n,m)$ | **全矩阵最大值**（可能有多处） |
| 回溯终点 | 固定 $F(0,0)$ | **任一得分为 0 的格子** |
| 结果 | 覆盖全文的比对 | 一段（可能带少量空位）的局部比对 |
| 复杂度 | $O(mn)$ | $O(mn)$ |

> 常见误区：SW 的第一行第一列不是 $0, -2, -4, \dots$，而是**全 0**。

## 4.3 SW 完整算例（**建议按此格式答题**）

**参数**：$s(x_i,y_j)=1$ 若相同、$-1$ 若不同；空位 $g=-2$（打开 = 扩展）。
$x = \text{CGATTGAC}$（长 8），$y = \text{TTGACG}$（长 6）。

### Step 1 填充矩阵（第一行第一列全 0，所有值 ≥ 0）

|  | — | T | T | G | A | C | G |
|---|---|---|---|---|---|---|---|
| **—** | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| **C** | 0 | 0 | 0 | 0 | 0 | 1 | 0 |
| **G** | 0 | 0 | 0 | 1 | 0 | 0 | 2 |
| **A** | 0 | 0 | 0 | 0 | 2 | 0 | 0 |
| **T** | 0 | 1 | 1 | 0 | 0 | 1 | 0 |
| **T** | 0 | 1 | **2** | 0 | 0 | 0 | 0 |
| **G** | 0 | 0 | 0 | **3** | 1 | 0 | 1 |
| **A** | 0 | 0 | 0 | 1 | **4** | 2 | 0 |
| **C** | 0 | 0 | 0 | 0 | 2 | **5** | 3 |

### Step 2 回溯

- **最大元**：$F(8,5)=5$（唯一）
- 沿对角线回退，直到 **$F(3,2)=0$** 停止

### 结果

```
x: TTGAC
y: TTGAC
```
局部比对得分 = **5**，无空位。核算：5 个相同 × 1 = 5 ✓

> 注意这条结果**同时演示了 SW 的价值**：$x$ 前面的 `CGA` 与 $y$ 后面的 `G` 被完全忽略 —— 全局比对会强迫它们参与对齐并拉低得分。

### 课件课内例题（参数：$s=1/-1$，$g=-2$）

$x$、$y$ 的两条序列在 PPT 里是图形对象，文本层没能提取出来；但回溯过程给出了明确的最优结果：

```
x: GAAG          （课件逐步显示 x: G → AG → AAG）
y:  AAG
```
即局部最优片段为 **AAG / AAG**，得分 3。

> 考试时以同一套参数自行填表即可，方法完全一致。

## 4.4 仿射罚分（Affine Gap Penalty）

### 4.4.1 定义

```
MVLSEGEWQLVLHVWAKVEADVAGHGQDILIRLFKSHPETLEKFDRVKHLKTEAEMKASEDLK
SLEWMVNWAMVNWAAVV-------DDFYQELFKAHPEYQNKFGFFKAHPEYQNKFGFKGVALG
                   ↑↑↑↑↑↑↑
                 gap extension
                 ↑ gap opening
```

$$w(k) = a + b \times (k-1) \qquad (k \ge 1;\; a, b < 0)$$

| 符号 | 含义 |
|---|---|
| $k$ | **连续空位的长度** |
| $a$ | **空位打开罚分 (gap opening penalty)** |
| $b$ | **空位扩展罚分 (gap extension penalty)** |

**两种情形（必考辨析）**：

| 情形 | 名称 | 每列空位代价 |
|---|---|---|
| $a = b$ | **线性罚分 (linear gap penalty)** | 每列相同（等同于前面 NW/SW 里那个常数 $g$） |
| $a \ne b$ | **仿射罚分 (affine gap penalty)** | 第一列 $a$，之后每列 $b$ |

> 一般 $b \le a$（延长比打开便宜）。生物学含义：一次插入/缺失事件一次性产生一段 indel，所以"打开"要罚重。

### 4.4.2 有了仿射罚分，DP 需要 3 个矩阵（Gotoh 算法）

> O. Gotoh. *An improved algorithm for matching biological sequences.* J Mol Biol **162**, 705–708 (1982).

**问题**：原来 $F(i,j)$ 只有"一个状态"，而仿射罚分下"当前位置是空位打开还是空位延长"必须区分开来 —— **因为代价不一样，不能合并成一个状态**。

**解决方案：用 3 个矩阵记录 3 种状态**：

| 矩阵 | 含义 |
|---|---|
| $M(i,j)$ | 最优得分，条件是 **$x[i]$ 与 $y[j]$ 对齐**（配对状态） |
| $I_x(i,j)$ | 最优得分，条件是 **$x[i]$ 与空位对齐**（$x$ 有残基、$y$ 是 gap） |
| $I_y(i,j)$ | 最优得分，条件是 **$y[j]$ 与空位对齐**（$y$ 有残基、$x$ 是 gap） |

> 课件原话：**"每一个矩阵值表现为一个状态；箭头表示状态间的转移。一个比对就是一条由状态节点连接起来的路径。"** —— 这是"状态机 / 有向图"视角，把二维表理解成网格图（lattice），比对就是图上一条路径。

### 4.4.3 递推公式（**必须默写**）

设 $d$ = gap opening，$e$ = gap extension：

$$\boxed{
\begin{aligned}
M(i,j) &= \max\big\{\,M(i-1,j-1),\;\; I_x(i-1,j-1),\;\; I_y(i-1,j-1)\,\big\} \;+\; s(x_i,\,y_j)\\[4pt]
I_x(i,j) &= \max\big\{\,M(i-1,j) + d,\;\; I_x(i-1,j) + e \,\big\}\\[4pt]
I_y(i,j) &= \max\big\{\,M(i,j-1) + d,\;\; I_y(i,j-1) + e \,\big\}
\end{aligned}}$$

**读法**：
- $M$ 可以由**任意一个**上一状态转移过来（对角线方向），再加替换分；
- $I_x$ 只能由「$M$ 然后打开」（$+d$）或「$I_x$ 然后延长」（$+e$）得到；
- $I_y$ 同理，方向是向左。

### 4.4.4 初始化（**NW + 仿射罚分**）

$$M(0,0)=0,\qquad M(i,0)=M(0,j)=-\infty$$
$$I_x(i,0) = d + (i-1)e,\qquad I_x(0,j) = -\infty$$
$$I_y(0,j) = d + (j-1)e,\qquad I_y(i,0) = -\infty$$

> 为什么 $M(i,0) = -\infty$？因为"$x[i]$ 与 $y[0]$ 配对"是非法的 —— 没有残基可配。用 $-\infty$ 表示这个状态不可达。

### 4.4.5 回溯

> **从 $M(m,n)$、$I_x(m,n)$、$I_y(m,n)$ 三者中的最大值出发；到 $M(0,0)$、$I_x(0,0)$、$I_y(0,0)$ 中的任意一个停止。**

即：从**三个矩阵右下角的最大者**出发，沿状态转移箭头反向走，直到**任一矩阵的 $(0,0)$**。

**复杂度：仍为 $O(mn)$**（这是 Gotoh 算法的贡献 —— 仿射罚分**不增加时间复杂度的阶**，只是常数因子约 3 倍）。

## 4.5 仿射罚分完整算例（课件原例，已复算）

> $x = \text{AAT}$，$y = \text{ACACT}$
> $s = 1$（相同）/ $-1$（不同）；$a = d = -3$，$b = e = -1$

### 三个矩阵

**$M$ —— $x[i]$ 与 $y[j]$ 对齐**

|  | — | A | C | A | C | T |
|---|---|---|---|---|---|---|
| **—** | 0 | −∞ | −∞ | −∞ | −∞ | −∞ |
| **A** | −∞ | **1** | −4 | −3 | −6 | −7 |
| **A** | −∞ | −2 | **0** | −1 | −4 | −5 |
| **T** | −∞ | −5 | −3 | −1 | −2 | **−3** |

**$I_x$ —— $x[i]$ 与空位对齐**

|  | — | A | C | A | C | T |
|---|---|---|---|---|---|---|
| **—** | −∞ | −∞ | −∞ | −∞ | −∞ | −∞ |
| **A** | −3 | −∞ | −∞ | −∞ | −∞ | −∞ |
| **A** | −4 | −2 | −7 | −6 | −9 | −10 |
| **T** | −5 | −3 | −3 | −4 | −7 | −8 |

**$I_y$ —— $y[j]$ 与空位对齐**

|  | — | A | C | A | C | T |
|---|---|---|---|---|---|---|
| **—** | −∞ | −3 | −4 | −5 | −6 | −7 |
| **A** | −∞ | −∞ | −2 | −3 | −4 | −5 |
| **A** | −∞ | −∞ | −5 | −3 | −4 | −5 |
| **T** | −∞ | −∞ | −8 | −6 | −4 | **−5** |

**最优值**：$\max\{M(3,5), I_x(3,5), I_y(3,5)\} = \max\{-3, -8, -5\} = \mathbf{-3}$（取 $M(3,5)$）

### 回溯得到的等优比对（课件给出 3 条，已逐条用打分函数验算 = −3）

```
x: A--AT        x: AA--T        x: A-A-T
y: ACACT        y: ACACT        y: ACACT
```

逐条核算（以 `A--AT / ACACT` 为例）：
- 配对部分：A/A = +1，A/C = −1，T/T = +1 → **+1**
- 一个长度为 2 的空位：$a + b(k-1) = -3 + (-1)(2-1) = \mathbf{-4}$
- 合计 $1 - 4 = \mathbf{-3}$ ✓

> 判分差异的关键：如果误用**线性罚分**（每列 −3），这两列空位会被罚 −6，最优解就会变成别的。**这正是仿射罚分存在的意义。**

## 4.6 带仿射罚分的局部比对（SW + affine）

就是把 4.4 的三矩阵递推与 SW 的"不为负 + 从最大元回溯到 0"结合：

### 初始化
$$M(i,0) = M(0,j) = 0,\qquad I_x(i,0) = I_x(0,j) = -\infty,\qquad I_y(i,0) = I_y(0,j) = -\infty$$

> 与 NW 版的关键差别：$M$ 的边界**是 0 而不是 $-\infty$**（允许局部比对从任意位置"零起点"开始），而 $I_x/I_y$ 的边界仍然是 $-\infty$（空位状态不能凭空开始）。

### 回溯
> **从 $M(i,j)$ 的最大值出发；到 $M(i,j)=0$ 处停止。**

即从**全 $M$ 矩阵的最大元**出发，沿状态箭头回退，直到遇到 **$M = 0$**。

**复杂度**：仍 $O(mn)$，空间 $O(3mn)$。

### 4.7.2 Biopython（课件给了完整代码）

```python
# 安装：pip install biopython   或   conda install biopython
from Bio import Align
from Bio.Seq import Seq

seq1 = Seq("ACCGGT")
seq2 = Seq("ACGT")

# ---- 全局比对 ----
aligner = Align.PairwiseAligner()
aligner.mode = "global"
alignments = aligner.align(seq1, seq2)

# ---- 局部比对 ----
aligner.mode = "local"
aligner.substitution_matrix = Align.substitution_matrices.load("BLOSUM62")
aligner.open_gap_score = -10
aligner.extend_gap_score = -1
test_alignments = aligner.align(seq1, seq2)
```

> 课件注释原文：*"BLOSUM62 指的是 `Bio.Align.substitution_matrices` 中加载的标准打分矩阵，用于提供匹配分数。−10 表示空位开放罚分，−1 表示空位扩展罚分。"*
> 也就是说：Biopython 用 **`mode="global"/"local"`** 切换 NW/SW，用 **`open_gap_score` / `extend_gap_score`** 分别指定 $a$ 和 $b$ —— 这正好对应本节的两种罚分。**默认的 gap opening −10 / extension −1 就是 NCBI BLAST 的默认值。**

## 4.9 常见考点问答

**Q：什么时候用全局比对，什么时候用局部比对？**
A：近似**全长同源**（同一基因在两个物种中的直系同源）→ 全局；只共享**某个结构域/保守片段**，或长度差异悬殊、只找一段匹配 → 局部。局部比对天然更宽容，因此**更容易得到显著结果**，但可能掩盖整体关系。

**Q：SW 一定比 NW 好吗？**
A：不是。SW 的得分总是 ≥ 对应的全局可得局部得分，但**局部最优 ≠ 生物学上正确**。若两条序列确实全长同源，NW 给出的整体信息更完整。

**Q：为什么仿射罚分要用 3 个矩阵？用 1 个不行吗？**
A：不行。因为"当前位置的空位代价"取决于"上一个位置是不是空位"（打开 vs 延长），是**有记忆的**（一阶马尔可夫）。单矩阵无法携带这个状态信息。Gotoh 的做法是把状态显式拆开，代价是把空间变成 3 倍，时间复杂度阶不变。

**Q：SW 的 DP 矩阵里会不会出现负数？**
A：**不会**（含 0 项，下限是 0）。这是它最显著的外观特征，也是最快的手算自检手段 —— 只要出现负数，就填错了。
