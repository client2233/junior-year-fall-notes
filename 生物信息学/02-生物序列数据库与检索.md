# 02 生物序列数据的检索与获取

## 2.1 数据库的两大分类维度

### 2.1.1 一级数据库 vs 二级数据库

| | 一级数据库（archive 档案库） | 二级数据库（curated / 加工库） |
|---|---|---|
| 内容 | 实验室操作得到的**原始数据**（测序序列、X 射线衍射的三维结构） | 在一级库信息基础上**计算加工 + 人为注释**后的结果 |
| 附带的说明 | 物种、类型、文献出处等基本说明 | 功能注释、结构域、家族、通路、互作等衍生信息 |
| 典型例子 | **GenBank、EMBL(ENA)、DDBJ**（核酸）；**PDB**（蛋白结构） | **RefSeq**（同物种同基因所有 mRNA 的**一致序列 consensus**）、**UniProtKB**、**SCOP、CATH、Pfam、GO、KEGG** |

> 记忆法：一级库=**原始观测**，二级库=**加工结论**。

### 2.1.2 公共数据库 vs 专业数据库

- **公共数据库**：大多数蛋白序列是把核酸序列的 **CDS 区翻译**后，再用 BLAST 做相似性分析，**主观人为**地给序列加上"蛋白质产物名称及功能注释"。**它们不是通过实验确定的**。
  - 典型：**UniProt 的 KnowledgeBase (UniProtKB)** = 人工校正注释的高质量 **Swiss-Prot** + 计算预测得到功能信息的 **TrEMBL**，是**目前最大的二级蛋白质序列数据库**。
- **专业数据库**：满足特定研究团体的需求，如专门的小 RNA 库、基因表达谱库、以及果蝇/线虫/拟南芥等模式生物的专业库。

## 2.2 核酸数据库

### 2.2.1 四大核酸数据库（**必背名字+组织**）

| 数据库 | 所属 | 网址 |
|---|---|---|
| **GenBank** | NCBI（美国） | https://www.ncbi.nlm.nih.gov/ |
| **ENA** (European Nucleotide Archive) | EMBL-EBI（欧洲） | https://www.ebi.ac.uk/ena |
| **DDBJ** | DNA Databank of Japan（日本） | https://www.ddbj.nig.ac.jp/ |
| **NGDC / GSA** (Genome Sequence Archive) | 国家基因组科学数据中心（中国，2019） | https://ngdc.cncb.ac.cn/ |

前三个通过 **INSDC**（International Nucleotide Sequence Database Collaboration, http://www.insdc.org/）**每日交换数据**，本质上是一套数据的三个镜像入口。

### 2.2.2 需要记住的数量级（课件明确要求记住）

| 项目 | 数量 |
|---|---|
| GenBank 核酸序列 | **约 2.67 亿**（267 million）条，约 8.2 万亿碱基对 |
| TrEMBL 蛋白序列 | **约 2.46 亿**（245,871,724）条，约 857 亿氨基酸 |
| Swiss-Prot 蛋白条目 | **约 57.6 万**（575,748）条（Release 2026_03, 2026-09-02；209,017,843 个氨基酸） |
| PDB 实验测定结构 | **约 26 万**（260,089）个（RCSB PDB, 2026-09） |
| AlphaFold DB 预测结构 | **约 2.15 亿**（214,683,829）个，含 48 个完整蛋白质组 |
| 自然界蛋白折叠类型数 | **约 2000** 种（有限！） |

课件用了一个非常生动的对比：
> 人脑神经元约 **1000 亿**；银河系恒星约 **1000–2000 亿**。
> —— 而 GenBank 里的碱基对数量已经到了 **万亿**量级。

### 2.2.3 Sequence–Structure Gap（核心 motivation，必考论述）

已知**序列**与已知**结构 / 功能**之间存在巨大鸿沟：

- 只有 **0.23%** 的已知蛋白序列有已知功能；只有 **0.11%** 有已知结构。
- 课件给出的倍数：序列数 / 结构数 ≈ **845 倍**（核酸 vs 结构），蛋白序列 vs 结构约 **78 倍**，TrEMBL vs Swiss-Prot 约 **21 倍**。

**如何填补这道鸿沟？** —— 这正是后面"序列比对 → 同源建模 / 模板法预测结构"存在的理由。因为**很多不同序列采用相似的 fold**（总量约 2000 种），所以"找同源"就能"借结构"。

### 2.2.4 核酸二级数据库

| 类型 | 数据库 |
|---|---|
| 非编码 RNA 综合库 | **RNAcentral** |
| microRNA | **miRBase** |
| 环状 RNA | **circBase、CIRCpedia** |
| ncRNA 相互作用 | **NPInter** |
| 转运 RNA | **GtRNAdb** |
| 基因参考序列 | **RefSeq** |
| 基因组 | **Ensembl** |

**RefSeq 的标识符前缀（极易考填空）**：

| 前缀 | 含义 |
|---|---|
| `NM_` | 人工审编的 mRNA（RefSeq curated transcript） |
| `XM_` | 自动注释的 mRNA（predicted model） |
| `NP_` | 人工审编的蛋白质 |
| `XP_` | 自动注释的蛋白质 |
| `NC_` | 染色体（genomic chromosome） |
| `NR_` / `XR_` | 非编码 RNA（curated / predicted） |

> 记忆法：**N** = curated（确定），**X** = predicted（预测）；**M** = mRNA，**P** = protein，**C** = chromosome。

**NCBI Gene**：序列来自 RefSeq，提供详细注释（基因组定位、基因名、蛋白名、基因结构）。

### 2.2.5 Ensembl

基因组数据库（http://www.ensembl.org/），提供基因结构、比较基因组、变异等注释。

## 2.3 蛋白质数据库

### 2.3.1 UniProtKB 的构成

```
UniProt KnowledgeBase (UniProtKB)
├── Swiss-Prot  人工注释 + 人工审核（高质量、条目少，~57.6 万）
└── TrEMBL      自动程序化注释（条目极多，~2.46 亿）
```

**序列来源**：UniProtKB 提供的蛋白序列中 **>95% 来自提交给 EMBL/GenBank/DDBJ 的 CDS 的翻译**。这些 CDS 由**基因预测程序**产生或**实验证明**。

### 2.3.2 蛋白质相关的其他数据库（分类记忆）

| 类别 | 数据库 |
|---|---|
| 蛋白序列 | **UniProtKB** (Swiss-Prot / TrEMBL) |
| 蛋白结构 & 结构分类 | **PDB、SCOP、CATH** |
| 蛋白结构预测 | **AlphaFold DB** |
| 蛋白质组学（质谱数据） | **PRIDE** (Proteomics Identification Database) |
| 蛋白质功能 / 家族 / 结构域 | **Prosite、Pfam、InterPro** |
| 分子互作 | **BioGRID、DIP、IntAct、STRING** |
| 代谢途径 | **KEGG、MANET** |
| 蛋白—配体结合 | **BioLiP** |
| 药物小分子 | **DrugBank** |
| 分析平台 | **ExPASy** (Expert Protein Analysis System) |

> 蛋白质组学（proteomics）= 一种基因组所表达的**全套蛋白质**。

### 2.3.3 PDB（蛋白质结构数据库）

- 第一个原子级蛋白结构：**血红蛋白 Haemoglobin，PDB ID `1gzx`**，1962 年 Perutz 与 Kendrew 获诺贝尔化学奖。
- 数据量（2026-09）：**260,089** 个实验测定结构 + 1,062,058 个计算模型。
- 可视化软件：**RasMol**（http://www.openrasmol.org/）、**PyMOL**（https://pymol.org/）、以及课件中提到的 RasWin。

### 2.3.4 AlphaFold DB

- 平台：https://alphafold.ebi.ac.uk/
- **214,683,829** 个结构，含 **48 个完整蛋白质组**可批量下载。
- 2026 年更新（EMBL-EBI, 2026-05）：已随 UniProt 2025_03 同步，新增蛋白复合物预测 —— 约 **170 万个**高置信度同源二聚体（homodimer）、约 **8 万个**高置信度异源二聚体（heterodimer），另有 810 万个低置信度异源二聚体可批量下载。

> 考点定位：AlphaFold 让"序列-结构鸿沟"在**预测层面**被大幅填平，但**功能**与**实验验证**依然依赖实验。

### 2.3.5 结构分类数据库 SCOP 与 CATH（**易混，重点辨析**）

| | SCOP | CATH |
|---|---|---|
| 全称 | Structural Classification of Proteins | **(C)**lass, **(A)**rchitecture, **(T)**opology/fold, **(H)**omologous superfamily |
| 层级 | Class → Fold → Superfamily → Family | Class → Architecture → Topology → Homologous superfamily |
| 判定 | 以**人工专家判断**的进化关系为主 | 以**自动算法**为主 |
| 网址 | http://scop.mrc-lmb.cam.ac.uk/scop/ | https://www.cathdb.info/ |

**蛋白质折叠类型总数是有限的（重要结论）**：
> 尽管 PDB 条目数**指数增长**，但**每年新增 fold 的速度在持续下降**。这说明自然界蛋白的 fold 数目应该是**有限的（估计约 2000 种）**。**许多不同的序列采用相似的 fold —— 这正是"基于模板的结构预测算法"成立的基础。**

|---|---|---|

| **ExPASy** | SIB 瑞士生物信息研究所的分析平台 | |

> 课件提示：可以翻阅《核酸研究》（NAR）每年的数据库专辑，里面还能找到更多这类数据库。

## 2.5 数据库文件类型与格式

### 2.5.1 三类文件的定位

| 格式 | 用途 |
|---|---|
| **GenBank 格式** | 核酸序列 + 详尽注释 |
| **FASTA 格式** | 序列本身（DNA/RNA/蛋白通用），最通用的交换格式 |
| **PDB 格式** | 三维结构（原子坐标） |

### 2.5.2 GenBank 格式的字段（必考）

| 字段 | 含义 |
|---|---|
| `LOCUS` | 序列名 + **序列长度** + **数据类型**（DNA/mRNA/aa） |
| `DEFINITION` | **标题**（一句话描述） |
| `ACCESSION` | **Accession number**（主登录号，稳定不变） |
| `VERSION` | **版本号**（如 `NM_001168.3`，末位 `.3` 为版本） |
| `GI` | GI number（历史遗留的唯一编号） |
| `ORGANISM` / `SOURCE` | 物种 / 来源 |
| `FEATURES` | 注释特征（CDS、exon、promoter 等） |
| `ORIGIN` | 序列本体 |

### 2.5.3 FASTA 格式

```
>标识符 描述行
ATGCGTACGTTAGCTAGCTAGCTAGCATCG...
```
- `>` 开头的行为**描述行**，第一个空格之前的部分是**标识符**。
- 序列可任意换行，程序读取时忽略换行。
- 这是 BLAST / 比对程序的标准输入输出格式。

### 2.5.4 UniProt 格式

关键字段：`ID`、`AC`（**Accession number**）、`DE`（描述）、`GN`（基因名）、`OS`（物种）、`SQ`（序列）等，另有大量**功能注释行**（如 `FT` 特征、`CC` 注释、`DR` 交叉引用）。

### 2.5.5 PDB 文件格式

- 核心记录：`ATOM`（原子坐标）、`HETATM`（非标准残基/配体）、`SEQRES`（序列）、`HEADER`、`REMARK` 等。
- 官方文档：http://www.wwpdb.org/documentation/file-format

## 2.6 一次完整检索流程（课件核心案例 —— 必考综合题）

### 题目
用实验方法（如酵母双杂交）发现了与有丝分裂期某蛋白可能互作的基因，测序得到以 `CCCCTGCCTGG...TTGAGGCCTCTGGC` 开头的一段序列。

**问题**：这是哪个基因？编码的蛋白序列？有没有保守功能结构域？功能是什么？在真核中保守吗？有没有三级结构？

### 检索路线与结论

```
① 序列 → NCBI BLAST (blastn / Megablast)
        「Megablast: 找基因序列」
        ↓
   核酸序列标识符： NM_001168.3
   基因： 人的 BIRC5 (Survivin)
   染色体定位： 17q25.3
   基因组坐标： 78214253–78225635
   初步功能： 凋亡、细胞分裂、染色体分离

② 取蛋白序列（142 aa）
        ↓
   蛋白序列标识符： NP_001159.2

③ PHI-BLAST 找结构域（填入蛋白 FASTA 序列）
        ↓
   结论： BIRC5 具有保守的功能结构域 BIR (Baculovirus IAP Repeat)

④ ExPASy → 蛋白条目
   UniProt ID： O15392
   信息： 翻译后修饰等

⑤ KEGG Pathway
        ↓
   参与通路： 癌症、直肠癌、乙肝 (Hepatitis B, hsa05161)

⑥ 找同源序列（在酵母中做 BLAST 比对）
        ↓
   酵母同源序列： BIR1 (UniProt P47134)  ← 注意是「可能」

⑦ PDB 三级结构
        ↓
   PDB ID： 1E31
```

### 最终六条结论（**可作为简答题标准答案背诵**）

1. 该基因为人类 **BIRC5**，染色体定位 **17q25.3**，基因组坐标 **78214253–78225635**；核酸标识符 **NM_001168.3**。
2. 人的 BIRC5 蛋白质含 **142 个氨基酸**，序列标识符 **NP_001159.2**。
3. BIRC5 具有保守的功能结构域 **BIR**。
4. 细胞亚定位：**中心粒、染色体、胞质**；功能：
   - (1) 在肿瘤形成过程中可能起一定作用
   - (2) **阻碍 G2/M 期的细胞编程性凋亡**
   - (3) **染色体乘客复合物 CPC (Chromosomal Passenger Complex)** 的成员之一
   - (4) 参与的生物学通路：癌症、直肠癌、乙肝
5. 人的 BIRC5 在酵母中的同源序列**可能是 BIR1**。
6. BIRC5 的三级结构已知，PDB 标识符 **1E31**。

### 这道题考查的能力（也是简答题的分析框架）
> **「给一段未知序列 → 用数据库与搜索工具层层递进：先定基因 → 再取蛋白 → 再找结构域 → 再看通路 → 再找同源 → 最后取结构」**
> 每一步都要能说出**用哪个数据库、哪个工具、得到什么类型的标识符**。

**Q1**：在小鼠（*Mus musculus*）中实验鉴定到一个有丝分裂相关基因 X，测序得到一段部分序列（`GATGAGCTGCTTATCCTACAAC...GAGGACATCCT`）。要求回答：

1. 基因 X 在小鼠中的名称？在 GenBank 中的 accession number 与小鼠基因组坐标。
2. 它在**人**中的同源基因及 accession number。
3. 人的该基因的**蛋白产物**：功能、亚细胞定位、是否为酶、是否有保守功能结构域。
4. 该基因在**酵母**中是否保守？如是，找出潜在同源物。
5. 该基因在**人**（不是小鼠）中的三级结构信息，以及 PDB 登录号。
