# 01 生物学基础（自修）

## 1.1 中心法则（Central Dogma）

```
       复制 (replication)
DNA ──────────────→ DNA
 │
 │ 转录 (transcription)
 ↓
RNA ──────→ 蛋白质
      翻译 (translation)
```

特殊情形：**逆转录**（RNA→DNA，逆转录病毒）与 **RNA 复制**（RNA→RNA）。课件中反复出现的三张图就是"复制 / 转录 / 翻译"。

对应的序列数据类型（考选择/填空高频）：

| 过程 | 产物 | 比对时的字母表 |
|---|---|---|
| 复制 | DNA | A T G C（脱氧核糖核苷酸） |
| 转录 | RNA | A U G C（核糖核苷酸，U 代替 T） |
| 翻译 | 蛋白质（肽链） | 20 种氨基酸，单字母码 ACDEFGHIKLMNPQRSTVWY |

## 1.2 DNA

### 1.2.1 历史线索（可能考填空）

- **1866**：Mendel 开创遗传学（豌豆实验）。
- **20 世纪初**：Morgan 等发展染色体遗传学说。
- **1944**：Oswald Avery 用**肺炎双球菌体外转化实验**证明 **DNA 是遗传物质**（此前普遍认为是蛋白质）。
- **1953**：Watson & Crick 在 Franklin 与 Wilkins 的 **X 射线衍射**数据基础上提出 **DNA 双螺旋结构**（Nature 171:737-738）。

### 1.2.2 单体与连接方式

构成 DNA 链的单体是**脱氧核糖核苷酸**，由三部分组成：磷酸 + 脱氧核糖 + 碱基。

| 碱基 | 英文 | 单字母 |
|---|---|---|
| 胞嘧啶 | Cytosine | C |
| 鸟嘌呤 | Guanine | G |
| 胸腺嘧啶 | Thymine | T |
| 腺嘌呤 | Adenine | A |

**互补配对原则**（氢键）：A = T（2 个氢键），C ≡ G（3 个氢键）。这是它最常被考的结论，也是 BLAST 能在双链上任一条链搜索的基础。

单体之间通过**磷酸二酯键**连接成链；磷酸与戊糖交替构成**骨架**，碱基在**内部**配对。

### 1.2.3 DNA 序列的方向性（**最容易错的细节**）

$$\text{5'-TCA-3'} \quad\Longleftrightarrow\quad \text{3'-AGT-5'}$$

- **5' 端是磷酸基团，3' 端是羟基（−OH）**。合成方向永远是 5'→3'。
- 反向互补链的方向相反，因此"在另一条链上找"等价于**取反向互补**后再搜索。
- 双螺旋是**右手螺旋**。

### 1.2.4 DNA 的高级结构（四级）

| 层级 | 内容 |
|---|---|
| 一级结构 | 碱基的排列顺序（就是"序列"本身） |
| 二级结构 | 双螺旋结构 |
| 更高级结构 | 超螺旋（supercoiling）与染色体的包装 |

- **负超螺旋**有助于 DNA 松弛、解旋（课件备注）。**30 nm 纤丝为左手螺旋**。
- 染色体 = chromosome。

## 1.3 基因的转录

**定义**：以 DNA 的**一条链**为模板，按照碱基互补配对原则，在 **RNA 聚合酶**作用下合成 RNA 的过程。转录有**正调控**和**负调控**之分。

### 1.3.1 真核生物基因的结构与元件（名词题重灾区）

| 元件 | 定义要点 |
|---|---|
| **编码区 (coding region)** | 具有翻译成蛋白潜力的 DNA 序列 |
| **非编码区 (non-coding region)** | 不翻译成蛋白，但发挥重要调控作用；**其序列比例远大于编码区** |
| **启动子 (promoter)** | 位于编码区**上游**，是 RNA 聚合酶和转录因子识别、组装的区域；转录起始于启动子 **3' 端的转录起始位点（TSS）**。不同启动子基础转录效率差异很大，但存在**共有碱基序列**（consensus，如 TATA box） |
| **终止子 (terminator)** | 位于转录产物末端，提供转录停止信号的 DNA 序列 |
| **增强子 (enhancer)** | 通过与转录因子相互作用提高转录效率；**位置不固定**（可在上游、下游、内含子中，甚至很远） |

### 1.3.2 转录终止与新生 RNA 链的加工

真核 mRNA 的三步加工：
1. **5' 端加帽子 (5' cap)**
2. **3' 端加尾巴 (poly-A tail)**
3. **内含子剪除 + 外显子拼接 (splicing)**

### 1.3.3 剪接、CDS、UTR

- 真核生物编码基因多为**断裂基因**：编码蛋白的 DNA 序列（**外显子 exon**）被若干长度不一的**内含子 intron** 分隔。
- **CDS (coding DNA sequence)**：成熟 mRNA 上从**起始密码子到终止密码子**的一段序列。
- **UTR (untranslational region)**：CDS 两端的非翻译区，含有**调控作用**。

### 1.3.4 ORF vs CDS（**必考辨析**）

| | CDS | ORF |
|---|---|---|
| 性质 | **已知**：一个基因上确确实实翻译成蛋白质的区段 | **预测**：任意一段"起于 ATG、止于终止子"的序列 |
| 存在性 | 一定真实存在 | **可能不是真实存在的 DNA 序列** |
| 数量关系 | 一条 CDS 只在**一个**读码框里 | 同一段序列按不同读码框可得 3 种 ORF（正链）/ 6 种（双链），**体内真正翻译的只有一种** |

> 记忆锚点：**CDS 是事实，ORF 是猜测。**

### 1.3.5 原核生物转录的三个特点（对比题常客）

1. **多顺反子**：一个转录单位含多个结构基因，共享一套启动子和终止子，随后翻译成各自独立的蛋白。
2. **无帽无尾、无内含子**：原核 mRNA 不存在复杂的加帽加尾，也没有内含子剪接。
3. **转录与翻译同空间进行**：无成熟 mRNA 出核步骤，转录未结束翻译已开始；因此原核 mRNA **半衰期远短于真核 mRNA**。

### 1.3.6 非编码 RNA（ncRNA）

rRNA、tRNA，以及 microRNA、siRNA、snRNA、snoRNA、circRNA、piRNA、lncRNA……以及 **ceRNA**（竞争性内源 RNA，通过 miRNA 应答元件互相"吸附"miRNA 来调控）。

## 1.4 翻译：从 RNA 到蛋白质

### 1.4.1 氨基酸

每个氨基酸 = **共有部分（氨基 + 羧基 + 中心碳）** + **不同的 R 基**。分类依据就是 R 基的化学性质（极性/带电/疏水/芳香/特殊）。

### 1.4.2 肽链的形成与二硫键

- 氨基酸通过**肽键**脱水缩合成肽链（蛋白质一级结构）。
- **二硫键**：半胱氨酸 + 半胱氨酸 = 胱氨酸（−S−S−），是稳定三级/四级结构的重要**共价**键。

### 1.4.3 蛋白质结构层级（必背）

| 层级 | 定义 | 主要作用力 |
|---|---|---|
| **一级结构** | 氨基酸的排列顺序（肽链） | 肽键（共价） |
| **二级结构** | 局部规则构象：**α-螺旋、β-折叠（β-pleated sheet）、转角** | **主链之间的氢键** |
| **三级结构** | 整条肽链的空间折叠（形成结构域） | 疏水作用、氢键、离子键、**二硫键**等（"新增键"） |
| **四级结构** | 多个亚基（subunit）组装成的复合体 | 亚基间非共价作用 |

课件中的演进顺序：一级结构 →（折叠 folding）→ 二级 →（进一步折叠）→ 三级 →（组装）→ 四级。

### 1.4.4 测定蛋白质空间结构的方法（考选择）

| 方法 | 英文 | 特点 |
|---|---|---|
| **X 射线衍射** | X-ray crystallography | 精度最高、最主流，但需**晶体**，是 PDB 中结构的主要来源 |
| **电镜** | electron microscopy (Cryo-EM) | 无需晶体，适合**大分子复合物**，近年分辨率大幅提升 |
| **核磁共振** | NMR spectroscopy | 在**溶液**中测，能给出动态信息，但受分子量限制（一般 < 30–40 kDa） |

> 补充：这些实验方法成本高、速度慢，这正是 **AlphaFold 结构预测数据库**存在的意义（见 [[02-生物序列数据库与检索]]）。
