## 9.1 PDB 文件与按列格式

**4HHB**：人脱氧血红蛋白（Fermi & Perutz 1984），$\alpha_2\beta_2$ 四聚体 —— 链 A、C 是 $\alpha$ 链，B、D 是 $\beta$ 链；每条链结合一个血红素（HEM），中心是 Fe。

> **注意** 这里的 $\alpha$ 和 $\beta$ 指**两种不同的多肽链亚基（subunit）类型**，**不是**蛋白质二级结构里的 $\alpha$ 螺旋 / $\beta$ 折叠。同一个字母在两个语境下含义完全不同。

文件前半部分是元数据，后半部分才是坐标：

```

TITLE     THE CRYSTAL STRUCTURE OF HUMAN DEOXYHAEMOGLOBIN AT 1.74
COMPND   2 MOLECULE: HEMOGLOBIN SUBUNIT ALPHA;
SOURCE   2 ORGANISM_SCIENTIFIC: HOMO SAPIENS;
REMARK   2 RESOLUTION.    1.74 ANGSTROMS
SEQRES   1 A  141  VAL LEU SER PRO ALA ASP LYS THR ASN VAL LYS ALA ALA
HELIX    1  AA SER A    3  GLY A   18  1
HET    HEM  A 142      43
ATOM      1  N   VAL A   1      19.323  29.727  42.781  1.00 49.05
ATOM      2  CA  VAL A   1      20.141  30.469  42.414  1.00 43.14
...
TER    1070      ARG A 141
HETATM 4431 FE   HEM A 142      18.362  18.488  23.755  1.00 18.07
...
CONECT  650 4431
END
```

| 记录 | 内容 |
|---|---|
| `HEADER` / `TITLE` | 分类、日期、ID、标题 |
| `COMPND` / `SOURCE` | 分子名称、物种 |
| `REMARK 2` | 分辨率 1.74 Å |
| `SEQRES` | 完整氨基酸序列 |
| `HELIX` / `SHEET` | 二级结构 |
| `HET` | 配体：HEM（血红素） |

| `TER` / `CONECT` | 链结束 / 化学键 |

`CONECT 650 4431` 记录的是 **A 链 His87 的 NE2 与血红素的 Fe 之间的配位键** —— 正是 9.4 例题 7 要计算的那一对原子，文件里已经明确写了这个键。

### 按列定位（本讲最重要的格式知识）

```
         1         2         3         4         5         6
123456789012345678901234567890123456789012345678901234567890123456
ATOM      1  N   VAL A   1      19.323  29.727  42.781  1.00 49.05
HETATM 4431 FE   HEM A 142      18.362  18.488  23.755  1.00 18.07
```

| 列（1-based） | 内容 |
|---|---|
| 1–6 | 记录类型（`ATOM` / `HETATM`） |
| 7–11 | 原子序号 |
| 13–16 | 原子名（`N`、`CA`、`FE`、`NE2`） |
| 17 | 替代位置标记 altLoc |
| 18–20 | 残基名（`VAL`、`HIS`、`HEM`） |
| **22** | **链编号** |
| 23–26 | 残基序号 |
| 27 | 插入码 iCode |
| 31–38 | $x$ 坐标 |
| 39–46 | $y$ 坐标 |
| 47–54 | $z$ 坐标 |
| 55–60 | 占据率 occupancy |
| 61–66 | **B 因子**（温度因子） |

Python 里就是切片（0-based，左闭右开）：

```python
atom_name  = line[12:16].strip()     # 第 13–16 列
res_name   = line[17:20].strip()     # 第 18–20 列
chain_id   = line[21]                # 第 22 列
res_seq    = int(line[22:26])        # 第 23–26 列
x, y, z    = float(line[30:38]), float(line[38:46]), float(line[46:54])
```

> **易错** PDB 是**按列定位**的，**不能用 `split()` 按空格切**。`ATOM      1  N   VAL A   1` 里字段挨在一起，`split()` 会把 `N` 和 `VAL` 切开的位置全搞错。又一次用到「从 0 开始、左闭右开」。

> **补充** 两个格式层面的常识：
> 1. `SEQRES` 是**完整序列**，`ATOM` 只包含**晶体中看得见的原子** —— 柔性片段（如末端、loop）在电子密度里看不到，就不会出现在 ATOM 里。二者可能不一致。
> 2. PDB 格式的原子序号只有 5 位，**最多 99,999 个原子**，核糖体这类大结构放不下。现在 RCSB 的标准格式是 **mmCIF（.cif）**，Biopython 用 `MMCIFParser` 读。

## 9.3 例题 6：用 Biopython 解析结构

```python
from Bio.PDB import PDBParser
st = PDBParser(QUIET=True).get_structure("hb", "data/4hhb.pdb")
model = st[0]
for chain in model:
    aa = [r for r in chain if r.id[0] == " "]
    print(chain.id, len(aa))
```

**输出（已实跑核对）**：`A 141`、`B 146`、`C 141`、`D 146`。

Biopython 的结构层次（必记，后面所有操作都在这个树上）：

```
Structure → Model → Chain → Residue → Atom
```

| 层 | 访问方式 | 说明 |
|---|---|---|
| Structure | `st` | 整个文件；X 射线结构通常是 `st[0]` 一个模型（NMR 结构有多个） |
| Model | `st[0]` | 一个模型 |
| Chain | `model["A"]` 或 `for chain in model` | 一条链 |
| Residue | `chain[87]`（按残基号）或遍历 | 一个残基 |
| Atom | `res["NE2"]` | 一个原子 |

**`r.id[0]` 是「异质残基标志」**，判断残基类型全靠它：

| `r.id[0]` | 含义 |
|---|---|
| `" "` | 标准残基（氨基酸 / 核苷酸） |
| `"H_HEM"` | 血红素等杂原子（HETATM） |
| `"W"` | 水分子 |

所以 `[r for r in chain if r.id[0] == " "]` 就是「只取标准氨基酸」。

> **易错** A 链只有 **141** 个残基，而 UniProt 的 HBA 有 **142** 个 —— 差的正是**起始 Met**：成熟蛋白被切掉了第一个甲硫氨酸。所以 **PDB 里的 His87 对应 UniProt 序列的第 88 位**。凡是「PDB 编号 ≠ UniProt 编号」的情况，几乎都是这个原因（前导肽、信号肽被切掉）。
>
> 实跑验证：用 `PPBuilder` 取出 A 链序列后，`seqA == hba[1:]` 为 **True**。

## 9.4 例题 7：Fe 被谁「抓住」？—— 计算原子间距离

```python
chainA = model["A"]
heme = [r for r in chainA if r.get_resname() == "HEM"][0]
fe = heme["FE"]
his87 = chainA[87]           # 按残基号取
print(his87.get_resname())   # HIS
print(fe - his87["NE2"])     # 两个原子相减 = 距离
```

**结果：A 链 Fe–His87 NE2 = 2.14 Å**，正好是**配位键**的长度。

近端组氨酸（proximal histidine）把铁「抓」在血红素中央 —— 这就是第 1 节里那句「Fe 被谁抓住」的答案。

> **要点** Biopython 里**两个 `Atom` 对象相减直接返回欧氏距离**（`Atom.__sub__` 内部算了范数），不需要自己写 $\sqrt{(x_1-x_2)^2+(y_1-y_2)^2+(z_1-z_2)^2}$。这是 Biopython 少数几个「运算符重载」的贴心设计。

## 9.5 tRNA 1EHZ：三叶草形二级结构

**1EHZ** = 酵母 tRNA-Phe，76 个核苷酸（按 tRNA 标准编号 1–76 恰好一一对应），分辨率 1.93 Å。

| 结构单元 | 编号 | 组成 |
|---|---|---|
| 受体茎（acceptor stem） | 1–7 : 66–72 | 7 bp |
| 3′ 端 CCA | 73–76 | **不配对**；A76 的 3′-OH 与氨基酸成酯键 |
| D 臂 | 10–25 | 4 bp 茎 + D 环（含二氢尿苷 D） |
| 反密码子臂 | 27–43 | 5 bp 茎 + 7 nt 环 |
| 可变环 | 44–48 | 不同 tRNA 长度差别最大 |
| T 臂（TΨC 臂） | 49–65 | 5 bp 茎 + T 环 |

- **反密码子 Gm34-A35-A36 ↔ 密码子 UUC（Phe）**。G34 与密码子 3′ 位的 U 是**摆动配对**（wobble）；`Gm` 表示 2′-O-甲基化鸟苷；
- **T54-Ψ55-C56** —— TΨC 臂名称的由来（Ψ = 假尿苷 pseudouridine）；
- Y37（wybutosine，yW）紧挨反密码子，稳定密码子–反密码子配对。

四个茎全是 Watson–Crick 配对（含 G–U 摆动配对）。

图上约定：**实心 = 茎（配对），空心 = 环，黑圈 = 修饰核苷酸**。

**实跑核对：76 个核苷酸，11 种修饰核苷酸** —— `1MA`、`2MG`、`5MC`、`5MU`、`7MG`、`H2U`、`M2G`、`OMC`、`OMG`、`PSU`、`YYG`。这些在 PDB 里是 **HETATM**，所以取核苷酸时要用 `"C4'" in r` 这种条件把它们也包括进来，**不能只筛 `r.id[0] == " "`**（否则会漏掉修饰核苷酸，76 变成更小的数）。

## 9.6 1EHZ 的三级结构：螺旋区与非螺旋区

按「是否在碱基配对的茎里」着色：**蓝色 42 个核苷酸构成 A 型双螺旋，橙色 34 个是环、连接区和 3′ 单链**（$42+34=76$ ✓）。

**三维中的两级堆积**：

- 受体茎 + T 茎**同轴堆积**成一段长螺旋；
- D 茎 + 反密码子茎堆积成另一段；
- 两段近乎**垂直**，形成 **L 形**；
- 反密码子在 L 的一端，3′ CCA 在另一端，两端相距约 **75 Å** —— 这两个位置分别对应核糖体上的**解码中心**和**肽基转移中心**。tRNA 的 L 形就是为了让这两个位点同时够得着。

- **D 环与 T 环在 L 的拐角（肘部）相互作用**（G18–Ψ55、G19–C56 等三级相互作用）—— 这正是下一节 B 因子**最低（最稳定）**的区域。

> **要点** 「两段螺旋垂直相交成 L 形」这个几何事实，是理解为什么 tRNA 能同时对接核糖体两个功能中心的钥匙。序列上的三叶草（二级）和空间上的 L 形（三级）是两回事，考试常在这里设陷阱。

## 9.7 RNA 结构（一）：tRNA 哪里最「柔软」？

```python
rna = PDBParser(QUIET=True).get_structure("t", "data/1ehz.pdb")[0]["A"]
nts = [r for r in rna if "C4'" in r]          # 76 个核苷酸（含修饰）
bf = [np.mean([a.get_bfactor() for a in r]) for r in nts]
```

**B 因子（温度因子）高 = 原子晃动大 = 柔性大。**

结论：**最柔的是 3′ CCA 端、5′ 端、反密码子环；最稳的是 D 环 / T 环相互作用的「肘部」。**

**实跑核对**（B 因子最低 / 最高各 10 个）：

| | 核苷酸编号 | 对应部位 |
|---|---|---|
| **最稳**（B 因子 29–32） | 57、9、21、22、20、8、53、50、56、49 | **T 环（53–57）与 D 环（8–22）** —— 正是 9.6 说的「肘部」 |
| **最柔**（B 因子 78–100） | 76、75、74、2、1、37、38、39、36、16 | **3′ CCA 端（74–76）、5′ 端（1–2）、反密码子环（36–39）** |

两边的结论与课件完全吻合，而且**结构上的解释自洽**：肘部靠三级相互作用钉死，所以最稳；CCA 端要反复与氨基酸成酯、反密码子端要在核糖体里扫描密码子，所以必须柔。

> **补充** **B 因子不是「真实运动」**，它是晶体学里的一个拟合参数（德拜–沃勒因子），反映原子在晶格中的**位置不确定性**：既来自热运动，也来自静态无序、以及拟合精度。所以 B 因子高的区域通常是柔性区，但不能反过来当作「动力学测量」。真正的动力学要用 NMR 弛豫或分子动力学模拟。

## 9.8 RNA 结构（二）：骨架伪扭转角 $\eta$ / $\theta$

**蛋白质**用 Ramachandran 图（$\phi$ / $\psi$）描述主链构象。**RNA 骨架比蛋白质多一个原子**（核糖 2′-OH），单靠两个角不够，所以用 **C4′ 和 P 这两个「共同原子」定义伪扭转角（pseudo-torsion）**：

$$
\eta = C4'(i-1) - P(i) - C4'(i) - P(i+1)
$$

$$
\theta = P(i) - C4'(i) - P(i+1) - C4'(i+1)
$$

```python
from Bio.PDB.vectors import calc_dihedral

def eta(prev, cur, nxt):
    v = [prev["C4'"], cur["P"], cur["C4'"], nxt["P"]]
    ang = calc_dihedral(*[a.get_vector() for a in v])
    return math.degrees(ang) % 360

print("A36 的 η =", round(eta(nts[34], nts[35], nts[36]), 1))
```

**4 个原子 → 1 个二面角**；`% 360` 把结果规范到 $[0°, 360°)$。

**结果**：74 个核苷酸中 **50 个（68%）落在螺旋区**（螺旋区判据：$\eta \in 140°\!-\!190°$、$\theta \in 190°\!-\!260°$）。离群点都在环区 —— **可以用来找结构「拐弯」的位置**。

**实跑核对**：74 个核苷酸的 $(\eta,\theta)$ 中，**同时**落在螺旋区的恰好 **50 个 = 68%** ✓，与课件一致。

偏离螺旋区的 24 个：`7–10`（受体茎与 D 臂的连接区）、`13–22`（**D 环**）、`34, 36`（**反密码子环**）、`46–49`（**可变环**）、`56–61`（**T 环**）、`75`（3′ 端附近）—— **全部落在环或连接区**，与二级结构一一对应。

> **要点** 为什么是 74 而不是 76？因为 $\eta$ 用到 $i-1$ 和 $i+1$ 两个邻居，**两端各少一个**；$\theta$ 用到 $i+1$，少一个。另外「50 个落在螺旋区」比 9.6 里的「42 个是配对核苷酸」更多 —— 因为**有些环里的核苷酸也延续了螺旋式的堆积**（例如反密码子环 3′ 侧），几何上仍落在螺旋区，但不参与碱基配对。**这两个数字（42 与 50）不矛盾，只是判据不同。**

### 课后练习 9

仿照 `eta()` 写出 `theta()`，算出所有核苷酸的 $(\eta,\theta)$ 并画散点图。

**参考解答**：

```python
def theta(cur, nxt):
    # 4 个原子：P(i), C4'(i), P(i+1), C4'(i+1)
    return dihedral(cur["P"], cur["C4'"], nxt["P"], nxt["C4'"])
```

配上一行循环就能得到全部 74 个点；螺旋区会聚成一块密集区域，四个环的核苷酸散落在外面。这正是 **RNA 版 Ramachandran 图**（Wadley, Keating, Duarte & Pyle 2007, *J Mol Biol*）。

## 9.10 预处理：截断 → 过滤 → $\log_2$

```python
# 截断：<100 记为 100，>16000 记为 16000
x = expr.clip(lower=100, upper=16000)
# 过滤：保留 最大/最小 > 5 倍 且 最大−最小 > 500 的基因
# （.loc[:, 条件] 按列筛选），再取 log2
x = np.log2(x.loc[:, (x.max()/x.min() > 5)
                   & (x.max()-x.min() > 500)])
```

**预处理后保留 3571 个基因（实跑核对 ✓，72 × 3571）。**

三步各自解决一个问题：

| 步骤 | 作用 |
|---|---|
| `clip(lower=100, upper=16000)` | 截断极端值 —— 低端是噪声底、高端是饱和值，留着会污染后续统计 |
| 过滤：`max/min > 5` **且** `max−min > 500` | 去掉**几乎不变化**的基因。两个条件都要满足，是为了同时排除「比值大但绝对差小」的基因 |
| `log2` | 把乘性关系变加性关系、压缩动态范围 —— 这也是 9.11 里 `diff` 能直接读作「log 倍数变化」的原因 |

流程参照 **Dudoit, Fridlyand & Speed 2002, *JASA***，是微阵列时代的标准做法。

> **要点** 为什么先 `clip` 再过滤再 `log2`，顺序不能换？因为过滤条件里的 `max−min > 500` 是在**原始尺度**上定义的阈值；取完 $\log_2$ 之后数值都被压到 5–14 之间，500 这个数就毫无意义了。**阈值永远要在对应的尺度上定义。**

## 9.11 例题 8：分组比较 + 箱线图

```python
# 按 ALL/AML 分组，求每个基因的组内平均；.T 转置成 基因 × 组
gm = x.groupby(labels).mean().T
# 新增一列：两组平均表达之差（log2 尺度，即 log 倍数变化）
gm["diff"] = gm["ALL"] - gm["AML"]
# 按差值从小到大排序：最前 = AML 中最高，最后 = ALL 中最高
top = gm.sort_values("diff")

# 导入画统计图的 seaborn
import seaborn as sns
# 取差异最大的基因 top.index[0]，与标签拼成一张两列的表
df = pd.DataFrame({"expr": x[top.index[0]],
                   "type": labels})
# 画箱线图：x 轴为白血病类型，y 轴为该基因的表达量
sns.boxplot(data=df, x="type", y="expr")
```

三行 pandas 的语义：

| 代码 | 含义 |
|---|---|
| `x.groupby(labels).mean()` | 按标签分组求均值 → 得到「组 × 基因」 |
| `.T` | 转置成「基因 × 组」，便于同类基因做差 |
| `gm["ALL"] - gm["AML"]` | 在 $\log_2$ 尺度上做差 = $\log_2(\text{ALL}/\text{AML})$，即 **log 倍数变化** |

**实跑结果（真实数据，预处理后的 3571 个基因）**：

| 方向 | 前 5 个探针集（`diff`） |
|---|---|
| **AML 中最高**（`diff` 最负） | `M27891_at` (−4.81)、`M84526_at` (−4.73)、`M19507_at` (−3.98)、`Y00787_s_at` (−3.54)、`D88422_at` (−3.32) |
| **ALL 中最高**（`diff` 最大） | `X82240_rna1_at` (+3.81)、`M11722_at` (+3.78)、`D88270_at` (+3.61)、`U05259_rna1_at` (+3.06)、`M89957_at` (+2.97) |

> **补充** 这些是 **Affymetrix 探针集 ID，不是基因符号**（`_at` / `_s_at` / `_rna1_at` 是探针类型后缀）。要拿到基因名，得查探针注释表或到 NCBI Gene 上按 ID 反查 —— 这正是课后练习 10 要求的动作。**别把探针 ID 当基因名去搜。**

## 9.12 手算题 2：分组均值与表达差异

下面是教学用简化表达矩阵。数值已取 $\log_2$，**直接在该尺度上求均值**。

| 样本 | 分组 | 基因 A | 基因 B | 基因 C |
|---|---|---|---|---|
| S1 | ALL | 4 | 8 | 5 |
| S2 | ALL | 6 | 10 | 7 |
| S3 | AML | 8 | 6 | 6 |
| S4 | AML | 10 | 8 | 6 |

**① 求各基因的 ALL 均值、AML 均值及 `diff` = ALL 均值 − AML 均值。**

| 基因 | ALL 均值 | AML 均值 | `diff` |
|---|---|---|---|
| A | $(4+6)/2 = 5$ | $(8+10)/2 = 9$ | $5-9=$ **−4** |
| B | $(8+10)/2 = 9$ | $(6+8)/2 = 7$ | $9-7=$ **+2** |
| C | $(5+7)/2 = 6$ | $(6+6)/2 = 6$ | **0** |

**② 按 `diff` 从小到大排序，写出基因顺序。**

$$
A(-4) < C(0) < B(+2)
$$

**③ 哪个基因在 AML 中相对更高？哪个在 ALL 中相对更高？**

- **AML 中相对更高：基因 A**（`diff` 最负，ALL 均值比 AML 均值低 4 个 $\log_2$ 单位，即低 $2^4=16$ 倍）；
- **ALL 中相对更高：基因 B**（`diff` 最大，高 $2^2=4$ 倍）；
- 基因 C 两组均值相等，没有区分能力。

> **要点** 这题就是 `groupby(labels).mean().T` 与 `sort_values("diff")` 的手算版。**基因 C 这种 `diff = 0` 的基因正是 9.10 的过滤条件要删掉的**（`max/min` 不满足 > 5）—— 手动版告诉你为什么那个过滤是对的。
>
> 记住 `diff` 的读法：**值越负 → AML 越高；值越正 → ALL 越高**。因为定义是 ALL 减 AML。

## 9.14 质控：去掉「坏」细胞

```python
adata.var["mt"] = adata.var_names.str.startswith("MT-")
sc.pp.calculate_qc_metrics(adata, qc_vars=["mt"], inplace=True)
adata = adata[(adata.obs.n_genes_by_counts < 2500)
              & (adata.obs.pct_counts_mt < 5)]
```

两类要剔除的坏细胞：

| 现象 | 原因 |
|---|---|
| **检测到的基因数太多** | 可能是两个细胞粘在一起（**doublet**） |
| **线粒体基因比例高** | 细胞**破损、濒死** —— 细胞膜破后胞质 mRNA 流失，线粒体转录本相对富集 |

完整流程（Notebook 版）在两步之前还加：

```python
sc.pp.filter_cells(adata, min_genes=200)   # 至少检出 200 个基因的细胞
sc.pp.filter_genes(adata, min_cells=3)     # 至少在 3 个细胞里出现的基因
```

**实跑核对（逐步）**：

| 步骤 | 结果 |
|---|---|
| 原始 | 2,700 细胞 × 32,738 基因 |
| `filter_cells(min_genes=200)` | 弃 **0** 个（这份原始数据已经是「每细胞 > 200 基因」的版本） |
| `filter_genes(min_cells=3)` | 弃 **19,024** 个基因 → 保留 **13,714** |
| 按 `n_genes < 2500` 且 `pct_mt < 5` | 保留 **2,638** 个细胞（弃 62 个） |
| **最终** | **2,638 细胞 × 13,714 基因** ✓ 与课件一致 |

被 `MT-` 匹配到的基因有 **13 个**（`MT-ND1`、`MT-ND2`、`MT-CO1`、`MT-CO2`、`MT-ATP8`、`MT-ATP6` …），即线粒体基因组的 13 个蛋白编码基因。QC 指标的实际分布：`n_genes` 212–3400，`pct_counts_mt` 0–22.6%。

> **要点** **阈值因数据而异，没有万能标准。** `< 2500` 和 `< 5%` 是 PBMC3k 的常用值，换一个组织、换一个平台就要重新看分布图（`sc.pl.violin`）再定。生信里「别人用这个阈值」从来不是理由。

## 9.15 标准流程：从计数矩阵到细胞图谱

```python
sc.pp.normalize_total(adata, 1e4)
# 总数标准化，将单个细胞总计数归一化到 1e4
sc.pp.log1p(adata)
# 对数转换，降低极高表达值的影响
sc.pp.highly_variable_genes(adata, n_top_genes=2000)
# 识别高变基因：挑选表达变异最大的 2000 个基因
sc.pp.pca(adata)
# 线性降维
sc.pp.neighbors(adata)
# 计算邻域图：基于 PCA 降维后的多维特征空间，计算细胞之间的 K-近邻图
sc.tl.umap(adata)
# 基于邻域图运行 UMAP 算法
sc.tl.leiden(adata, resolution=0.5)
# 细胞聚类：用 Leiden 图聚类算法对细胞进行社区发现（分群）
```

**每一步都在解决上一步的遗留问题**：

| 步骤 | 为什么需要 |
|---|---|
| `normalize_total` | 不同细胞的测序深度差好几倍，不归一化就会「按测序量聚类」 |
| `log1p` | 压缩高表达值的动态范围，让差异可控 |
| `highly_variable_genes` | 32,738 个基因里大部分是恒定噪声，只留 2000 个最「有信息」的 |
| `pca` | 把 2000 维降到几十维，去冗余、降噪 |
| `neighbors` | 构建细胞间的相似度图 —— UMAP 和 Leiden 都以它为基础 |
| `umap` | 二维可视化（**只用于画图，不用于聚类**） |
| `leiden` | 真正的分群 |

> **要点** 每一行都是一个函数调用 —— **到这里你已经会读这种代码了**。PCA、邻居图、聚类背后的原理是第 10 讲的内容，本讲只需要能按顺序跑通、并知道每步在做什么。

**练习 12 参考解答** —— 代码：

```python
def ai_revcomp(seq):
    pairs = {"A": "T", "T": "A", "G": "C", "C": "G"}
    return "".join(pairs[b] for b in seq[::-1])

print(ai_revcomp("ATGC"))
# print(ai_revcomp("atgN"))   # 取消注释，看看会发生什么
```

**Bug**：字典 `pairs` 里只有 4 个大写碱基。测试 `"atgN"` 时会抛 `KeyError: 'N'`（也可以是小写 `'a'`，取决于遍历顺序 —— 但**只要有 N 或小写就必崩**）。

**修正**：

```python
def fixed_revcomp(seq):
    pairs = {"A": "T", "T": "A", "G": "C", "C": "G", "N": "N"}
    return "".join(pairs[b] for b in reversed(seq.upper()))

fixed_revcomp("atgN")   # 'NCAT'
```

核验：`atgN` → 大写 `ATGN` → 反向 `NGTA` → 互补 **`NCAT`** ✓

> **要点** 这道题的用意不是「N 怎么办」，而是：**AI 生成的代码要自己审**。这段函数看起来完全正确 —— 语法对、示例 `ATGC` 跑得出结果、逻辑也对 —— **只有在边界输入上才会暴露问题**。写成可复用的函数（而不是一次性脚本）时，第一件要做的事就是 8.5 那条自检：`revcomp(revcomp(s)) == s`，以及「拿含 N / 小写的序列试一遍」。
