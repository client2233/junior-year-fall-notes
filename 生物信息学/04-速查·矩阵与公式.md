## 6.4 PAM vs BLOSUM 一表对比（**简答标准答案**）

| | **PAM** | **BLOSUM** |
|---|---|---|
| 全称 | Percent Accepted Mutation | BLOcks SUbstitution Matrix |
| 作者 / 年份 | Dayhoff et al., 1978 | Henikoff & Henikoff, 1992 |
| 数据来源 | 71/75 个**近缘**同源序列组（**最低 85% identity**），共 1572 次突变 | 多序列比对中的**保守无空位 block**，**直接统计** |
| 是否外推 | **是**（$M_{PAMn} = (M_{PAM1})^n$） | **否**（直接由计数得到） |
| 构造步数 | **三步**：计数突变 → 相对突变性 → 突变概率 | **四步**：计数 $f_{ij}$ → $q_{ij}$ → $e_{ij}$ → log-odds $S_{ij}$ |
| 参数含义 | **累积突变百分比**（PAM1 = 1% 残基改变） | **建库序列的一致性阈值**（BLOSUM62 = ≥62%） |
| 数字越大 | PAM 越大 → **进化距离越远** → 越适远缘 | BLOSUM 越大 → **建库序列越相似** → 越适近缘 |
| 优点 | 有明确进化模型，可给出进化距离 | 符合实际观测，**整体优于 PAM**，更适合生物学关系分析与局部相似性搜索 |
| 缺点 | 外推误差累积，与进化时间无对应 | **不能与进化挂钩**（无进化距离含义） |
| 常用值 | PAM250（远缘，最常用）、PAM120、PAM30 | **BLOSUM62（默认）**、BLOSUM80（近缘）、BLOSUM45（远缘） |

## 6.5 打分矩阵的统一理论（PAM 与 BLOSUM 都用它）

$$\boxed{\;S_{ij} = \log\frac{q_{ij}}{e_{ij}} = \log\frac{\text{观测到 } i,j \text{ 同现的概率}}{\text{随机独立下 } i,j \text{ 同现的期望概率}}\;}$$

- $S_{ij} > 0$ ⇔ 该替换**比随机更常见**（被自然选择保留）
- $S_{ij} < 0$ ⇔ 该替换**比随机更少见**（倾向于被淘汰）
- PAM 中 $q_{ij} = M_{ij}$，$e_{ij} = p_i p_j$
- BLOSUM 中 $e_{ij} = p_i^2$（$i=j$）或 $2p_ip_j$（$i \ne j$）

**为什么必须用 log-odds（三个理由）**
1. 让"整条比对得分 = 各列得分之和"成立（log 把乘法变加法）——**这是 DP 的前提**；
2. 把不对称的 $M_{ij}$ 恢复成**对称**的 $S_{ij}$；
3. 分数的**符号与大小**具有可解释的统计学含义（相对随机期望的对数似然比）。

## 6.6 空位罚分速查

| 名称 | 公式 | 说明 |
|---|---|---|
| **线性 (linear)** | $w(k) = a\cdot k$，即 $a=b$ | 每列空位代价相同，等价于常数 $g$ |
| **仿射 (affine)** | $w(k) = a + b(k-1)$ | 第一列 $a$（opening），其余每列 $b$（extension），一般 $b \le a$ |

**四种参数组合的适用场景（课件表格）**

| 打开 $a$ | 扩展 $b$ | 比对结果 | 适用 |
|---|---|---|---|
| 大 | 大 | 极少插入和缺失 | 非常相关的蛋白质间的比对 |
| 大 | 小 | 少量大块插入 | 整个功能域可能插入的情况 |
| 小 | 大 | 大量小块插入 | 亲缘关系较远的蛋白质同源性分析 |

**常用实际取值**

| 场景 | opening | extension |
|---|---|---|
| NCBI BLAST 默认（BLOSUM62） | **−11** | **−1** |
| Biopython 默认 | −10 | −1 |
| 课件算例 | −3 | −1 |

> 长 $k$ 的一段连续空位，总罚分 = $a + b(k-1)$。例：$a=-11,b=-1,k=5 \Rightarrow -11+(-1)(4) = -15$。

## 6.7 动态规划递推一览

### NW（线性罚分，全局）
$$F(i,j) = \max\begin{cases} F(i-1,j-1) + s(x_i,y_j)\\ F(i-1,j) + g\\ F(i,j-1) + g\end{cases}\qquad F(i,0)=ig,\;F(0,j)=jg$$

### SW（线性罚分，局部）
$$F(i,j) = \max\left(0,\; F(i-1,j-1) + s(x_i,y_j),\; F(i-1,j)+g,\; F(i,j-1)+g\right)\qquad F(i,0)=F(0,j)=0$$

### Gotoh（仿射罚分；$d$=opening，$e$=extension）

$$
\begin{aligned}
M(i,j) &= \max\{M(i{-}1,j{-}1),\, I_x(i{-}1,j{-}1),\, I_y(i{-}1,j{-}1)\} + s(x_i,y_j)\\
I_x(i,j) &= \max\{M(i{-}1,j)+d,\; I_x(i{-}1,j)+e\}\\
I_y(i,j) &= \max\{M(i,j{-}1)+d,\; I_y(i,j{-}1)+e\}
\end{aligned}
$$

| 版本 | $M$ 的边界 | $I_x/I_y$ 的边界 | 回溯起点 | 回溯终点 |
|---|---|---|---|---|
| **NW + affine** | $M(0,0)=0$，其余 **−∞** | $I_x(i,0)=d+(i-1)e$，$I_x(0,j)=-\infty$；$I_y$ 对称 | $\max\{M(m,n),I_x,I_y\}$ | 任一 $(0,0)$ |
| **SW + affine** | $M(i,0)=M(0,j)=\mathbf{0}$ | **全 −∞** | $\max M(i,j)$（全表最大） | **$M(i,j)=0$** |

### SW 与 NW 的两点差别（**背这两句**）
1. **Non-negative scores** —— 递推中多一项 0，初始化时按迭代公式全部为 0；
2. **Traceback** —— 从**最大元**开始，直到**得分为 0** 的格子结束。

## 6.9 显著性统计速查

$$E = Kmn\,e^{-\lambda S}\qquad P\text{-value} = 1-e^{-E}\qquad S_{\text{bit}} = \frac{\lambda R - \ln K}{\ln 2},\quad E \approx mn\,2^{-S_{\text{bit}}}$$

| 符号 | 含义 |
|---|---|
| $K$ | 搜索空间的自然尺度（由打分矩阵与罚分决定） |
| $\lambda$ | 打分系统的自然尺度（同上） |
| $m$ | 查询序列长度 |
| $n$ | 库序列长度 / 库总残基数 |
| $S$ / $R$ | 原始得分 raw score |
| $S_{\text{bit}}$ | 比特得分，与打分系统无关，可跨程序比较 |

- **判读阈值：E 值 ≤ 0.001 视为好结果。**
- E 值 = 在两条随机序列中期望找到的、得分 ≥ S 的比对**条数**。
- 理论出处：Karlin & Altschul, PNAS 1990 (87:2264)；PNAS 1993 (90:5873)。
- Poisson 分布：$p(X=k) = \dfrac{\lambda^k e^{-\lambda}}{k!}$

## 6.11 高频易错点（最后 10 分钟）

1. **SW 的第一行第一列全是 0**，不是 $0,-2,-4,\dots$。
2. **SW 矩阵里不会出现负数** —— 出现就是算错了。
3. **SW 回溯从全表最大元开始，遇到 0 停**；NW 从 $F(n,m)$ 到 $F(0,0)$。
4. **identity 的分母是查询序列长度**，不是比对长度。
5. **PAM 数字越大 = 进化距离越远**；**BLOSUM 数字越大 = 序列越相似**。方向相反！
6. **BLOSUM 的 $e_{ij}$，$i\ne j$ 时要乘 2**。
7. **仿射罚分必须用 3 个矩阵**，单矩阵无法区分"打开"与"延长"。
8. **$M(i,0)$ 在 NW 下是 $-\infty$、在 SW 下是 0**（因为局部比对允许"零起点"）。
9. **E 值 低 ≠ 序列长**，而是"这么高的分很难碰巧出现"。
10. **$K$、$\lambda$ 由打分系统决定** —— 换矩阵/换罚分必须重算，不能跨程序照搬。
11. **FASTA 最后一步仍然用 DP**，启发式只体现在"候选区域筛选"上。
12. **BLAST 的延伸阶段是无空位的 (ungapped)**，这是旧版特性，新版加了 gapped extension。
13. **ORF 是预测、CDS 是事实**；同一序列有 3 个读码框（正链）。
14. **一级库是原始数据、二级库是加工注释** —— PDB 是一级库，SCOP/CATH 是二级库。
