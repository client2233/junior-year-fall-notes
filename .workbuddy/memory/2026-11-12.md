### 两份的骨架差异

- **hw2** 必须从前面的「线性表」概念起（顺序表是线性表的第一个实现），所以 `1 线性表` → `1.1 定义与 ADT` → `1.2 顺序表` → `1.3 动态数组`。
- **hw3** 直接从 `1 线性表的链式存储` 起，开头一句衔接顺序表（「顺序表要求逻辑相邻的元素物理上也相邻，因而插入删除必须整体搬移」）。末尾保留 `1.5 顺序表与链表的比较`，作为第三次作业的收口。

### 排版参数（两份不同，别统一套）

| | hw2 | hw3 |
|---|---|---|
| `\linespread` | 1.17 | 1.19 |
| `\parskip` | 5.5pt | 4.5pt |
| `\arraystretch` | 1.05 | 1.05 |

**hw3 不能用 1.28**：内容比 hw2 多两张表，1.28 直接撑成 3 页（第 3 页只有几行，很丑）。1.19 正好 2 页且第 2 页约 75% 满。

**hw2 不能用 1.20 及以上**：1.20 时「删除的平均移动次数」公式被挤到第 2 页，与页底的引导句「若 $n$ 个位置等概率，平均移动次数为」断开。1.17 时公式完整留在第 1 页。

### 经验：判断公式是否跨页，用 pdftotext 比读图快

```bash
pdftotext -layout hw2.pdf - | awk 'BEGIN{p=1} /\f/{p++} {if(p==1) print}' | grep -v '^\s*$' | tail -4
```

看第 1 页末尾几行是不是停在引导句上（如「平均移动次数为」），若是则公式掉到了下一页。**调行距时每改一次都要重跑这一条**，因为断点会随行距跳变。配合 `pdfinfo` 看页数，两步就能定下参数，不必每版都渲染读图。
