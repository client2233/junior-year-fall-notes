- **障碍函数幂次的万能判据**：$\psi_a=\tau^{-p}e^{a\lvert x\rvert^2/\tau}$（$\tau=1-4at$）代入 $(\partial_t-\Delta)$ 得 $\frac{2a(2p-n)}{\tau}\psi_a$ —— **解热方程 $\iff p=n/2$**。王嘉项第十一周把 $\Phi_R$ 写成 $p=1/2$，只在 $n=1$ 对；$n\ge2$ 时是**下解**，比较原理方向反了。同一判据也解释「增长类 $e^{a\lvert x\rvert^2}$ 只能活到 $t=1/(4a)$」。
- **Tychonoff 反例的判据是增长常数爆掉**：$u_0=e^{-1/t^\alpha}$ 无限平坦，$u=\sum u_0^{(k)}(t)x^{2k}/(2k)!$ 解热方程且 $u(\cdot,0)=0$，但 Cauchy 估计给出 $\lvert u\rvert\le e^{2x^2/t}$ —— $A(t)=2/t$ 随 $t\to0$ 无界。所以「增长控制最大值原理」的命门是 **$A$ 与 $t$ 无关**（分段法能成立的唯一理由）。
- **$b_R$ 与 $w$ 之间要过一道「$\lvert w\rvert$ 是下解」**：$w$ 与 $-w$ 都解热方程 ⟹ 都是下解 ⟹ $\max$ 仍是下解 ⟹ $\lvert w\rvert\le b_R$。跳过这步则「$b_R\to0$ ⟹ $w\equiv0$」无逻辑通道。
- **衰减率差 2 的坑**：$\int_\Omega u^2$ 的衰减指数是 $2\lambda_1$，$L^2$ **范数**的指数才是 $\lambda_1$。第十一周 §5.1 结论写 $e^{-\lambda_1t}$、证明末步写 $e^{-2\lambda_1t}$，是硬错。
- **双边估计的系数自检**：$2t\lvert\nabla P_tf\rvert^2\le P_t(f^2)-(P_tf)^2\le2tP_t(\lvert\nabla f\rvert^2)$，取 $f=\langle a,x\rangle$ 时三量全等于 $2t\lvert a\rvert^2$ —— 仿射 $f$ 取等，是最省事的验系数办法。

**信息论**
- 手写板书的三类固定写法问题：① 定义里加「else 取 0」分支（多余，链式乘积自带零因子）；② 反向马氏链直接说「也构成 MC」，漏了「只在 $p(x_2^n)>0$ 处成立」的支撑条件；③ $\varlimsup$ 的横杠写成看着像分式，$0\le\varlimsup_{P_e\to0}H(X\mid\hat X)\le\cdots$ 容易误读成 $\frac{H(X\mid\hat X)}{P_e\to0}$。
