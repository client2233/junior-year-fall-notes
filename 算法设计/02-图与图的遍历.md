# 02 图与图的遍历

## 2.1 基本定义与应用

**无向图** $G=(V,E)$：

- $V$ = 顶点集合；$E$ = 边，反映顶点之间的关系；
- 图参数：$n=|V|$，$m=|E|$。

**例**：$V=\{1,2,\dots,8\}$，

$$

E=\{1\text{-}2,\ 1\text{-}3,\ 2\text{-}3,\ 2\text{-}4,\ 2\text{-}5,\ 3\text{-}5,\ 3\text{-}7,\ 3\text{-}8,\ 4\text{-}5,\ 5\text{-}6\}

$$

**图的起源（1736, Leonhard Euler）**：哥尼斯堡七桥问题。**欧拉路径存在当且仅当图连通且恰有 0 个或 2 个奇度顶点。**

**常见应用中的图**：

| 场景 | 结点 | 边 |
|---|---|---|
| Web 图 | 网页 | 超链接 (hyperlink) |
| 食物生态链 | 生物种类 | 从猎物到捕食者 |
| 通信 / 公路 / 管网 | 交换机、路口、管道连接点 | 链路、公路、管道 |

### 图的两种表示

**邻接矩阵**：$n\times n$ 的 0-1 矩阵，$A_{ij}=1$ 当且仅当 $i$ 与 $j$ 相邻。

**邻接链表**：每个顶点挂一个链表，存放它的全部邻居。

$$

\text{存储代价：邻接矩阵 } \Theta(n^2),\qquad \text{邻接链表 } \Theta(m+n)
$$

> **补充**：后面几乎所有图算法的复杂度都用 $O(m+n)$ 或 $O(m\log n)$ 表示，前提就是**用邻接链表**。这是 [[16-NP与计算的难解性·归约与NP类]] 里"输入规模是 $m,n$"的前提。

### 路径、连通、圈、树

> **Def.** 无向图 $G=(V,E)$ 的一条**路径 $P$** 定义为如下的结点序列 $v_1,v_2,\dots,v_{k-1},v_k$，其中 $v_i v_{i+1}$ 是 $E$ 中的一条边。$P$ 被称为从 $v_1$ 到 $v_k$ 的路径。

> **Def.** 如果一条路径所有的结点都是相互不同的，就称为**简单的**。

> **Def.** 如果对于无向图中任意两个顶点都存在一条路径，那么无向图被称为是**连通的**。

> **Def.** 路径 $v_1,v_2,\dots,v_{k-1},v_k$ 被称为一个**圈 (cycle)**，如果 $v_1=v_k$，$k>2$，而且前 $k-1$ 个顶点两两不同。

> **Def.** 一个无向图被称为是**树**，如果它是连通的而且没有圈。

**定理（树的等价刻画）**：设 $G$ 是一个具有 $n$ 个结点的无向图，下面任意两条都可以推出第三条：

1. $G$ 是连通的；
2. $G$ 不包含一个圈；
3. $G$ 有 $n-1$ 条边。

> **补充**：这条定理是后面 [[04-贪心·最短路径与最小生成树]] 里 MST 有 $n-1$ 条边、且割性质里"加一条边必然成圈"的依据。

### 有根树

给一棵树选择一个根结点 $r$，安排所有的边从 $r$ 出发，目的是为了建立**分层结构**：每个结点有父结点 (parent) 与子结点 (child)。

## 2.2 图的连通性与图的遍历

两个基本问题：

- **$s$-$t$ 连通性问题**：给定图中两个顶点 $s,t$，是否存在一条 $s$ 到 $t$ 的路径？
- **$s$-$t$ 最短路径问题**：$s$-$t$ 之间的最短路径是多长？

应用场景：穿越迷宫、通信网络中最少的多跳连接路径。

### 广度优先搜索 (BFS)

从顶点 $s$ 开始向各个方向"探索"，把探索到的顶点依次加在各层上。

$$

L_0=\{s\}

$$

$$

L_1=\text{all neighbors of } L_0

$$

$$

L_{i+1}=\text{all nodes that do not belong to an earlier layer and that have an edge to a node in } L_i

$$

```
BFS(s, G):
    Discovered[s] = true, 其他 v 置 Discovered[v] = false
    初始化 L[0]，单个元素 s 构成
    层计数器 i = 0
    BFS 树 T = 空集
    While L[i] 非空:
        初始化一个空表 L[i+1]
        For 每个 L[i] 中的结点 u:
            考虑每条关联到 u 的边 (u, v)
            If Discovered[v] == false then
                置 Discovered[v] = true
                把边 (u, v) 加到树 T 上
                把 v 加到表 L[i+1]
            Endif
        Endfor
        层计数器 i 加 1
    Endwhile
```

> **定理 3.11**　如果图是邻接表给出的，BFS 算法的上述实现将以 $O(m+n)$ 时间运行。

**证明**：考虑结点 $u$，存在 $\deg(u)$ 条与 $u$ 相连的边 $(u,v)$，所以处理所有边的时间是

$$

\sum_{u\in V}\deg(u)=2m

$$

此外对于顶点，还要 $O(n)$ 的额外时间来管理数组 `Discovered`。故总代价 $O(m+n)$。

#### BFS 的两条结构性质

> **定理**　BFS 算法产生的层 $L_i$ 就是到源点 $s$ 距离为 $i$ 的顶点集合。存在一条 $s$ 到 $t$ 的路径当且仅当 $t$ 出现在某一层中。

> **定理**　设 $T$ 是图 $G=(V,E)$ 的一棵广度优先搜索树，$(x,y)$ 是 $G$ 中的一条边，那么 $x,y$ 所属的层数**至多相差 1**。

> **补充**：第二条性质是 [[02-图与图的遍历|二分性测试]] 的全部依据——如果所有边都跨相邻层，那么按层奇偶着色就是一个合法二着色。

### 深度优先搜索 (DFS)

- **BFS**：从 $s$ 开始出发探查，按照距离分层，一般用**队列**维护即将被处理的结点；
- **DFS**：从 $s$ 开始出发探查，方式更"冲动"，用**栈**维护即将被处理的结点。

```
DFS(s):
    初始化 S 为具有一个元素 s 的栈
    While S 非空:
        从 S 中取出一个结点 u
        If Explored[u] == false then
            置 Explored[u] = true
            For 每条与 u 关联的边 (u, v):
                把 v 加到栈 S
            Endfor
        EndIf
    Endwhile
```

**应用实例**：图形填充（油漆桶）——顶点是像素点，边表示"是否都是亮绿色"；需要找到同种亮绿色的连通结构，然后整体改变颜色。

## 2.3 连通分支与有向图中的连通性

**BFS 算法发现的是从起点 $s$ 可达的结点。** 把这个集合记为 $R$：

$$

R \leftarrow \{s\}
$$

$$

\text{While } \exists\ \text{边 } (u,v) \text{ 使 } u\in R,\ v\notin R:\quad R \leftarrow R\cup\{v\}

$$

> **定理**　算法结束产生的集合 $R$ 恰好是 $G$ 的包含 $s$ 的连通分支。

> **定理 3.8**　对无向图中任两个结点 $s$ 与 $t$，它们的连通分支或者**相等**，或者**不相交**。（有向图的对应版本是定理 3.17。）

### 有向图

**有向图 (directed graph)** $G=(V,E)$，边 $(u,v)$ 表示从 $u$ 到 $v$。无向图中的一些概念与问题在这里可以推广。

> **Def.** $u$ 和 $v$ 是**相互可达的**，如果彼此之间存在到达对方的路径。

> **Def.** 如果图中每对结点是相互可达的，那么此图是**强连通的**。

**引理**　设 $s$ 是图 $G$ 中的任意一个结点。$G$ 是强连通的，当且仅当图中的每个结点能够与 $s$ 相互可达。

**强连通性判定的算法**：

```
Pick any node s.
Run BFS from s in G.
Run BFS from s in G^rev.
Return true iff all nodes reached in both BFS executions.
```

$$

\text{存在 } O(m+n) \text{ 的有效算法判别图 } G \text{ 是否强连通。}
$$

## 2.4 二分性测试（BFS 的一个应用）

> **Def.** **二部图 (bipartite graph)** 是一个图，其中结点集可以划分为 $X$ 与 $Y$，每条边一端在 $X$ 中，另一端在 $Y$ 中。

直观地，一个图是二部图，如果能对结点着红色和蓝色，使得每条边有一个红端点和一个蓝端点。

**问题**：给一个图 $G$，它是二部图吗？

> **动机**：很多有关图的问题，**如果是二部图，那么问题会变得容易一些**。

### 核心定理

> **定理**　如果一个图是二部图，那么它不可能包含一个奇圈。

> **定理（BFS 层刻画）**　设 $G$ 是一个连通图，$L_0,\dots,L_k$ 是从顶点 $s$ 由 BFS 算法生成的层。那么下面两件事一定恰好成立其一：
>
> (i) $G$ 中没有边与同一层的两个结点相交。这种情况下 $G$ 是二部图，其中**偶数层**的结点可以着红色，**奇数层**结点可以着蓝色。
>
> (ii) $G$ 中有一条边与同一层的两个结点相交。此种情形下，存在一个**奇圈**，$G$ 不可能是二部图。

> **引理**　图 $G$ 是二部图当且仅当图中没有奇圈。

**证明思路**：

- (i) 红蓝交替着色即为合法二着色；
- (ii) 若 $(x,y)$ 同属第 $j$ 层，则 $s\to x$ 的 $j$ 条边、边 $(x,y)$、$y\to s$ 的 $j$ 条边构成一个长度 $2j+1$ 的圈，是奇圈。

> **补充**：$2$-着色恰好就是二部性，所以"$G$ 是 $2$-可着色的"这个问题是 $O(m+n)$ 的；而 [[16-NP与计算的难解性·归约与NP类]] 中会看到 $3$-着色是 NP 完全的。**从 $2$ 跳到 $3$ 是难度上的断崖**。

## 2.5 有向无圈图与拓扑排序

**问题背景**：存在标记为 $\{1,2,\dots,n\}$ 的任务集，之间存在先后的依赖关系，是否存在一个有效的执行任务的次序？

> **Def.** 有向图 $G=(V,E)$ 的一个**拓扑排序**是它的结点作为 $v_1,v_2,\dots,v_n$ 的一个排序，对每条边 $(v_i,v_j)$，都有 $i<j$。

> **Def.** **DAG (Directed Acyclic Graph)**：有向图没有圈。

> **定理**　如果 $G$ 有一个拓扑排序，那么 $G$ 是一个 DAG。

**证明**：反设 $G$ 有有向圈 $C=v_1\to v_2\to\cdots\to v_k\to v_1$。拓扑序要求 $i_1<i_2<\cdots<i_k<i_1$，矛盾。

### 两个关键问题

- **Q1**：是否每一个 DAG 都存在拓扑排序？
- **Q2**：如果存在，如何计算？

> **命题**　在每一个 DAG 中，存在一个**没有输入边的结点**。

**证明**：反设每个结点都有入边。从任意结点出发，沿入边一直往回走，由于顶点有限，必然重复经过某个结点，于是得到一个圈，与 DAG 矛盾。

> **定理**　如果 $G$ 是一个 DAG，那么 $G$ 有一个拓扑排序。

**证明**：对 $n$ 归纳。取一个无入边的结点 $v$，把它排在首位；$G-\{v\}$ 仍是 DAG，由归纳假设有拓扑排序，接在 $v$ 之后即为所求。

### 算法

```
To compute a topological ordering of G:
    Find a node v with no incoming edges and order it first
    Delete v from G
    Recursively compute a topological ordering of G - {v}
        and append this order after v
```

> **定理**　上面算法在 $O(m+n)$ 时间内找到一个拓扑排序。

**证明**：考虑边逐次递降的代价 $O(m)$；追踪被删除的结点代价 $O(n)$。

> **补充**：更工程化的写法是 **Kahn 算法**——先用入度表找出所有入度为 0 的点入队，出队时把它的出边终点的入度减 1，减到 0 就入队。它和上面的递归写法等价，但避免了显式删除操作。另一种写法是 **DFS 后序遍历取逆序**。
