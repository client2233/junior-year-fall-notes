# 09 动态规划·带权区间调度与分段最小二乘

## 9.1 三种算法设计范式的定位

| 范式 | 核心思想 | 局限 |
|---|---|---|
| **贪心算法** | 利用局部最优化原理，逐渐建立起完整的最优解 | 构成算法设计最自然的方法；但对人们碰到的大多数问题，实际困难**不在于确定几个贪心策略中哪一个是正确的，而是事实上可能不存在有效的贪心算法** |
| **分治策略** | 把问题递归分解成几个更小规模的子问题，然后通过一个合理的复杂度把子问题的解合并成全局的解 | 分治策略没有强到可以把指数的蛮力搜索减少到多项式时间；它擅长的是**降低已有算法的时间复杂度（降低幂次）** |
| **动态规划** | 通过把事情分解为一系列子问题，然后对越来越大的子问题建立正确的解，从而**隐含地探查所有可行解的空间** | 通过问题可行解的指数规模的集合，**不必明确检查所有的解** |

> **Bellman** 在 1950 年代为了研究系统控制问题而提出了动态规划的方法，对控制理论界和数学界有深远影响。
>
> $$
> \text{Dynamic programming} = \text{planning over time}
> $$

**应用领域**：生物信息学、控制论、信息论、行为学研究、计算机科学（理论、图形、人工智能、系统……）。

**一些经典的动态规划算法**：

- Unix 比较两个文件的不同算法（`diff`）；
- **Smith–Waterman 序列比对算法**；
- **Bellman–Ford** 网络中的最短路径路由算法；
- **Cocke–Kasami–Younger** 自然语言处理算法。

## 9.2 带权的区间调度 (Weighted Interval Scheduling)

### 问题

对于区间调度问题，不同区间有一样的权重时，贪心算法可以得到最优解。**如果不同区间有不同的权重**：

- 任务 $j$ 在 $s_j$ 时刻开始、$f_j$ 时刻结束，其权重为 $v_j$；
- 两个任务如果对应的时间区间不相交，称为**相容**；
- **目标**：寻找最大的相容的区间子集，使得所选区间的**权重之和最大**。

> 贪心算法情形下，区间的权重可以看成都是 1。对于区间权重不同的情形，**贪心算法就失效了**。解决之道：更加灵活的调度策略。

### 定义 $p(j)$

> **定义**　任务需求按照结束时间排序：$f_1\le f_2\le\cdots\le f_n$。
>
> 对区间 $j$ 定义 $p(j)$ 为**使得区间 $i$ 与 $j$ 不相交的最大的标记 $i<j$**，也就是说，$p(j)$ 是最右边的与 $j$ 不相交的区间。

**例**：$p(8)=5,\quad p(7)=3,\quad p(2)=0$。

### 最优解的结构

分析最优解 $O$ 的性质：

1. 如果区间 $n\in O$，那么 $O$ 一定包含对于需求 $\{1,\dots,p(n)\}$ 所组成问题的一个最优解；
2. 如果 $n\notin O$，那么 $O$ 等于对需求 $\{1,\dots,n-1\}$ 所组成问题的最优解。

> 求区间 $\{1,2,\dots,n\}$ 上的最优解，包括查看形如 $\{1,2,\dots,j\}$ 的较小问题的最优解。

对任意在 1 与 $n$ 之间的 $j$ 值，令 $O_j$ 表示对于有需求 $\{1,\dots,j\}$ 所组成问题的最优解，并且令 $OPT(j)$ 表示这个解的值。我们寻找的最优解就是 $O_n$，具有值 $OPT(n)$。

> **定理 6.1**
>
> $$

> OPT(j)=
> \begin{cases}
> 0, & \text{if } j=0\\
> \max\{\,v_j+OPT(p(j)),\ OPT(j-1)\,\}, & \text{otherwise}
> \end{cases}

> $$

> **定理 6.2**　需求 $j$ 属于集合 $\{1,2,\dots,j\}$ 上的最优解当且仅当

$$

v_j+OPT(p(j))\ge OPT(j-1)

$$

> 上面定理构成了动态规划求解基础的最重要的部分：**用较小子问题的最优解来表达更大规模问题的最优解的一个递推的等式**。

### 朴素递归算法为什么不行

```
Compute-Opt(j):
    If j = 0 then
        Return 0
    Else
        Return max(v_j + Compute-Opt(p(j)), Compute-Opt(j-1))
    Endif
```

> **定理 6.3**　对每个 $j=1,2,\dots,n$，Compute-Opt$(j)$ 正确地计算了 $OPT(j)$。

但是：**最坏情形下这个算法将以指数时间运行！**

> 观察：递归算法特别容易产生**冗余的重复子问题计算**，从而导致了指数阶算法。递归调用的次数增长就像 **Fibonacci 序列**一样：

$$

F(n)=F(n-1)+F(n-2)
$$

### 备忘录 (memoization)

为了避免上面的重复计算，我们把**中间计算的结果存储起来**，需要的时候先查找是否计算过。下面将用到一个数组 $M[0\ldots n]$ 保存中间计算结果。

```
M-Compute-Opt(j):
    If j = 0 then
        Return 0
    Else if M[j] is not empty then
        Return M[j]
    Else
        M[j] = max(v_j + M-Compute-Opt(p(j)), M-Compute-Opt(j-1))
        Return M[j]
    Endif
```

> **定理 6.4**　M-Compute-Opt$(n)$ 的运行时间是 $O(n)$。

**证明**：对于 M-Compute-Opt$(j)$，每一次调用所用的时间是 $O(1)$；每次调用时，

- (i) 或者返回一个已经存在的值 $M[j]$；
- (ii) 或者填入一个新项 $M[j]$，并且有**两次**递归调用。

定义**进展度量**为 $M[\cdot]$ 的非空元素数目：

- 初始 $\Phi=0$，全局中 $\Phi\le n$；
- $\Phi$ 每次增加 1。

可以推导出最多会有 $2n$ 次递归调用，所以 M-Compute-Opt$(n)$ 总的运行时间是 $O(n)$。

**预处理**：算法实现的过程中先对开始时间和结束时间排序，便于后面的处理：

$$

\text{按结束时间排序 } O(n\log n),\qquad \text{计算 } p(\cdot)\ O(n)\ \text{（若已对开始时间排序）}
$$

> **一些编程语言（如 Lisp）可以自动实现备忘录的功能 (built-in support for memoization)**，因而有好的执行效率；但是在其他的一些语言中（比如 Java）就没有实现这一功能。

### 迭代（自底向上）版本

> **另一种解决的思路**：在子问题上迭代，而不是递归地计算解。通过迭代算法直接计算 $M[\cdot]$ 中的项。

```
Iterative-Compute-Opt:
    M[0] = 0
    For j = 1, 2, ..., n:
        M[j] = max(v_j + M[p(j)], M[j-1])
    Endfor
```

$$

\text{运行时间 } O(n),\ \text{上面算法清楚地运行了 } n \text{ 次迭代运算}
$$

### 输出最优解本身

前面的动态规划算法只计算了一个最优解的**值**，如果想要输出这组最优的区间集合，如何处理？

> **利用存储的 $M[\cdot]$ 数组进行后期处理**。根据定理 6.2，$j$ 属于一个区间集合 $\{1,\dots,j\}$ 的最优解当且仅当

$$

v_j+OPT(p(j))\ge OPT(j-1)
$$

```
Find-Solution(j):
    If j = 0 then
        不输出
    Else if v_j + M[p(j)] >= M[j-1] then
        输出 j
        Find-Solution(p(j))
    Else
        Find-Solution(j-1)
    Endif
```

$$

\text{复杂度 } O(n)
$$

### 小结

> 对于带权区间调度问题，我们设计了一个多项式时间的算法：先设计一个（指数时间的）**递归**算法，然后通过**备忘录**将其转换成一个有效的递推算法，这个算法利用了全局数组 $M[\cdot]$ 来记录递归函数值。

## 9.3 动态规划的一般原理

> **动态规划与分治策略**
>
> - **相似之处**：通过子问题的解来求出全局问题的解；
> - **不同之处**：
>   - **子问题不独立**（有重叠）；
>   - **把子问题的解存在备忘录中**。

> **动态规划类型问题的三个特征**
>
> 1. 只存在**多项式个**子问题；
> 2. 容易从子问题的解计算初始问题的解；
> 3. 在子问题从"最小"到"最大"存在一种**自然的顺序**，与一个容易计算的**递推式**相联系，这个递推式允许从某些更小的子问题来确定一个子问题的解。

> **动态规划的四步过程**
>
> 1. **刻划最优解的结构**；
> 2. **递归定义最优解的值**；
> 3. **按照自底向上的方式或自顶向下记忆化方式**计算最优解的值，并记录下求解的途径；
> 4. **按照求解路径**给出最优解的形成过程。

## 9.4 分段的最小二乘 (Segmented Least Squares)

### 问题的提出

绘制在一组二维数轴上的科学统计数据，试图用一条"最佳拟合"的线通过这些数据——统计学与数值分析中的基本问题。

给定平面上由 $n$ 个点组成的集合

$$

P:\ (x_1,y_1),(x_2,y_2),\dots,(x_n,y_n),\qquad x_1<x_2<\cdots<x_n
$$

给定由方程 $y=ax+b$ 定义的直线 $L$，我们说 $L$ 相对于 $P$ 的**误差**是它对于 $P$ 中点的"距离"的平方和：

$$

SSE=\sum_{i=1}^{n}(y_i-ax_i-b)^2
$$

自然的目标是寻找具有最小误差的直线。这是一个求极值的问题，通过微积分中的方法可以解出 $a,b$。

> **实际中的困难**：有些时候数据看起来不像在一条直线中，而是大致位于**两条连续的直线**中，如何把"最佳拟合"这个概念形式化？——使用**最少的直线**来拟合这些点。

**问题**：如何在拟合的**精确度**和使用**最少的直线数目**之间找到一个平衡？

### 问题形式化

给定一组点 $(x_1,y_1),\dots,(x_n,y_n)$，其中 $x_1<x_2<\cdots<x_n$。寻找一组直线使得：在所有直线上的平方误差之和 $E$ 与直线的数目 $L$ 之间找到一个好的平衡。

因此定义**罚分度量函数**：

$$

E+cL,\qquad c>0 \text{ 是某一个常数}
$$

### 动态规划

**定义**：

- $OPT(j)$ = 对于点 $p_1,p_2,\dots,p_j$ 的最优解；
- $e(i,j)$ = 关系到 $p_i,p_{i+1},\dots,p_j$ 的任何直线的**最小误差**。

> **定理 6.6**　如果最优划分的最后一段是 $p_i,p_{i+1},\dots,p_n$，那么最优解的值是

$$

OPT(n)=e(i,n)+c+OPT(i-1)
$$

为得到 $OPT(j)$，对于某一个 $i$，我们应该以最好的方式产生最后的一段 $p_i,\dots,p_j$。

> **定理 6.7**　对于 $p_1,\dots,p_j$ 的子问题，

$$

OPT(j)=
\begin{cases}
0, & \text{if } j=0\\
\min_{1\le i\le j}\{\,e(i,j)+c+OPT(i-1)\,\}, & \text{otherwise}
\end{cases}
$$

现在设计这个算法中的困难部分已经克服：给出一个**自底向上**的算法。

### 复杂度分析

- **前半部分**：计算 $O(n^2)$ 个 $e(i,j)$；若按照公式逐对计算，每一对 $e(i,j)$ 需要 $O(n)$ 的复杂度；
- **后半部分**：总的代价应该是 $O(n^2)$；
- **因此总的算法代价**：

$$

O(n^3)
$$

> 如果**预先**计算统计信息 $e(i,j)$（用递推 / 前缀和的方式），那么代价降为 $O(n^2)$。

### 输出划分

通过数组 $M$ 向回寻找计算最优的划分：

```
Find-Segments(j):
    If j = 0 then
        不用输出
    Else
        找一个使得 e(i, j) + c + M[i-1] 最小的 i
        输出这一段 {p_i, ..., p_j} 作为直线段，以及输出
            递归函数 Find-Segments(i-1) 的结果
    Endif
```
