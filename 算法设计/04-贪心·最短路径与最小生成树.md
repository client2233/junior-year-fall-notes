# 04 贪心·最短路径与最小生成树

## 4.1 一个图的最短路径（Dijkstra 算法）

> **Edsger W. Dijkstra**（1972 年图灵奖）。主要研究工作：最早指出 "goto 有害"、首创结构化程序设计、PV 操作、Algol60 编译器。1956 年，在荷兰的两个地点之间找出最短路径，就是 Dijkstra 算法的起点。

### 问题描述

- 从网络中一个点到另一个点的旅行，经过一系列交叉点，基本问题是确定相应的图中结点之间的**最短路径**；
- **有向图** $G=(V,E)$，源点 $s$，终点 $t$，每条边 $e$ 有长度 $\ell_e\ge 0$；
- **最短路径问题**：寻找有向图中 $s$ 到 $t$ 的最短路径。

### 算法

> 保持一个结点集 $S$，如果源点 $s$ 到 $u$ 的最短路径一旦确定，那么 $u$ 就加到 $S$ 中。

$$
\text{最开始 } S=\{s\},\quad d(s)=0
$$

```
Dijkstra 算法 (G, l):
    设 S 是被探查的结点集合
    对每个 S 中的 u，存储一个 d(u)
    初始 S = {s} 且 d(s) = 0
    While S != V:
        选择一个不在 S 中的结点 v，使得从 S 到 v 至少
            有一条边连接
        d'(v) = min_{e=(u,v), u in S} { d(u) + l_e }
        将 v 加入 S 并且定义 d(v) = d'(v)
    Endwhile
```

> **关键点**：当 Dijkstra 算法加入一个结点 $v$ 时，我们就得到了**正确的**到 $v$ 的最短路径距离。

### 正确性：定理 4.14

> **定理 4.14**　算法执行中任意一点的集合 $S$，对每个 $S$ 中的 $u$，路径 $P_u$ 是最短的 $s$-$u$ 路径。

**证明（归纳）**：

- $|S|=1$ 时显然。
- 假设 $|S|=k>1$ 时命题成立。设 $v$ 是下一个加入 $S$ 的结点，$u$-$v$ 是被选中的边。
- 最短 $s$-$u$ 路径加上 $(u,v)$ 是一条长度为 $r(v)$ 的 $s$-$v$ 路径。
- 考虑任意一条 $s$-$v$ 路径 $P$，证明它不短于 $r(v)$。设 $x$-$y$ 是 $P$ 中**第一条离开 $S$ 的边**，$P'$ 是 $P$ 中到 $x$ 的子路径。$P$ 一旦离开 $S$ 就已经太长了：

$$

\ell(P)\ \ge\ \ell(P')+\ell(x,y)\ \ge\ d(x)+\ell(x,y)\ \ge\ r(y)\ \ge\ r(v)

$$

其中：

- $\ell(P')\ge d(x)$：非负权重 + 归纳假设；
- $d(x)+\ell(x,y)\ge r(y)$：$r(y)$ 的定义（$y\notin S$，$r(y)$ 是所有从 $S$ 出发进入 $y$ 的边的最小 $d(x)+\ell(x,y)$）；
- $r(y)\ge r(v)$：因为 Dijkstra 选择了 $v$ 而不是 $y$。

### 高效实现

> 对于每个"无关顶点"，不做改变；对于"相邻顶点"，当 $v$ 被加入"核心"时，对于边 $e=(v,w)$，更新临时最短距离：

$$

r(w)=\min\{\,r(w),\ r(v)+\ell_e\,\}

$$

> **提高效率的方法**：采用**优先队列**来存放没有探索的结点，根据 $r(v)$ 来排序。

| 实现方式 | 复杂度 | 说明 |
|---|---|---|
| 普通数组 | $O(mn)$ | 每次考虑增加一个结点，再线性求到源点最小距离 |
| **优先队列（堆）** | $O(m\log n)$ | $O(m)$ 次考虑边，$n$ 次 ExtractMin，$m$ 次 ChangeKey |

> **补充**：Dijkstra 要求**边权非负**。带负权的最短路在 [[11-动态规划·序列比对]] 之后由 Bellman-Ford 处理（动态规划）。

## 4.2 最小生成树问题

### 问题描述

假设我们有位置集合 $V=\{v_1,v_2,\dots,v_n\}$，我们想建立一个通信网络，网络应该是连通的，我们希望尽可能便宜地建立它。

对于确定的边 $e=(v,w)$，存在一个正的费用 $c_e$。问题是对于图 $G=(V,E)$，寻找 $T\subseteq E$，使得图 $(V,T)$ 是连通的，而且

$$

\sum_{e\in T} c_e\ \text{最小}
$$

例子中 $T$ 的总费用为 $50$。

> **命题 4.16**　设 $T$ 是满足上面网络设计问题的最小费用解，那么 $(V,T)$ 是一棵**树**。

**证明**：若 $(V,T)$ 含圈，删掉圈上任一条边仍连通且费用更小，矛盾。

### 应用

**直接应用 —— MST (Minimum Spanning Tree)**：

- Network design：telephone, electrical, TV cable, computer, road；
- 作为 NP 难问题的**近似算法**的基础：traveling salesperson problem、Steiner tree。

**间接应用**：

- max bottleneck paths；
- LDPC codes for error correction；
- learning features for real-time face verification；
- spanning-tree protocol for Ethernet bridging（避免网络中的圈）；
- Cluster analysis。

### 暴力搜索不可行：Cayley 定理

> **Cayley's 定理**　$K_n$ 一共存在 $n^{n-2}$ 种支撑树。

由此可见用穷举暴力搜索的方法是不可行的，需要有效的设计算法。

## 4.3 三种贪心算法

| 算法 | 初始 | 规则 |
|---|---|---|
| **Kruskal** | $T=\varnothing$，边按费用递增排序 | 通过不断插入边来建立生成树：把边 $e$ 插入 $T$，**只要不构成圈** |
| **Reverse-Delete（反向删除）** | $T=E$ | 依照费用递减的次序删除边：当到达每条边 $e$ 时（从最贵的开始），**只要这样做不破坏当前图的连通性**就删掉它 |
| **Prim** | $S=\{s\}$（任意起点） | 贪心地增长树 $T$：每步选择**一端在 $T$ 中、费用最小**的边与 $T$ 连接 |

**殊途同归，三种算法都可以产生最小生成树 (MST)。**

## 4.4 圈、割与两类性质

> **圈 (Cycle)**：形如 $a\text{-}b,\ b\text{-}c,\ c\text{-}d,\ \dots,\ y\text{-}z,\ z\text{-}a$ 的边集合。

> **割 (Cutset)**：一个割是结点的一个子集 $S$；对应的**割集** $D$ 是**恰好有一个端点在 $S$ 中**的边的子集。
>
> 例：$S=\{3,4,5,7\}$ 对应割集 $\{3\text{-}4,\ 3\text{-}5,\ 7\text{-}8\}$。

> **命题**　一个圈和一个割有**偶数条**相交边。

### 定理 4.17（割性质 / cut property）

> **定理 4.17**　假设所有边的费用都是不等的。令 $S$ 是任意结点子集，且 $S\ne\varnothing,V$；边 $e=(u,v)$ 是一端在 $S$ 中、另一端在 $V-S$ 中的**费用最小**的边，那么**每棵最小生成树都包含边 $e$**。

**证明（交换论证）**：

1. 假设 $e$ 不属于 $T^*$（某棵最小生成树）；
2. 增加 $e$ 到 $T^*$ 形成了一个圈 $C$；
3. 边 $e$ 既属于圈 $C$，也属于与 $S$ 对应的割 $D$；因此一定存在**另一条边** $f$，既属于 $C$ 也属于 $D$；
4. 那么 $T'=T^*\cup\{e\}-\{f\}$ 也是一棵生成树；
5. 因为 $c_e<c_f$（费用不等且 $e$ 是割中最小），$\operatorname{cost}(T')<\operatorname{cost}(T^*)$，导出矛盾。

> **推论**　这也说明 Prim 算法每步选的都是割中最小边，因此每步加入的边都**属于每棵 MST**。

### 定理 4.20（圈性质 / cycle property）

> **定理 4.20**　假设所有边的费用都是不等的。令 $C$ 是 $G$ 的一个圈，令边 $f=(v,w)$ 是属于 $C$ 的**最贵的边**，那么 $f$ **不属于** $G$ 的任何最小生成树。

**证明（交换论证）**：假设 $f$ 属于 $T^*$。

1. 把 $f$ 从 $T^*$ 中删除得到一个集合 $S$（两个连通分支）；
2. 与 $S$ 对应的割 $D$ 中，边 $f$ 在圈 $C$ 上，也一定存在另一条边 $e$，既属于 $C$ 也属于 $D$；
3. 那么 $T'=T^*\cup\{e\}-\{f\}$ 也是一棵生成树；
4. 因为 $c_e<c_f$，$\operatorname{cost}(T')<\operatorname{cost}(T^*)$，导出矛盾。

### 反向删除算法的正确性：定理 4.21

> **定理 4.21**　逆删除算法产生 $G$ 的一棵最小生成树。

**证明**：最后算法输出 $(V,T)$ 是连通的。如果 $(V,T)$ 包含一个圈 $C$，考虑 $C$ 上最贵的边 $e$，它将是算法遇到的第一条边，移走它应该不会破坏图的连通性——与逆删除算法的行为矛盾（算法当时就应该删掉了它）。

## 4.5 三种算法的细节与复杂度

### Prim 算法

> **Prim's algorithm** [Jarník 1930, Dijkstra 1957, Prim 1959]

- 初始 $S=$ 任意结点；
- 每次把与 $S$ 对应的**割中最小费用边**加入 $T$，同时把新的探索结点 $u$ 加入 $S$。

> **定理 4.19**　Prim 算法产生一棵最小生成树。

**证明**：对于 Prim 算法，容易知道它只加了那些属于每棵最小生成树的边。根据定义，$e$ 是使得一个结点在 $S$ 中而另一个结点在 $V-S$ 中费用最低的边 $(\min_{u\notin S} c_e)$，所以根据割性质 4.17，$e$ 在每一棵最小生成树中。

**实现**：采用与 Dijkstra 类似的算法，使用**优先队列**。保持一些已经探索过的结点集合 $S$；对于每一个没有探索过的结点 $v$，

$$

cost[v]=\text{从 } v \text{ 连到 } S \text{ 中某个结点的最便宜边的费用}
$$

$$

\text{复杂度（堆实现）}=O(m\log n)
$$

### Kruskal 算法

> **Kruskal's algorithm** [Kruskal, 1956]

- 边按照费用递增的顺序排序；
- **Case 1**：如果把边 $e$ 加入 $T$ 时构成了一个圈，那么跳过边 $e$；
- **Case 2**：否则，把边 $e=(u,v)$ 加入 $T$ 中（根据割性质），其中 $S$ 是与 $u$ 连通的结点集。

```
Kruskal(G, c) {
    sort edge weights so that c_1 <= c_2 <= ... <= c_m
    T <- 空集
    foreach (u in V) make a set containing singleton u
    for i = 1..m:
        (u, v) = e_i
        if (u and v are in different sets) {
            T <- T ∪ {e_i}
            merge the sets containing u and v
        }
    return T
}
```

**算法实现**：主要使用 **union-find 数据结构**；保持每一个连通分支的集合。

> **Kruskal 算法代价**：$O(m\log n)$

> **补充（排除费用不同的假设）**：原来假设所有边的费用不同，现在推广——对于边费用相同的情形加一个**无穷小扰动**，这样避免了"平分"的情形；对于原来不同的费用次序没有影响。注意到相关的算法基于边费用的**相对关系**，所以同样产生对原始实例也是最优的 MST。

### 比较

| 算法 | 复杂度 | 关键数据结构 |
|---|---|---|
| Prim | $O(m\log n)$ | 优先队列（堆） |
| Kruskal | $O(m\log n)$ | union-find |
| Reverse-Delete | $O(m\log n)$ | 连通性检查 |

> **选择建议（补充）**：稠密图（$m\sim n^2$）用 Prim 更省（$O(n^2)$ 数组实现）；稀疏图（$m\sim n$）两者同阶，Kruskal 实现更简单。

### MST 的推广方向

- 还关心点到点的距离；
- 介意边上的拥塞：给定需要在结点对之间运输的交通量，需要寻找一棵生成树，其中每条边运输不超过确定的交通量；
- **真实的网络设计鲁棒性**：寻找集合上最便宜的连通网络，要求删除一条边后仍保持畅通。

## 4.6 聚类 (Clustering)：最大间隔聚类

### 问题

给定一组个体（照片、文件、微生物等），需要试图把它们分类或者组成相关的群体，产生聚类问题。

**需要定义距离函数**：描述关系的远近。

> **基本问题**：Divide into clusters so that points in different clusters are far apart.

应用：mobile ad hoc networks 路由、基因表达模式识别、Web 搜索的文档归类、医学图像数据库的相似性检索、Skycat（把 109 个天体聚成恒星 / 类星体 / 星系）。

### 形式化

- **$k$ 聚类**：把对象分成 $k$ 个非空的部分；
- **距离函数** $d(p_i,p_j)$ 满足：

$$

d(p_i,p_i)=0,\qquad d(p_i,p_j)>0,\qquad d(p_i,p_j)=d(p_j,p_i)
$$

- **间隔 (spacing)**：处在**不同**聚类中的任何一对点之间的**最小**距离；
- 对于某个 $k$，寻找具有**最大可能间隔**的 $k$ 聚类。

### 算法：单链聚类 = Kruskal

```
按照距离 d(p_i, p_j) 增加的次序在点对之间增加边
如果发现 p_i 与 p_j 已经属于同一个聚类，
    那么应该避免加这条边，因为它不会改变连通分支的集合
每次添加一条横跨两个不同连通分支的边，就把两个对应的聚类合并
```

可以发现，实现的过程仿佛就是 **Kruskal 最小生成树算法**：

- 也就是，运行 Kruskal 算法，但是**就在它加最后的 $k-1$ 条边之前停止**；
- 等价于取整棵最小生成树 $T$，然后**删除 $k-1$ 条最贵的边**，并且定义 $k$ 聚类是所得到的连通分支 $C_1,C_2,\dots,C_k$。

> **定理 4.26**　由删除最小生成树 $T$ 的 $k-1$ 条最贵的边所构成的连通分支 $C_1^*,C_2^*,\dots,C_k^*$ 组成一个**最大间隔的 $k$ 聚类**。

**证明**：设 $C_1,\dots,C_k$ 是另外一个聚类。

- $C^*$ 的间隔就是第 $k-1$ 条最贵边的长度，记为 $d^*$；
- 设 $p_i,p_j$ 在 $C^*$ 的同一个聚类 $C_t^*$ 中，但是在 $C$ 的不同聚类中，比如 $C_a$ 与 $C_b$；
- 由于 $p_i,p_j$ 属于同一个连通分支 $C_t^*$，所以一定在我们停止之前 Kruskal 算法添加了 $p_i$-$p_j$ 路径上所有的边。特别地，这条路径上每条边的长度**至多**是 $d^*$；
- 因为相邻的 $p,q$ 属于 $C$ 中不同的聚类，所以 $C$ 的间隔 $\le d^*$。

$$

\Rightarrow\ C^* \text{ 是最大间隔聚类},\qquad \text{复杂度 } O(m\log n)=O(n^2\log n)
$$
