# 07 分治·最近点对

## 7.1 问题

**给定平面上的 $n$ 个点，找最邻近的一对点。**

- 这是**计算几何**领域的基础问题；
- 20 世纪 70 年代，M. I. Shamos 与 D. Hoey 关心是否能找到一个渐进的比平方阶更快的算法。

**应用领域**：Graphics、computer vision、geographic information systems、molecular modeling、air traffic control。它也是 nearest neighbor、Euclidean MST、Voronoi 图的特殊情形。

### 可行性分析

- **特殊情形**：如果所有的点都在一个维度的直线上（按坐标排序），$O(n\log n)$ 即可；
- 为了方便后面的描述，假设这些点的 $x$ 坐标都**不相同**。

### 朴素的划分为什么不行

考虑把一块平面区域分成四个部分——**这种划分会带来的问题：不均匀**（点可能集中在某一格，某一格可能为空）。

正确做法：**划分的时候，用一条垂直线把点集分成相等的两部分。**

---

## 7.2 分治算法

**三个步骤**：

1. 在**左半部分**寻找各自最邻近的点对；
2. 在**右半部分**寻找各自最邻近的点对；
3. **合并**：在"交界"的边中寻找最近的点对。

最后返回上面 3 个解中的最优解。

**问题的关键**：寻找"交界"的边中比 $\delta=\min(\delta_L,\delta_R)$ 还要近的点对。

### 窄带 (strip)

根据平面几何的约束性质，只需要考虑**分界线附近的点集**情况：把分界线左右各 $\delta$ 宽的区域称为**窄带**。

把"窄带"之中的点集按照 $y$ 坐标的大小排序编号。

> **定义**　设 $s_i$ 是 $2\delta$ 窄带中按照 $y$ 坐标排序的第 $i$ 个点。

> **命题**　如果 $|i-j|\ge 12$，那么 $s_i$ 与 $s_j$ 之间的距离至少是 $\delta$。

**证明**：

- 在 $\frac12\delta\times\frac12\delta$ 的小盒子中，**至多只有一个点**（否则这两个点的距离小于 $\delta$，与 $\delta$ 是最优解矛盾）；
- $s_i$ 与 $s_j$ 之间至少可以间隔两行，距离 $\ge 2\left(\frac12\delta\right)=\delta$。

> **直观**：这里目的是为了说明**不需要在窄带之间进行两两之间点的比较**；只需要在一个常数阶的范围内比较就可以。

## 7.3 算法与复杂度

```
Closest-Pair(P):
    构造 P_x 与 P_y                     O(n log n)
    (p0*, p1*) = Closest-Pair-Rec(P_x, P_y)
```

```
Closest-Pair-Rec(P_x, P_y):
    If |P| <= 3 then
        进行简单穷举排序
    End if
    构造 Q_x, Q_y, R_x, R_y             O(n) 时间
    (q0*, q1*) = Closest-Pair-Rec(Q_x, Q_y)
    (r0*, r1*) = Closest-Pair-Rec(R_x, R_y)
    delta = min(d(q0*, q1*), d(r0*, r1*))
    L = { <x, y> : x = x* }             集合 Q 中点的最大 x 坐标构成的竖直线
    S = P 中与 L 相距在 delta 之内的点集
    构造 S_y                            O(n) 时间
    For 每个点 S_y 中的点 s:
        计算从 s 到跟着 S_y 的 15 个点中每个点的距离
    令 s, s' 是达到其中最小距离的点对      O(n) 时间
    If d(s, s') < delta then
        Return (s, s')
    Else if d(q0*, q1*) < d(r0*, r1*) then
        Return (q0*, q1*)
    Else
        Return (r0*, r1*)
    End if
```

### 先看一个次优版本

如果每一步都对窄带重新按 $y$ 排序：

$$

T(n)\le 2T(n/2)+O(n\log n)
\ \Rightarrow\ T(n)=O(n\log^2 n)
$$

| 步骤 | 代价 |
|---|---|
| 划分 + 排序（每层都重新排） | $O(n\log n)$ |
| 递归 | $2T(n/2)$ |
| 合并（扫描窄带） | $O(n)$ |
| **合计** | $O(n\log^2 n)$ |

### 改进到 $O(n\log n)$

> **是否存在 $O(n\log n)$ 的算法？**
>
> 上述算法在窄带之中的排序消耗了 $O(n\log n)$；所以希望在窄带中能够**不必从头开始排序**。
>
> 通过**预处理**，可以在 $O(n)$ 的时间内实现窄带中的排序。

做法：一开始就把所有点按 $x$ 排序得到 $P_x$、按 $y$ 排序得到 $P_y$，递归时通过一次线性扫描把 $P_y$ **分裂**成 $Q_y$、$R_y$（而不是在每个子问题里重新排序）。于是每一步只有 $O(n)$ 的额外代价。

> **定理 5.12**　上面修改后的分治算法的运行时间是 $O(n\log n)$。

**证明**：

$$

T(n)\le 2T(n/2)+O(n)\ \Rightarrow\ T(n)=O(n\log n)
$$

> **补充（系数 12 与 15 的来源）**：窄带内按 $y$ 排序后，与 $s$ 距离可能小于 $\delta$ 的点只有紧随其后的**常数个**。课件把"间隔两行"写成 $|i-j|\ge12$，于是算法只需检查后续 **15** 个点（书中另一处给出更紧的参数 7）。要点不是具体常数，而是**"只需检查常数个"**——这才把合并步从 $O(n^2)$ 压到 $O(n)$。
